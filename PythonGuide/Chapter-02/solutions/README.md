# Chapter 02. Solutions

## Exercise Solutions

### Q-01

**정답: ③ `total_price`**

변수 이름은 숫자로 시작할 수 없고, `-`는 뺄셈 연산자로 해석됩니다. `class`는 Python에서 사용하는 키워드이므로 변수 이름으로 사용할 수 없습니다.

### Q-02

**정답: ②**

`=`은 오른쪽 값을 왼쪽 변수 이름에 대입합니다. 두 값이 같은지 비교하는 연산자는 `==`입니다.

### Q-03

**정답: ③ `str`**

따옴표로 감싼 `"12"`는 숫자처럼 보이지만 문자열입니다.

### Q-04

**정답: ② `3`**

`17 / 5`는 `3.4`이고, `17 // 5`는 그 결과를 아래쪽 정수로 내린 `3`입니다.

### Q-05

**모범답안:** `=`은 변수에 값을 대입할 때 사용하고, `==`은 두 값이 같은지 비교할 때 사용합니다. `==`으로 비교하면 참 또는 거짓을 나타내는 결과를 얻습니다.

### Q-06

**모범답안:** `7 + 3`은 정수끼리 더하므로 `10`입니다. `"7" + "3"`은 문자열을 이어 붙이므로 `"73"`입니다.

### Q-07

**정답**

```text
10
```

`count`는 처음에 2입니다. `count + 3`을 다시 대입하면 5가 되고, `count *= 2`를 실행하면 10이 됩니다.

### Q-08

**정답**

```text
10
18
```

첫 번째는 곱셈을 먼저 계산하고, 두 번째는 괄호 안의 덧셈을 먼저 계산합니다.

### Q-09

**정답**

```text
False
True
```

`stock >= requested`는 `True`, `is_open`은 `False`입니다. 두 조건을 `and`로 연결하면 `False`, `or`로 연결하면 `True`입니다.

### Q-10

**모범답안**

```python
unit_price = 2500
quantity = 4

total = unit_price * quantity
print(total)
```

**실행 결과**

```text
10000
```

Python에서 곱셈은 `x`가 아닌 `*`로 작성합니다.

## Mini Project Solutions

### Basic — 상품 구매 금액 계산

[모범 코드: `basic.py`](./basic.py)

단가와 수량을 곱해 할인 전 금액을 구한 다음, 할인 금액을 뺍니다. 계산 결과를 별도 변수에 보관하면 나중에 출력하거나 다른 계산에 사용할 수 있습니다.

**확인할 사항**

- 단가나 수량을 변경하면 할인 전 금액과 결제 금액이 함께 변경됩니다.
- 할인 금액이 0이면 결제 금액은 할인 전 금액과 같습니다.
- 출력에 사용하는 금액을 매번 새로 계산하지 않고 변수를 통해 사용합니다.

### Advanced — 카페 주문 및 결제 가능 여부 확인

[모범 코드: `advanced.py`](./advanced.py)

상품별 금액을 더한 주문 금액을 기준으로 결제 예정 금액과 회원 혜택 대상 여부를 각각 계산합니다. 결제 가능 여부는 보유 잔액과 결제 예정 금액을 비교하고, 회원 혜택 대상 여부는 회원 상태와 **할인 전 주문 금액**을 함께 확인합니다.

두 조건의 기준 금액이 다르다는 점에 주의해야 합니다. 회원 혜택 대상이라고 해서 할인 금액이 자동으로 변경되는 것은 아닙니다.

**확인할 사항**

- 보유 잔액이 14,000원이면 결제 가능 여부는 `False`입니다.
- 보유 잔액을 15,000원으로 바꾸면 `True`입니다.
- 회원 여부를 `False`로 바꾸면 회원 혜택 대상 여부는 `False`입니다.
- 조건문 없이 비교식과 논리식만으로 두 결과를 계산합니다.
