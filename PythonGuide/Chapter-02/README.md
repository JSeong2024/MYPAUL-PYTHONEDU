# Chapter 02. Variables, Data Types & Operators

프로그램에서는 숫자를 계산하거나 문장을 다루고, 계산한 결과를 나중에 다시 사용하기도 합니다. 이러한 작업을 하려면 값을 구분할 이름과 값을 계산하는 방법이 필요합니다.

이번 장에서는 **변수(Variable)**, **자료형(Data Type)**, **연산자(Operator)** 를 살펴봅니다. 아직 복잡한 프로그램을 만들지는 않지만, 이후에 배우는 조건문과 반복문, 함수 모두 이 내용을 바탕으로 사용합니다.

## 2.1. Variables & Assignment

### 2.1.1. 변수란 무엇인가?

어떤 상품의 가격이 1,500원이고 세 개를 구매한다고 가정해 봅시다. 계산식은 다음과 같습니다.

```python
print(1500 * 3)
```

**실행 결과**

```text
4500
```

계산은 간단하지만, 숫자만 보고는 `1500`과 `3`이 무엇을 뜻하는지 알기 어렵습니다.

값에 이름을 붙이면 코드의 의미가 분명해집니다.

```python
price = 1500
quantity = 3

total = price * quantity
print(total)
```

**실행 결과**

```text
4500
```

`price`는 상품 가격, `quantity`는 수량을 나타냅니다. `total`에는 두 값을 곱한 결과가 들어갑니다.

이처럼 프로그램에서 값을 가리키도록 붙인 이름을 **변수(Variable)** 라고 합니다. 가격표에 상품의 이름을 적어 두면 어떤 물건인지 구별할 수 있듯이, 변수 이름을 사용하면 값이 무엇을 의미하는지 알 수 있습니다.

Python에서는 `=`을 사용해 변수에 값을 **대입(Assignment)** 합니다.

```python
price = 1500
```

이 코드는 오른쪽의 `1500`을 `price`라는 이름으로 사용할 수 있게 한다는 뜻입니다. 수학에서 사용하는 등호와는 의미가 다릅니다. 두 값이 같은지 비교할 때는 뒤에서 배울 `==`을 사용합니다.

### 2.1.2. 변수에 저장된 값 바꾸기

변수는 같은 이름으로 다시 대입할 수 있습니다.

```python
quantity = 3
print(quantity)

quantity = 5
print(quantity)
```

**실행 결과**

```text
3
5
```

첫 번째 `print()`에서는 `3`이 출력됩니다. 그다음 `quantity`에 `5`를 대입했으므로 두 번째 출력은 `5`가 됩니다.

변수에 들어 있는 값을 이용해 새로운 값을 계산할 수도 있습니다.

```python
count = 3
count = count + 1

print(count)
```

**실행 결과**

```text
4
```

`count = count + 1`은 오른쪽을 먼저 계산한 뒤 그 결과를 다시 `count`에 대입합니다. 따라서 기존 값 `3`에 `1`을 더한 `4`가 남습니다.

### 2.1.3. 변수 이름 정하기

Python에서는 변수 이름을 비교적 자유롭게 정할 수 있지만 몇 가지 규칙이 있습니다.

| 이름 | 사용 가능 | 이유 |
|---|:---:|---|
| `price` | O | 영문자로 시작 |
| `item_count` | O | 단어 사이에 밑줄(`_`) 사용 |
| `score2` | O | 첫 글자 뒤에 숫자 사용 |
| `2score` | X | 숫자로 시작 |
| `item-price` | X | `-`는 뺄셈 연산자로 해석 |
| `class` | X | Python에서 정해 둔 키워드 |

이름에는 영문자, 숫자, 밑줄 등을 사용할 수 있습니다. 다만 숫자로 시작할 수 없고, `class`나 `if`처럼 Python 문법에서 사용하는 **키워드(Keyword)** 는 변수 이름으로 쓸 수 없습니다.

Python은 대문자와 소문자를 구별합니다. `price`와 `Price`는 서로 다른 변수입니다.

여러 단어를 연결할 때는 `student_count`, `total_price`처럼 소문자와 밑줄을 사용하는 방식을 권장합니다. 무엇을 나타내는지 쉽게 짐작할 수 있는 이름이 좋습니다.

### 2.1.4. 여러 값 출력하기

`print()`에 쉼표로 구분한 값을 넣으면 한 줄에 함께 출력할 수 있습니다.

```python
name = "Apple"
price = 1500

print("상품:", name)
print("가격:", price)
```

**실행 결과**

```text
상품: Apple
가격: 1500
```

쉼표로 구분한 값 사이에는 기본적으로 공백 한 칸이 들어갑니다. 출력 형식을 자세히 다루는 방법은 Chapter 03에서 배웁니다.

## 2.2. Data Types

### 2.2.1. 숫자와 문자는 어떻게 다를까?

사람은 `20`이라는 숫자와 `"20"`이라는 문장을 보고 차이를 쉽게 이해합니다. 컴퓨터는 이 둘을 서로 다른 종류의 값으로 다룹니다.

값이 어떤 종류인지 구분하는 것을 **자료형(Data Type)** 이라고 합니다. 지금은 다음 네 가지를 알아두면 됩니다.

| 자료형 | 이름 | 예시 | 의미 |
|---|---|---|---|
| `int` | 정수(Integer) | `10`, `-3`, `0` | 소수점이 없는 정수 |
| `float` | 실수(Float) | `3.14`, `-0.5` | 소수점이 있는 수를 표현 |
| `str` | 문자열(String) | `"Python"`, `"20"` | 글자와 문장 |
| `bool` | 불리언(Boolean) | `True`, `False` | 참 또는 거짓 |

정수와 실수는 계산에 사용할 수 있지만, 문자열은 글자를 나타내기 위해 사용합니다. 문자열은 큰따옴표(`" "`)나 작은따옴표(`' '`)로 감쌉니다.

```python
age = 20
height = 175.5
name = "Mina"
is_student = True
```

`True`와 `False`는 따옴표를 붙이지 않으며 첫 글자를 대문자로 작성합니다.

### 2.2.2. 자료형 확인하기

`type()`을 사용하면 값의 자료형을 확인할 수 있습니다.

```python
print(type(20))
print(type(3.5))
print(type("Python"))
print(type(True))
```

**실행 결과**

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

출력된 `<class 'int'>`는 값의 자료형이 `int`라는 뜻입니다. 지금은 괄호와 `class`의 자세한 의미보다 `int`, `float`, `str`, `bool`을 구분하는 데 집중하면 됩니다.

Python에서는 변수 이름 자체에 자료형이 고정되지 않습니다. 같은 이름에 다른 종류의 값을 다시 대입할 수도 있습니다.

```python
value = 10
print(type(value))

value = "ten"
print(type(value))
```

**실행 결과**

```text
<class 'int'>
<class 'str'>
```

### 2.2.3. 숫자와 문자열의 차이

숫자를 더할 때와 문자열을 연결할 때는 같은 `+` 기호를 사용해도 결과가 다릅니다.

```python
print(20 + 5)
print("20" + "5")
```

**실행 결과**

```text
25
205
```

첫 번째는 숫자끼리 더한 결과입니다. 두 번째는 문자열 `"20"`과 `"5"`를 이어 붙인 결과입니다.

문자열과 숫자를 바로 더하려고 하면 오류가 발생합니다.

```python
print("20" + 5)
```

이 코드는 `TypeError`를 발생시킵니다. 서로 다른 자료형에 대해 해당 `+` 연산을 수행할 수 없기 때문입니다. 문자열을 숫자로 바꾸거나 숫자를 문자열로 바꾸는 방법은 Chapter 03에서 배웁니다.

## 2.3. Arithmetic Operators

연산자는 값을 계산하거나 비교할 때 사용하는 기호입니다. 먼저 숫자 계산에 사용하는 **산술 연산자(Arithmetic Operator)** 를 살펴봅니다.

### 2.3.1. 기본 산술 연산

| 연산자 | 의미 | 예시 | 결과 |
|:---:|---|---|---|
| `+` | 덧셈 | `7 + 3` | `10` |
| `-` | 뺄셈 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 | `7 / 2` | `3.5` |
| `//` | 몫을 내림하여 구하기 | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

곱셈에는 `×`가 아닌 `*`를 사용합니다. 거듭제곱에는 `**`를 사용하며, `^`는 거듭제곱 연산자가 아닙니다.

### 2.3.2. 나눗셈, 몫, 나머지

사과 17개를 상자 하나에 5개씩 담는다고 생각해 봅시다.

```python
apples = 17
box_size = 5

print(apples / box_size)
print(apples // box_size)
print(apples % box_size)
```

**실행 결과**

```text
3.4
3
2
```

- `/`는 일반적인 나눗셈 결과를 구합니다.
- `//`는 나눗셈 결과를 아래쪽 정수로 내립니다. 양수끼리 계산하는 위 예제에서는 가득 채운 상자가 세 개입니다.
- `%`는 나머지를 구합니다. 상자에 넣고 남는 사과는 두 개입니다.

`//`를 단순히 소수점만 잘라 내는 연산자로 기억하면 안 됩니다. 음수가 포함되면 결과가 달라질 수 있습니다. 예를 들어 `-7 // 3`의 결과는 `-3`입니다.

또한 `/`는 정수끼리 계산해도 `float` 결과를 반환합니다.

```python
print(8 / 2)
```

**실행 결과**

```text
4.0
```

0으로 나누는 연산은 할 수 없습니다. 예를 들어 `10 / 0`을 실행하면 `ZeroDivisionError`가 발생합니다.

### 2.3.3. 계산 순서

Python도 일반적인 수학 계산처럼 곱셈과 나눗셈을 덧셈과 뺄셈보다 먼저 계산합니다.

```python
print(10 + 2 * 3)
print((10 + 2) * 3)
```

**실행 결과**

```text
16
36
```

첫 번째는 `2 * 3`을 먼저 계산합니다. 두 번째는 괄호 안의 `10 + 2`를 먼저 계산합니다.

계산식을 읽기 어렵다면 괄호를 사용해 의도를 분명히 나타내는 편이 좋습니다.

## 2.4. Comparison & Logical Operators

### 2.4.1. 비교 연산자

**비교 연산자(Comparison Operator)** 는 두 값을 비교합니다. 결과는 참을 나타내는 `True` 또는 거짓을 나타내는 `False`입니다.

| 연산자 | 의미 | 예시 | 결과 |
|:---:|---|---|---|
| `==` | 같다 | `5 == 5` | `True` |
| `!=` | 다르다 | `5 != 3` | `True` |
| `>` | 크다 | `5 > 3` | `True` |
| `<` | 작다 | `5 < 3` | `False` |
| `>=` | 크거나 같다 | `5 >= 5` | `True` |
| `<=` | 작거나 같다 | `5 <= 3` | `False` |

예를 들어 시험 점수가 60점 이상인지 확인할 수 있습니다.

```python
score = 75

print(score >= 60)
print(score == 100)
```

**실행 결과**

```text
True
False
```

아직 조건문을 배우지는 않았지만, 비교 결과를 직접 출력해 확인할 수 있습니다. Chapter 05에서는 이 결과에 따라 서로 다른 코드를 실행하는 방법을 배웁니다.

여기서 `=`과 `==`을 혼동하지 않도록 주의합니다.

```python
score = 75        # 값을 대입
print(score == 75)  # 두 값이 같은지 비교
```

### 2.4.2. 논리 연산자

**논리 연산자(Logical Operator)** 는 여러 조건을 함께 판단할 때 사용합니다.

| 연산자 | 의미 | 조건 판단 예시 |
|:---:|---|---|
| `and` | 두 조건이 모두 참이어야 참 | 나이가 충분하고, 동의도 한 경우 |
| `or` | 두 조건 중 하나 이상이 참이면 참 | 쿠폰이 있거나, 회원인 경우 |
| `not` | 참과 거짓을 반대로 바꿈 | 로그인 상태가 아닌 경우 |

다음은 물건을 살 수 있는지 확인하는 예제입니다.

```python
balance = 15000
price = 12000
is_available = True

print(balance >= price)
print(balance >= price and is_available)
print(balance < price or not is_available)
```

**실행 결과**

```text
True
True
False
```

잔액은 가격보다 크고, 상품도 구매할 수 있는 상태이므로 두 조건을 `and`로 연결한 결과는 `True`입니다.

마지막 식은 잔액이 부족하거나 상품을 구매할 수 없는 상태인지 확인합니다. 두 조건이 모두 거짓이므로 `False`가 출력됩니다.

이 예제처럼 비교식이나 `True`·`False`를 논리 연산자로 연결하면 결과를 참·거짓으로 판단할 수 있습니다.

## 2.5. Assignment Operators & Expressions

### 2.5.1. 복합 대입 연산자

변수의 값을 증가시키거나 줄일 때는 계산과 대입을 한 번에 작성할 수 있습니다.

```python
count = 3
count = count + 2

print(count)
```

**실행 결과**

```text
5
```

같은 코드를 다음과 같이 줄일 수 있습니다.

```python
count = 3
count += 2

print(count)
```

**실행 결과**

```text
5
```

`+=`처럼 계산과 대입을 함께 수행하는 기호를 **복합 대입 연산자(Augmented Assignment Operator)** 라고 합니다.

| 연산자 | 예시 | 의미 |
|:---:|---|---|
| `+=` | `x += 3` | `x`에 3을 더한 결과를 다시 대입 |
| `-=` | `x -= 3` | `x`에서 3을 뺀 결과를 다시 대입 |
| `*=` | `x *= 3` | `x`에 3을 곱한 결과를 다시 대입 |
| `/=` | `x /= 3` | `x`를 3으로 나눈 결과를 다시 대입 |
| `//=` | `x //= 3` | `x`를 3으로 나눈 몫을 내림하여 다시 대입 |
| `%=` | `x %= 3` | `x`를 3으로 나눈 나머지를 다시 대입 |

복합 대입 연산자가 모든 상황에서 더 좋은 것은 아닙니다. 원래 값을 유지해야 한다면 새로운 변수를 사용하는 것이 적절합니다.

```python
original_price = 10000
discount = 2000

final_price = original_price - discount

print(original_price)
print(final_price)
```

**실행 결과**

```text
10000
8000
```

### 2.5.2. 표현식과 계산 결과

`price * quantity`, `score >= 60`처럼 값을 계산해 결과를 만들어 내는 코드를 **표현식(Expression)** 이라고 합니다.

```python
price = 2500
quantity = 4

total = price * quantity
is_expensive = total >= 10000

print(total)
print(is_expensive)
```

**실행 결과**

```text
10000
True
```

`price * quantity`는 숫자 결과를 만들고, `total >= 10000`은 참·거짓 결과를 만듭니다. 이 결과를 변수에 대입하거나 `print()`로 확인할 수 있습니다.

여기까지 익힌 문법만으로도 간단한 가격 계산이나 조건 확인 프로그램을 작성할 수 있습니다. 다음 장에서는 키보드로 값을 입력받고, 출력 결과를 원하는 형식으로 표시하는 방법을 다룹니다.

---

## Summary

- **변수**는 값에 이름을 붙여 다시 사용할 수 있게 합니다. `=`은 대입, `==`은 비교에 사용합니다.
- 대표적인 **자료형**에는 정수 `int`, 실수 `float`, 문자열 `str`, 불리언 `bool`이 있습니다.
- `+`, `-`, `*`, `/`, `//`, `%`, `**`로 숫자를 계산합니다. 괄호를 사용하면 계산 순서를 분명하게 나타낼 수 있습니다.
- **비교 연산자**는 두 값을 비교하고, **논리 연산자**는 여러 조건을 함께 판단합니다.
- `+=`, `-=` 등의 **복합 대입 연산자**는 계산 결과를 같은 변수에 다시 대입할 때 사용합니다.

#### 1. 상품 구매 금액 계산

상품을 구매할 때 할인 전 금액과 최종 결제 금액을 계산하는 프로그램을 작성합니다.

**주어진 정보**

| 항목 | 값 |
|---|---|
| 상품명 | 사과 |
| 단가 | 1,800원 |
| 수량 | 4개 |
| 할인 금액 | 1,000원 |

**요구사항**

1. 상품명, 단가, 수량, 할인 금액을 각각 변수에 저장한다.
2. 할인 전 금액을 `단가 × 수량`으로 계산한다.
3. 최종 결제 금액을 `할인 전 금액 - 할인 금액`으로 계산한다.
4. 상품명, 수량, 할인 전 금액, 할인 금액, 최종 결제 금액을 출력한다.

**예상 출력**

```text
상품: 사과
수량: 4
할인 전 금액: 7200
할인 금액: 1000
결제 금액: 6200
```

**확인할 사항**

- 단가나 수량을 변경하면 계산 결과도 달라지는가?
- 할인 금액을 0으로 바꾸면 결제 금액은 할인 전 금액과 같아지는가?
- 금액 계산에 필요한 숫자를 출력문마다 직접 반복하지 않고 변수를 사용했는가?

### Advanced 
#### 2. 카페 주문 및 결제 가능 여부 확인

카페에서 여러 상품을 주문했습니다. 주문 금액과 할인 적용 후 금액을 계산하고, 보유한 잔액으로 결제할 수 있는지 확인하는 프로그램을 작성합니다.

**주어진 정보**

| 항목 | 값 |
|---|---|
| 커피 단가 | 4,500원 |
| 커피 수량 | 2잔 |
| 샌드위치 단가 | 6,200원 |
| 샌드위치 수량 | 1개 |
| 할인 금액 | 1,000원 |
| 보유 잔액 | 14,000원 |
| 회원 여부 | `True` |
| 회원 혜택 최소 주문 금액 | 15,000원 |

**요구사항**

1. 모든 정보를 변수에 저장한다.
2. 상품별 금액을 계산한 뒤 주문 금액을 구한다.
3. 주문 금액에서 할인 금액을 빼 결제 예정 금액을 구한다.
4. 보유 잔액이 결제 예정 금액 이상인지 비교한다.
5. 회원이면서 **할인 전 주문 금액이 15,000원 이상**인지 논리 연산자로 확인한다.
6. 주문 금액, 할인 금액, 결제 예정 금액, 결제 가능 여부, 회원 혜택 대상 여부를 출력한다.

**예상 출력**

```text
주문 금액: 15200
할인 금액: 1000
결제 예정 금액: 14200
결제 가능: False
회원 혜택 대상: True
```

회원 혜택 대상인지는 확인만 합니다. 혜택에 따라 할인 금액을 바꾸거나 결제를 진행하는 기능은 구현하지 않습니다. 이러한 분기 처리는 Chapter 05의 조건문에서 다룹니다.

**확인할 사항**

- 주문 수량을 변경하면 주문 금액과 결제 예정 금액이 함께 바뀌는가?
- 보유 잔액을 15,000원으로 변경하면 결제 가능 여부가 `True`로 바뀌는가?
- 회원 여부를 `False`로 변경하면 회원 혜택 대상 여부가 `False`로 바뀌는가?
- 비교 연산자와 논리 연산자를 사용해 참·거짓을 판단했는가?
