# 6.7. While

**조건이 참인 동안 반복하기**

카페에서 주문 금액을 차례로 입력받아 합계를 구한다고 가정해 봅시다. 주문이 몇 건 들어올지는 미리 알 수 없지만, 입력이 끝났다는 뜻으로 0을 받을 수는 있습니다. 이처럼 계속할 조건을 정해 두고 작업을 반복할 때 `while`문을 쓸 수 있습니다.

## 6.7.1. 조건을 확인한 뒤 실행하기

`while` 뒤에 조건을 쓰고 콜론(`:`)을 붙입니다. 반복할 코드는 공백 네 칸을 들여씁니다.

```text
while (조건):
    (코드1)
(코드2)
```

> 조건이 참인 동안 코드1을 반복합니다. 매 차례 코드1을 실행하기 전에 조건을 다시 검사합니다. 조건이 거짓이면 반복을 마치고 코드2를 실행합니다.

첫 검사에서 조건이 거짓이면 코드1은 한 번도 실행되지 않습니다.

## 6.7.2. 조건에 쓰이는 값 바꾸기

3부터 1까지 거꾸로 세어 봅시다. 처음에 `count`를 3으로 정하고, 숫자 하나를 출력할 때마다 1을 뺍니다.

```python
count = 3

while count > 0:
    print(count)
    count -= 1

print("시작!")
```

**실행 결과**

```text
3
2
1
시작!
```

  <thead>
    <tr><th>검사할 때의 <code>count</code></th><th><code>count &gt; 0</code></th><th>하는 일</th></tr>
  </thead>
  <tbody>
    <tr><td>3</td><td>참</td><td>3을 출력한 뒤 2로 바꿉니다.</td></tr>
    <tr><td>2</td><td>참</td><td>2를 출력한 뒤 1로 바꿉니다.</td></tr>
    <tr><td>1</td><td>참</td><td>1을 출력한 뒤 0으로 바꿉니다.</td></tr>
    <tr><td>0</td><td>거짓</td><td>반복을 마치고 시작 안내를 출력합니다.</td></tr>
  </tbody>
</table>

처음부터 `count = 0`으로 설정하면 `시작!`만 출력됩니다. 반대로 `count -= 1`을 빼면 `count`가 3으로 유지되어 반복이 끝나지 않습니다. 이처럼 조건이 계속 참이어서 반복이 끝나지 않는 것을 **무한 반복**(**Infinite Loop**)이라고 합니다.

> 이 예제는 6.3절의 `for count in range(3, 0, -1):`로도 작성할 수 있습니다. `for`는 다음 숫자를 하나씩 꺼내고, 위 `while`문에서는 코드를 실행할 때마다 `count`를 직접 줄입니다.

## 6.7.3. 0을 입력할 때까지 합계 구하기

6.2절에서는 리스트에 담겨 있는 숫자를 더했습니다. 이번에는 주문 금액을 한 번에 하나씩 입력받습니다. 금액은 양의 정수로 입력하고, 입력을 마칠 때만 0을 넣는다고 가정합니다.

```python
total = 0
amount = int(input("주문 금액 (끝내려면 0): "))

while amount != 0:
    total += amount
    amount = int(input("주문 금액 (끝내려면 0): "))

print(f"합계: {total:,}원")
```

**실행 예시**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
```

첫 입력은 조건을 검사하기 전에 받습니다. 0이 아니라면 합계에 더하고, 다음 금액을 입력받아 `amount`에 저장합니다. 0을 입력하면 다음 검사에서 `amount != 0`이 거짓이 되므로 0을 더하는 줄까지 가지 않고 합계를 출력합니다. 처음부터 0을 입력하면 합계는 0원입니다.
