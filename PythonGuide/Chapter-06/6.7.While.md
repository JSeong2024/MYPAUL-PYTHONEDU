# 6.7. While

**While 문**

카페에서 주문 금액을 하나씩 입력받아 전체 주문 금액의 합계를 구한다고 가정해 봅시다. 주문이 모두 몇 건 들어올지는 미리 알 수 없지만, 모든 입력이 끝났다는 신호로 `0`을 입력받을 수는 있습니다.

6.2절부터 살펴본 `for` 문은 주로 자료구조에 저장된 항목이나 일정한 범위의 숫자를 순서대로 다룰 때 사용합니다. 반면 `while` 문은 특정 조건이 참인 동안 작업을 계속 반복할 때 사용합니다.

이번 절에서는 `while` 문의 기본 구조와 동작 원리를 살펴보고, 사용자 입력에 따라 반복을 종료하는 프로그램을 작성해 봅시다.

## 6.7.1. 조건을 확인한 뒤 실행하기

`while` 키워드 뒤에 조건식을 작성하고 콜론(`:`)을 붙입니다. 조건이 참인 동안 반복해서 실행할 코드는 공백 네 칸을 들여써서 작성합니다.

```text
while (조건):
    (코드1)
(코드2)
```

`while` 문은 다음과 같은 순서로 동작합니다.

1. 조건식을 평가하여 참(`True`)인지 거짓(`False`)인지 확인합니다.
2. 조건식이 참이면 반복문 내부의 `(코드1)`을 실행합니다.
3. `(코드1)`의 실행이 끝나면 다시 조건식을 평가합니다.
4. 조건식이 참인 동안 위 과정을 반복합니다.
5. 조건식이 거짓이면 반복을 종료하고 반복문 바깥의 `(코드2)`를 실행합니다.

`while` 문은 반복문 내부의 코드를 실행하기 전에 조건식을 먼저 평가합니다. 따라서 처음부터 조건식이 거짓이라면 `(코드1)`은 한 번도 실행되지 않습니다.

> `while` 문은 반복문 내부의 코드를 실행하는 도중에 조건식을 계속 검사하는 것이 아니라, 새로운 반복을 시작하기 직전에 조건식을 평가합니다.

## 6.7.2. 조건에 쓰이는 값 바꾸기

`3`부터 `1`까지 숫자를 거꾸로 세는 프로그램을 작성해 봅시다. 먼저 `count` 변수의 초깃값을 `3`으로 설정하고, 숫자를 하나 출력할 때마다 `count`의 값을 `1`씩 감소시킵니다.

`count`가 `0`보다 큰 동안 숫자를 계속 출력하고, 반복이 끝나면 `시작!`을 출력하도록 작성합니다.

```python
count = 3

while count > 0:
    print(count)
    count -= 1

print("시작!")
```

**실행 결과**

```text
3
2
1
시작!
```

먼저 `count > 0`이라는 조건식을 평가합니다. `count`의 초깃값은 `3`이므로 조건식이 참이 되어 반복문 내부의 코드를 실행합니다.

현재 `count`의 값을 출력한 뒤 `count -= 1`을 실행하여 값을 `1`만큼 감소시킵니다. 이후 다시 조건식을 평가하고, 같은 과정을 반복합니다.

`count`의 값이 `0`이 되면 다음 조건 검사에서 `count > 0`이 거짓으로 평가됩니다. 따라서 반복문을 종료하고, 반복문 바깥에 작성된 `print("시작!")`을 실행합니다.

만약 처음부터 `count = 0`으로 설정하면 첫 번째 조건 검사에서 거짓으로 평가되므로 반복문 내부의 코드는 한 번도 실행되지 않고 `시작!`만 출력됩니다.

### 무한 반복

반복문 안에서 `count -= 1`을 작성하지 않으면 어떻게 될까요?

`count`의 값이 계속 `3`으로 유지되므로 `count > 0`은 항상 참으로 평가됩니다. 결국 반복문이 종료되지 않고 숫자 `3`을 계속 출력하게 됩니다.

이처럼 종료되지 않고 계속 실행되는 반복을 **무한 반복**(**Infinite Loop**)이라고 합니다.

`while` 문을 작성할 때는 다음 사항을 확인하는 것이 좋습니다.

- 반복을 시작하기 전에 조건식에 사용할 변수를 적절한 값으로 초기화했는지 확인합니다.
- 반복문 내부에서 조건식에 사용되는 값이 적절하게 변경되는지 확인합니다.
- 원하는 시점에 반복을 종료할 수 있는지 확인합니다.

> 무한 반복이 항상 잘못된 것은 아닙니다. 사용자 입력을 계속 기다리거나 프로그램의 상태를 지속적으로 확인해야 하는 경우에는 의도적으로 무한 반복을 사용하기도 합니다. 이러한 반복을 제어하는 방법은 6.8절에서 살펴보겠습니다.

> 의도하지 않은 무한 반복으로 프로그램이 종료되지 않는다면 터미널에서 `Ctrl + C`를 눌러 실행을 중단할 수 있습니다.

이 예제는 6.3절에서 배운 `for count in range(3, 0, -1):`를 사용하여 동일한 출력 결과를 얻을 수도 있습니다.

`for` 문은 `range()`에서 다음 숫자를 순서대로 꺼내지만, 이 예제의 `while` 문은 반복문 내부에서 `count`의 값을 직접 변경하여 종료 조건에 도달하도록 한다는 차이가 있습니다.

## 6.7.3. 0을 입력할 때까지 합계 구하기

6.2절에서는 리스트에 저장된 숫자를 하나씩 꺼내 합계를 구했습니다. 이번에는 미리 준비된 리스트 없이 사용자에게 주문 금액을 하나씩 입력받아 합계를 구해 보겠습니다.

주문이 몇 건 들어올지는 미리 알 수 없으므로 반복 횟수를 정하기 어렵습니다. 대신 사용자가 `0`을 입력하기 전까지 주문 금액을 계속 더하도록 `while` 문을 사용합니다.

이 예제에서는 주문 금액으로 양의 정수를 입력하며, 모든 주문 금액의 입력을 마쳤을 때만 `0`을 입력한다고 가정합니다.

```python
total = 0
amount = int(input("주문 금액 (끝내려면 0): "))

while amount != 0:
    total += amount
    amount = int(input("주문 금액 (끝내려면 0): "))

print(f"합계: {total:,}원")
```

**실행 예시**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
```

먼저 주문 금액의 합계를 저장할 변수 `total`을 `0`으로 초기화합니다. 이후 첫 번째 주문 금액을 입력받아 `amount`에 저장합니다.

`while` 문은 반복문 내부의 코드를 실행하기 전에 조건식을 평가하므로, `amount != 0`을 검사할 수 있도록 첫 번째 주문 금액을 반복문 바깥에서 미리 입력받습니다.

입력받은 금액이 `0`이 아니라면 `total += amount`를 실행하여 현재 주문 금액을 합계에 더합니다. 이후 다음 주문 금액을 입력받아 `amount`에 저장하고, 다시 조건식을 평가합니다.

사용자가 `4800`, `2500`, `0`을 차례로 입력했을 때 각 변수의 값은 다음과 같이 바뀝니다.

사용자가 `0`을 입력하면 다음 조건 검사에서 `amount != 0`이 거짓으로 평가됩니다. 따라서 반복문 내부의 코드를 실행하지 않고 반복을 종료한 뒤 최종 합계를 출력합니다.

처음부터 `0`을 입력한다면 반복문이 한 번도 실행되지 않으므로 `total`은 초깃값인 `0`으로 유지되고, 합계는 `0원`으로 출력됩니다.

> 이 예제에서 `0`은 실제로 더해야 할 주문 금액이 아니라 입력이 끝났음을 나타내는 값입니다. 이처럼 입력이나 반복의 종료를 알리기 위해 사용하는 특별한 값을 **센티널 값**(**Sentinel Value**)이라고 합니다.

반복문 내부에 다음 주문 금액을 입력받는 코드가 있다는 점에도 주목해 보세요. 이 코드가 없다면 `amount`에 처음 입력받은 금액이 계속 남아 있게 됩니다. 처음 입력한 금액이 `0`이 아니라면 종료 조건에 도달하지 못하고 같은 금액을 계속 더하는 무한 반복이 발생합니다.

### `for` 문과 `while` 문 비교하기

`for` 문과 `while` 문은 모두 작업을 반복해서 실행하기 위한 제어문이지만, 반복을 진행하고 종료하는 방식에 차이가 있습니다.

  </thead>
  <tbody>

      <td align="center">반복 기준</td>
      <td align="left">순회할 대상</td>
      <td align="left">조건식</td>
    </tr>
    <tr>
      <td align="center">주로 사용하는 상황</td>
      <td align="left">자료의 항목을 하나씩 처리할 때</td>
      <td align="left">특정 조건이 유지되는 동안 작업할 때</td>
    </tr>

    </tr>
    <tr>
      <td align="center">활용 예시</td>

      <td align="left">사용자 입력, 상태 확인</td>
    </tr>

> 반복 횟수를 미리 알 수 있는 경우에는 `for` 문이 편리하며, 사용자 입력이나 상태 변화에 따라 반복을 종료해야 하는 경우에는 `while` 문이 적합한 경우가 많습니다. 다만 반복 횟수를 알고 있어도 `while` 문을 사용할 수 있으며, `for` 문의 반복 횟수를 항상 미리 알아야 하는 것은 아닙니다. 프로그램의 목적과 반복 조건에 따라 적절한 반복문을 선택하세요.

## 확인 문제

1. 6.7.2절의 코드에서 `count = 2`로 시작하면 어떤 내용이 차례대로 출력될까요?
2. 6.7.2절의 코드에서 `count -= 1`을 `print(count)`보다 먼저 실행하도록 순서를 바꾸면, `count = 3`일 때 어떤 숫자가 차례대로 출력될까요?
3. 6.7.3절의 프로그램을 실행하고 `1200`, `800`, `0`을 차례로 입력하면 최종 합계는 얼마가 출력될까요?
4. 다음 코드에서 무한 반복이 발생하는 이유를 설명하고, 숫자 `1`부터 `5`까지 출력한 뒤 반복이 종료되도록 코드를 수정해 보세요.

   ```python
   number = 1

   while number <= 5:
       print(number)
   ```
