# 6.5. Loops with Data Structures

**리스트와 딕셔너리 순회하기**

플레이리스트에서는 노래 제목을 하나씩 꺼냈습니다. 카페 가격표에서는 메뉴 이름만 꺼낼 수도 있고, 메뉴 이름과 가격을 한 쌍으로 꺼낼 수도 있습니다. `for`에서 값을 꺼낼 대상을 바꾸어 어떤 값이 나오는지 살펴봅시다.

## 6.5.1. 리스트에서 항목 하나씩 꺼내기

6.2절에서 사용한 플레이리스트를 다시 순회해 봅시다.

```python
playlist = ["with", "Santa Baby", "Angel Bite", "with"]

for title in playlist:
    print(title)
```

**실행 결과**

```text
with
Santa Baby
Angel Bite
with
```

> `playlist`에서 노래 제목을 하나씩 꺼내 `title`에 넣고 출력합니다. `"with"`가 목록에 두 번 들어 있으므로 두 번 출력합니다.

## 6.5.2. 딕셔너리에서 키 하나씩 꺼내기

4.3절의 카페 가격표에서는 메뉴 이름이 키이고 가격이 값입니다. 딕셔너리를 `in` 뒤에 바로 쓰면 **키**를 하나씩 꺼냅니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

for item in menu:
    print(item)
```

**실행 결과**

```text
커피
쿠키
```

첫 번째 차례에 `item`은 `"커피"`, 두 번째 차례에는 `"쿠키"`입니다. 가격도 필요하면 `menu[item]`으로 현재 메뉴의 가격을 읽을 수 있습니다.

## 6.5.3. `items()`로 키와 값을 함께 꺼내기

메뉴 이름과 가격을 모두 쓴다면 `items()`로 **키와 값의 쌍**을 하나씩 꺼냅니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

for key, value in menu.items():
    print(f"{key}: {value:,}원")
```

**실행 결과**

```text
커피: 4,800원
쿠키: 2,500원
```

> `menu.items()`에서 한 쌍을 꺼낼 때마다 첫 번째 값은 `key`에, 두 번째 값은 `value`에 넣습니다. 그 두 값으로 들여쓴 코드를 한 번 실행합니다.

<table align="center">
  <thead>
    <tr><th>반복 차례</th><th>꺼낸 쌍</th><th><code>key</code></th><th><code>value</code></th></tr>
  </thead>
  <tbody>
    <tr><td>첫 번째</td><td><code>("커피", 4800)</code></td><td><code>"커피"</code></td><td><code>4800</code></td></tr>
    <tr><td>두 번째</td><td><code>("쿠키", 2500)</code></td><td><code>"쿠키"</code></td><td><code>2500</code></td></tr>
  </tbody>
</table>

`key`와 `value`는 직접 정하는 변수 이름입니다. 이 예제에서는 `for item, price in menu.items():`라고 쓰고, 출력하는 줄에도 같은 이름을 쓰면 코드에서 메뉴 이름과 가격을 바로 알아볼 수 있습니다.

> `{value:,}`에서 `:` 뒤에 출력 형식을 적습니다. `,`는 세 자리마다 쉼표를 넣으므로 `4800`이 `4,800`으로 표시됩니다.

## 6.5.4. `values()`로 값만 꺼내기

가격표의 메뉴를 종류별로 하나씩 장바구니에 담는다고 가정해 봅시다. 총액을 구할 때는 메뉴 이름 없이 가격만 필요합니다.

```python
menu = {"커피": 4800, "쿠키": 2500}
total = 0

for price in menu.values():
    total += price

print(f"합계: {total:,}원")
```

**실행 결과**

```text
합계: 7,300원
```

<table align="center">
  <thead>
    <tr><th>필요한 정보</th><th><code>in</code> 뒤에 쓸 코드</th><th>한 차례에 꺼내는 값</th></tr>
  </thead>
  <tbody>
    <tr><td>메뉴 이름</td><td><code>menu</code></td><td>키 하나</td></tr>
    <tr><td>가격</td><td><code>menu.values()</code></td><td>값 하나</td></tr>
    <tr><td>메뉴 이름과 가격</td><td><code>menu.items()</code></td><td>키와 값 한 쌍</td></tr>
  </tbody>
</table>

## 확인 문제

1. 플레이리스트 예제에서 `"with"`는 몇 번 출력될까요?
2. `menu = {"차": 3000, "주스": 4500}`일 때 `for item in menu:`로 꺼내는 값은 무엇일까요?
3. 2번 가격표에서 `items()`로 이름과 가격을 꺼내고, 4,000원 이상인 메뉴의 이름만 출력해 보세요.
4. 6.5.4의 가격표에 `"물": 0`을 추가하면 `values()`에서 꺼내는 값은 몇 개이고, 합계는 얼마일까요?

<details>
<summary>정답 확인</summary>

1. 두 번 출력됩니다.
2. `"차"`, `"주스"`를 순서대로 꺼냅니다.
3. `for item, price in menu.items():` 안에 `if price >= 4000:`을 쓰고, 그 안에서 `print(item)`을 실행합니다. 주스만 출력됩니다.
4. 가격은 세 개를 꺼내며, 합계는 7,300원입니다.

</details>
