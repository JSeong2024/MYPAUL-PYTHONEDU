# 6.5. Loops with Data Structures

**리스트와 딕셔너리 순회하기**

6.2절에서는 `for` 문을 사용해 플레이리스트에 저장된 노래 제목을 하나씩 꺼내 보았습니다. 카페의 가격표처럼 딕셔너리로 구성된 자료에서는 메뉴 이름만 꺼내거나, 가격만 꺼내거나, 메뉴 이름과 가격을 한 쌍으로 꺼낼 수도 있습니다.

이처럼 자료구조에 저장된 항목을 하나씩 방문하는 과정을 **순회**(**Traversal**)라고 합니다. 이번 절에서는 리스트와 딕셔너리를 순회하는 방법과 각 메서드에 따라 어떤 값이 꺼내지는지 살펴보겠습니다.

## 6.5.1. 리스트에서 항목 하나씩 꺼내기

6.2절에서 사용한 플레이리스트를 다시 한번 순회해 보겠습니다. `for` 문의 `in` 뒤에 리스트를 작성하면 리스트에 저장된 항목을 처음부터 마지막까지 순서대로 꺼냅니다.

```python
playlist = ["with", "Santa Baby", "Angel Bite", "with"]

for title in playlist:
    print(title)
```

**실행 결과**

```text
with
Santa Baby
Angel Bite
with
```

`playlist`에서 노래 제목을 하나씩 꺼내 `title` 변수에 저장한 뒤 출력합니다. 리스트에 저장된 항목이 네 개이므로 반복문은 총 네 번 실행됩니다.

> 리스트는 중복된 항목을 허용합니다. 따라서 `"with"`처럼 동일한 항목이 여러 번 저장되어 있다면 반복문에서도 저장된 횟수만큼 해당 항목을 꺼냅니다.

## 6.5.2. 딕셔너리에서 키 하나씩 꺼내기

4.3절에서 사용한 카페 가격표를 살펴보겠습니다. 이 딕셔너리에서는 메뉴 이름이 **키**(**Key**)이고, 가격이 **값**(**Value**)입니다.

`for` 문의 `in` 뒤에 딕셔너리를 그대로 작성하면 딕셔너리에 저장된 키를 하나씩 꺼냅니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

for item in menu:
    print(item)
```

**실행 결과**

```text
커피
쿠키
```

첫 번째 반복에서는 `item`에 `"커피"`가 저장되고, 두 번째 반복에서는 `"쿠키"`가 저장됩니다. 딕셔너리는 항목이 추가된 순서를 유지하므로 키도 해당 순서대로 꺼내집니다.

현재 메뉴의 가격도 확인하고 싶다면 `menu[item]`처럼 대괄호(`[]`) 안에 키를 넣어 해당 키에 연결된 값을 가져올 수 있습니다.

> `for item in menu:`와 `for item in menu.keys():`는 동일한 키를 같은 순서로 꺼냅니다. 딕셔너리를 순회할 때는 기본적으로 키를 꺼내므로 `keys()` 메서드를 생략하여 작성하는 경우가 많습니다.

## 6.5.3. `items()`로 키와 값을 함께 꺼내기

카페의 가격표를 출력하려면 메뉴 이름뿐만 아니라 가격도 필요합니다. 이처럼 키와 값을 모두 사용해야 할 때는 딕셔너리의 `items()` 메서드를 사용합니다.

`items()` 메서드를 사용하면 딕셔너리에 저장된 키와 값을 한 쌍씩 꺼낼 수 있습니다. 각 쌍은 `(키, 값)` 형태의 튜플로 구성되며, `for` 문을 통해 순서대로 꺼낼 수 있습니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

for key, value in menu.items():
    print(f"{key}: {value:,}원")
```

**실행 결과**

```text
커피: 4,800원
쿠키: 2,500원
```

`menu.items()`를 순회하면서 키와 값의 쌍을 하나씩 꺼냅니다. 각 튜플의 첫 번째 요소인 키는 `key`에, 두 번째 요소인 값은 `value`에 각각 저장됩니다. 이후 두 변수를 사용하여 메뉴 이름과 가격을 출력합니다.

각 반복에서 꺼내는 항목과 변수에 저장되는 값은 다음과 같습니다.

<table align="center">
  <thead>
    <tr><th>반복 차례</th><th>꺼낸 쌍</th><th><code>key</code></th><th><code>value</code></th></tr>
  </thead>
  <tbody>
    <tr><td>첫 번째</td><td><code>("커피", 4800)</code></td><td><code>"커피"</code></td><td><code>4800</code></td></tr>
    <tr><td>두 번째</td><td><code>("쿠키", 2500)</code></td><td><code>"쿠키"</code></td><td><code>2500</code></td></tr>
  </tbody>
</table>

> 튜플이나 리스트처럼 여러 요소가 묶여 있는 자료에서 각 요소를 개별 변수에 나누어 할당하는 것을 **언패킹**(**Unpacking**)이라고 합니다. 이 예제에서는 키와 값으로 구성된 튜플을 두 변수에 나누어 저장합니다.

`key`와 `value`는 정해진 이름이 아니라 개발자가 직접 지정하는 변수 이름입니다. 따라서 `for item, price in menu.items():`처럼 저장되는 값의 의미가 드러나는 이름을 사용할 수도 있습니다. 이때 출력문에서도 변경한 변수 이름을 사용해야 합니다.

변수의 역할을 쉽게 파악할 수 있도록 저장되는 값에 어울리는 이름을 사용하는 습관을 들여 보세요.

> f-문자열의 `{value:,}`에서 콜론(`:`) 뒤에는 값의 출력 형식을 지정합니다. 쉼표(`,`)를 사용하면 정수 부분에 세 자리마다 천 단위 구분 기호를 표시할 수 있습니다. 예를 들어 `4800`은 `4,800`으로 출력되며, 변수에 저장된 실제 값은 변경되지 않습니다.

## 6.5.4. `values()`로 값만 꺼내기

카페의 가격표에 등록된 모든 메뉴를 하나씩 구매한다고 가정해 보겠습니다. 총 결제 금액을 계산할 때는 메뉴 이름이 아닌 가격만 필요합니다. 이처럼 딕셔너리에 저장된 값만 꺼내고 싶을 때는 `values()` 메서드를 사용합니다.

```python
menu = {"커피": 4800, "쿠키": 2500}
total = 0

for price in menu.values():
    total += price

print(f"합계: {total:,}원")
```

**실행 결과**

```text
합계: 7,300원
```

먼저 총 결제 금액을 저장할 변수 `total`을 `0`으로 초기화합니다. 이후 `menu.values()`에서 가격을 하나씩 꺼내 `price`에 저장하고, `total += price`를 통해 현재 가격을 누적하여 더합니다.

첫 번째 반복에서는 `4800`을 더하고, 두 번째 반복에서는 `2500`을 더합니다. 모든 반복이 끝나면 `total`에는 전체 메뉴 가격의 합인 `7300`이 저장됩니다.

> 딕셔너리는 중복된 키를 허용하지 않지만, 서로 다른 키에 동일한 값을 저장할 수 있습니다. 따라서 가격이 같은 메뉴가 여러 개 있더라도 `values()`는 각 메뉴의 가격을 모두 꺼냅니다.

> 모든 가격의 합계만 구하고 싶다면 `sum(menu.values())`를 사용하여 반복문을 직접 작성하지 않고도 같은 결과를 얻을 수 있습니다.

<table align="center">
  <thead>
    <tr><th>필요한 정보</th><th><code>in</code> 뒤에 쓸 코드</th><th>한 차례에 꺼내는 값</th></tr>
  </thead>

    <tr><td>메뉴 이름</td><td><code>menu</code></td><td>키 하나</td></tr>

## 확인 문제

1. 6.5.1절의 플레이리스트 예제에서 `"with"`는 모두 몇 번 출력될까요?
2. `menu = {"차": 3000, "주스": 4500}`일 때 `for item in menu:`로 순회하면 어떤 값이 어떤 순서로 꺼내질까요?
3. 2번 문제의 가격표에서 `items()`를 사용하여 메뉴 이름과 가격을 함께 꺼내고, 가격이 4,000원 이상인 메뉴의 이름만 출력하는 코드를 작성해 보세요.
4. 6.5.4절의 가격표에 `"물": 0`이라는 항목을 추가한 뒤 같은 반복문을 실행하면 `values()`를 통해 꺼내는 값은 모두 몇 개이고, 최종 합계는 얼마가 출력될까요?

<details>
<summary>정답 확인</summary>

1. `"with"`가 리스트에 두 번 저장되어 있으므로 **두 번** 출력됩니다.

2. 딕셔너리를 그대로 순회하면 키를 꺼냅니다. 따라서 `"차"`, `"주스"`를 순서대로 꺼냅니다.

3. `items()`를 사용해 메뉴 이름과 가격을 각각 `item`과 `price`에 저장합니다. 이후 `if` 문을 사용하여 가격이 4,000원 이상인지 확인하고, 조건을 만족하는 메뉴의 이름만 출력합니다.

   ```python
   menu = {"차": 3000, "주스": 4500}

   for item, price in menu.items():
       if price >= 4000:
           print(item)
   ```

   **실행 결과**

   ```text
   주스
   ```

4. 딕셔너리에 저장된 항목이 세 개이므로 총 **세 개**의 값(`4800`, `2500`, `0`)을 꺼냅니다. `0`을 더해도 합계는 변하지 않으므로 최종 합계는 `7,300원`입니다.
