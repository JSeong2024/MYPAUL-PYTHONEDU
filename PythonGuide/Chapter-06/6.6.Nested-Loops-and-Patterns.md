# 6.6. Nested Loops & Patterns

**중첩 반복문과 패턴 그리기**

6.3절에서는 줄 번호에 따라 별의 개수를 늘려 계단 모양을 그려 보았습니다. 이번에는 줄마다 공백과 별의 개수를 일정한 규칙에 따라 바꾸어 피라미드를 그려 보겠습니다.

이어서 반복문 안에 또 다른 반복문을 작성하는 방법을 알아보고, 이를 활용해 2차원 격자의 각 칸을 순서대로 확인하면서 원하는 위치에 별을 배치해 봅시다.

## 6.6.1. 줄마다 공백과 별의 개수 정하기

높이가 3인 피라미드를 그리려면 첫 번째 줄에 공백 두 칸과 별 하나를 배치해야 합니다. 한 줄씩 아래로 내려갈 때마다 별 앞에 오는 공백은 하나씩 줄어들고, 별은 두 개씩 늘어납니다.

각 줄에 필요한 공백과 별의 개수를 정리하면 다음과 같습니다.

<table align="center">
  <thead>
    <tr><th>줄 번호</th><th>앞 공백</th><th>별</th></tr>
  </thead>
  <tbody>
    <tr><td>1</td><td>2</td><td>1</td></tr>
    <tr><td>2</td><td>1</td><td>3</td></tr>
    <tr><td>3</td><td>0</td><td>5</td></tr>
  </tbody>
</table>

피라미드의 높이와 줄 번호를 이용하면 각 줄에 필요한 공백과 별의 개수를 다음과 같이 계산할 수 있습니다.

| 구분 | 계산 방법 | Python 표현식 |
| :---: | :---: | :---: |
| 앞 공백의 개수 | 전체 높이 - 줄 번호 | `height - row` |
| 별의 개수 | 줄 번호 × 2 - 1 | `2 * row - 1` |

이 규칙을 이용하면 피라미드의 높이가 달라지더라도 같은 코드로 원하는 크기의 피라미드를 그릴 수 있습니다. 다음 예제에서는 높이로 1 이상의 정수를 입력한다고 가정합니다.

```python
height = int(input("높이: "))

for row in range(1, height + 1):
    spaces = height - row
    stars = 2 * row - 1
    print(" " * spaces + "*" * stars)
```

**실행 예시**

```text
높이: 3
  *
 ***
*****
```

`range(1, height + 1)`을 사용하여 `row`가 `1`부터 `height`까지 순서대로 바뀌도록 합니다. 각 반복에서는 현재 줄 번호를 기준으로 공백의 개수(`spaces`)와 별의 개수(`stars`)를 계산합니다.

`" " * spaces`로 공백 문자열을 만들고, `"*" * stars`로 별 문자열을 만듭니다. 두 문자열을 `+` 연산자로 연결한 뒤 `print()`로 출력하면 피라미드의 한 줄이 완성됩니다.

> 문자열에 `0`을 곱하면 빈 문자열(`""`)이 만들어집니다. 따라서 마지막 줄에서는 `spaces`가 `0`이 되므로 별 앞에 공백이 추가되지 않습니다.

> Python에서는 문자열 반복 연산을 사용하여 여러 문자를 한 번에 생성할 수 있습니다. 따라서 각 줄의 공백과 별을 하나씩 출력하기 위한 별도의 반복문을 작성하지 않아도 됩니다.

## 6.6.2. 중첩 반복문으로 행과 열 살펴보기

반복문 안에 또 다른 반복문을 작성하는 구조를 **중첩 반복문**(**Nested Loop**)이라고 합니다.

중첩 반복문은 영화관 좌석표나 바둑판처럼 가로와 세로로 구성된 2차원 자료를 처리할 때 유용하게 사용할 수 있습니다.

영화관 좌석표를 위에서부터 한 줄씩, 왼쪽에서 오른쪽으로 한 칸씩 확인한다고 생각해 보세요. 가로 방향으로 나열된 한 줄을 **행**(**Row**), 세로 방향으로 나열된 한 줄을 **열**(**Column**)이라고 합니다.

바깥 반복문에서 행을 하나씩 선택하고, 안쪽 반복문에서 해당 행의 각 열을 순서대로 확인하면 모든 좌석의 위치를 빠짐없이 확인할 수 있습니다.

```python
for row in range(1, 3):
    for col in range(1, 4):
        print(f"{row}행 {col}열")
```

**실행 결과**

```text
1행 1열
1행 2열
1행 3열
2행 1열
2행 2열
2행 3열
```

바깥 반복문의 `row`에 `1`이 저장되면 안쪽 반복문이 시작됩니다. 안쪽 반복문에서는 `col`이 `1`, `2`, `3`으로 순서대로 바뀌며 각 칸의 위치를 출력합니다.

안쪽 반복문이 모두 끝나면 바깥 반복문의 다음 반복이 시작됩니다. 이때 `row`는 `2`가 되고, 안쪽 반복문은 처음부터 다시 실행되므로 `col` 역시 `1`부터 시작합니다.

각 변수의 값이 바뀌는 순서를 정리하면 다음과 같습니다.

| 실행 순서 | `row` | `col` | 실행 결과 |
| :---: | :---: | :---: | :---: |
| 1 | 1 | 1 | 1행 1열 |
| 2 | 1 | 2 | 1행 2열 |
| 3 | 1 | 3 | 1행 3열 |
| 4 | 2 | 1 | 2행 1열 |
| 5 | 2 | 2 | 2행 2열 |
| 6 | 2 | 3 | 2행 3열 |

> 안쪽 반복문은 바깥 반복문이 한 번 반복될 때마다 처음부터 끝까지 실행됩니다. 이 예제에서는 바깥 반복문이 2번 반복되고, 매번 안쪽 반복문이 3번씩 반복되므로 `print()`는 총 2 × 3 = 6번 실행됩니다.

중첩 반복문을 작성할 때는 들여쓰기에 특히 주의해야 합니다. 이 예제에서 안쪽 `for` 문은 공백 네 칸, 안쪽 반복문에 속한 `print()` 문은 공백 여덟 칸을 들여씁니다.

| 들여쓰기 | 코드가 속한 위치 | 실행 시점 |
| :---: | :---: | :---: |
| 공백 0칸 | 두 반복문 바깥 | 반복문과 별도로 실행 |
| 공백 4칸 | 바깥 반복문 내부 | 행마다 한 번 |
| 공백 8칸 | 안쪽 반복문 내부 | 각 칸마다 한 번 |

안쪽 반복문이 끝난 직후 행마다 한 번씩 실행할 코드가 있다면, 안쪽 `for` 문과 같은 깊이인 공백 네 칸을 들여써서 작성합니다.

## 6.6.3. 테두리와 가운데에 별 놓기

중첩 반복문과 조건문을 함께 사용하면 특정 위치에만 원하는 문자를 배치할 수 있습니다.

5×5 크기의 정사각형 격자를 그린다고 가정해 보겠습니다. 격자의 각 칸은 행 번호와 열 번호로 위치를 나타낼 수 있습니다.

별을 배치할 위치는 다음과 같은 규칙으로 정합니다.

- 첫 번째 행 또는 마지막 행에 해당하는 칸
- 첫 번째 열 또는 마지막 열에 해당하는 칸
- 정가운데인 `3행 3열`에 해당하는 칸

첫 번째와 두 번째 규칙을 만족하는 칸은 사각형의 테두리를 구성하고, 세 번째 규칙을 만족하는 칸은 사각형의 중심에 해당합니다. 이외의 칸은 모두 공백으로 채웁니다.

```python
size = 5
center = 3

for row in range(1, size + 1):
    line = ""

    for col in range(1, size + 1):
        on_border = (
            row == 1 or row == size or col == 1 or col == size
        )
        at_center = row == center and col == center

        if on_border or at_center:
            line += "*"
        else:
            line += " "

    print(line)
```

**실행 결과**

```text
*****
*   *
* * *
*   *
*****
```

먼저 `size`에는 사각형의 크기를, `center`에는 가운데에 해당하는 행과 열의 번호를 저장합니다.

바깥 반복문에서는 행 번호인 `row`를 하나씩 변경하고, 안쪽 반복문에서는 열 번호인 `col`을 하나씩 변경하면서 현재 칸의 위치를 확인합니다.

### 별을 배치할 위치 판단하기

5.2절에서 배운 논리 연산자 `or`와 `and`를 사용하여 현재 칸이 테두리 또는 정가운데에 해당하는지 판단합니다.

`on_border`에는 현재 칸이 테두리에 해당하는지 판단한 결과를 저장합니다. 첫 번째 행, 마지막 행, 첫 번째 열, 마지막 열 중 하나라도 해당하면 `True`가 됩니다.

`at_center`에는 현재 칸이 정가운데에 해당하는지 판단한 결과를 저장합니다. 행 번호와 열 번호가 모두 `center`와 같아야 하므로 `and` 연산자를 사용합니다.

두 변수 중 하나라도 `True`이면 별을 추가하고, 두 변수 모두 `False`이면 공백을 추가합니다.

<table align="center">
  <thead>
    <tr><th>위치</th><th>테두리인가요?</th><th>정가운데인가요?</th><th>붙이는 문자</th></tr>
  </thead>
  <tbody>
    <tr><td>1행 3열</td><td>예</td><td>아니요</td><td>별</td></tr>
    <tr><td>2행 3열</td><td>아니요</td><td>아니요</td><td>공백</td></tr>
    <tr><td>3행 3열</td><td>아니요</td><td>예</td><td>별</td></tr>
  </tbody>
</table>

> 조건식을 `on_border`와 `at_center`라는 두 변수로 나누어 작성하면 각 조건이 무엇을 판단하는지 쉽게 파악할 수 있습니다. 복잡한 조건식을 작성할 때는 의미에 따라 조건을 나누고, 그 결과를 변수에 저장하여 활용하는 방법도 좋습니다.

### 한 줄씩 완성하여 출력하기

`line`은 현재 행에 배치할 별과 공백을 저장하는 문자열 변수입니다. 새로운 행을 시작할 때마다 `line = ""`을 실행하여 빈 문자열로 초기화합니다.

안쪽 반복문에서는 각 칸의 조건을 검사하고, 그 결과에 따라 별(`"*"`)이나 공백(`" "`)을 `line`에 하나씩 연결합니다.

예를 들어 두 번째 행을 구성하는 과정은 다음과 같습니다.

| 열 번호 | 추가하는 문자 | `line`에 저장된 문자열 |
| :---: | :---: | :---: |
| 초기 상태 | - | `""` |
| 1 | 별 | `"*"` |
| 2 | 공백 | `"* "` |
| 3 | 공백 | `"*  "` |
| 4 | 공백 | `"*   "` |
| 5 | 별 | `"*   *"` |

안쪽 반복문이 끝나면 현재 행에 해당하는 다섯 칸이 모두 채워집니다. 이후 `print(line)`을 실행하여 완성된 문자열을 한 줄에 출력합니다.

`print(line)`은 안쪽 반복문 바깥에 있지만 바깥 반복문 안에 속하므로 행마다 한 번씩 실행됩니다. 이러한 과정을 다섯 번 반복하면 5×5 크기의 사각형이 완성됩니다.

> `line = ""`을 바깥 반복문보다 앞에 작성하면 새로운 행이 시작되어도 이전 행의 문자열이 남아 있게 됩니다. 반대로 안쪽 반복문에 작성하면 칸을 하나 확인할 때마다 문자열이 초기화됩니다. 이처럼 중첩 반복문에서는 변수를 초기화하는 위치에 따라 실행 결과가 달라질 수 있습니다.

## 확인 문제

1. 6.6.1절의 코드에서 높이 `4`를 입력하면 두 번째 줄과 마지막 줄에 공백과 별이 각각 몇 개씩 들어갈까요?
2. 6.6.2절의 코드에서 바깥 반복문의 범위를 `range(1, 4)`로 바꾸면 총 몇 줄이 출력될까요?
3. 6.6.3절의 코드에서 정가운데의 별을 제외하고 테두리에만 별을 배치하려면 `if` 문의 조건식을 어떻게 바꾸어야 할까요?
4. 6.6.3절의 코드에서 사각형의 크기를 `7`로 바꾸고 정가운데에도 별을 배치하려면 `center` 변수의 값을 얼마로 바꾸어야 할까요?

<details>
<summary>정답 확인</summary>

1. 공백의 개수는 `height - row`, 별의 개수는 `2 * row - 1`로 계산합니다.

   | 줄 번호 | 공백의 개수 | 별의 개수 |
   | :---: | :---: | :---: |
   | 두 번째 줄 | 4 - 2 = 2 | 2 × 2 - 1 = 3 |
   | 마지막 줄 | 4 - 4 = 0 | 2 × 4 - 1 = 7 |

   따라서 두 번째 줄에는 공백 **2개**와 별 **3개**, 마지막 줄에는 공백 **0개**와 별 **7개**가 들어갑니다.

2. 바깥 반복문이 3번 반복되고, 매번 안쪽 반복문이 3번씩 반복됩니다. 따라서 `3 × 3 = 9`줄이 출력됩니다.

3. 정가운데를 판단하는 `at_center` 조건을 제외하고 `on_border` 조건만 확인하도록 변경합니다.

   ```python
   if on_border:
       line += "*"
   else:
       line += " "
   ```

   **실행 결과**

   ```text
   *****
   *   *
   *   *
   *   *
   *****
   ```

4. 행과 열의 번호가 `1`부터 `7`까지이므로 정가운데에 해당하는 번호는 `4`입니다. 따라서 `center = 4`로 변경하면 됩니다.

   사각형의 크기가 홀수라면 `//` 연산자를 사용하여 가운데에 해당하는 번호를 자동으로 계산할 수도 있습니다.

   ```python
   center = size // 2 + 1
   ```

   이렇게 작성하면 `size`의 값을 변경할 때마다 가운데 번호를 직접 수정할 필요가 없습니다.
