# 6.6. Nested Loops & Patterns

**중첩 반복문과 패턴 그리기**

6.3절에서는 줄 번호만큼 별을 출력해 계단을 그렸습니다. 이번에는 줄마다 공백과 별의 개수를 바꾸어 피라미드를 그립니다. 그다음 사각형의 각 칸을 하나씩 살펴보며 어느 위치에 별을 놓을지 정합니다.

## 6.6.1. 줄마다 공백과 별의 개수 정하기

높이가 3인 피라미드를 그리려면 첫 줄에 공백 두 칸과 별 하나가 필요합니다. 한 줄 내려갈 때마다 앞 공백은 하나 줄고, 별은 두 개 늘어납니다.

<table align="center">
  <thead>
    <tr><th>줄 번호</th><th>앞 공백</th><th>별</th></tr>
  </thead>
  <tbody>
    <tr><td>1</td><td>2</td><td>1</td></tr>
    <tr><td>2</td><td>1</td><td>3</td></tr>
    <tr><td>3</td><td>0</td><td>5</td></tr>
  </tbody>
</table>

앞 공백은 높이에서 줄 번호를 빼면 됩니다. 별은 줄 번호의 두 배에서 1을 빼면 됩니다. 높이는 1 이상의 정수를 입력한다고 가정합니다.

```python
height = int(input("높이: "))

for row in range(1, height + 1):
    spaces = height - row
    stars = 2 * row - 1
    print(" " * spaces + "*" * stars)
```

**실행 예시**

```text
높이: 3
  *
 ***
*****
```

> `" " * spaces`로 앞 공백을 만들고, `"*" * stars`로 별을 만듭니다. 두 문자열을 이어 붙인 뒤 한 줄로 출력합니다. 한 줄을 통째로 만들 수 있으므로 이 예제에서는 `for`문 하나로 충분합니다.

## 6.6.2. 중첩 반복문으로 행과 열 살펴보기

반복문 안에 또 다른 반복문을 넣는 구조를 **중첩 반복문**(**Nested Loop**)이라고 합니다. 좌석표를 한 칸씩 읽는다고 생각해 보세요. 바깥 반복문에서 행 하나를 고르면, 안쪽 반복문에서 그 행의 열을 처음부터 끝까지 확인합니다.

```python
for row in range(1, 3):
    for col in range(1, 4):
        print(f"{row}행 {col}열")
```

**실행 결과**

```text
1행 1열
1행 2열
1행 3열
2행 1열
2행 2열
2행 3열
```

> 바깥쪽에서 `row`에 1을 넣으면 안쪽에서 `col`이 1, 2, 3으로 바뀝니다. 다음 행으로 넘어가면 `row`는 2가 되고 `col`은 다시 1부터 시작합니다.

이 예제에서는 안쪽 `for`를 공백 네 칸, 그 안의 `print()`를 공백 여덟 칸 들여씁니다. 안쪽 반복문이 끝난 직후에 행마다 한 번 실행할 코드가 있다면, 안쪽 `for`와 같은 깊이에 씁니다.

## 6.6.3. 테두리와 가운데에 별 놓기

5×5 사각형에서 현재 칸이 첫 행이나 마지막 행, 첫 열이나 마지막 열에 있으면 테두리입니다. `3행 3열`에는 가운데 별을 놓습니다. 나머지 칸은 공백으로 채웁니다.

```python
size = 5
center = 3

for row in range(1, size + 1):
    line = ""

    for col in range(1, size + 1):
        on_border = (
            row == 1 or row == size or col == 1 or col == size
        )
        at_center = row == center and col == center

        if on_border or at_center:
            line += "*"
        else:
            line += " "

    print(line)
```

**실행 결과**

```text
*****
*   *
* * *
*   *
*****
```

`line = ""`은 새 행을 시작할 때마다 한 번 실행합니다. 안쪽 반복문에서 칸마다 별이나 공백을 붙이고, 그 행의 다섯 칸을 모두 채우면 `print(line)`을 실행합니다. `print(line)`은 안쪽 반복문 밖에 있지만 바깥 반복문에는 속하므로 **행마다 한 번** 실행됩니다.

## 확인 문제

1. 6.6.1에서 높이 4를 입력하면 둘째 줄과 마지막 줄에 앞 공백과 별이 각각 몇 개 들어갈까요?
2. 6.6.2에서 바깥 반복문을 `range(1, 4)`로 바꾸면 총 몇 줄이 출력될까요?
3. 6.6.3에서 정가운데 별을 빼고 테두리만 출력하려면 `if` 조건을 어떻게 바꾸면 될까요?
4. 크기를 7로 바꾸고 정가운데에도 별을 놓으려면 `center`를 얼마로 바꾸면 될까요?

<details>
<summary>정답 확인</summary>

1. 둘째 줄에는 앞 공백 2개와 별 3개, 마지막 줄에는 앞 공백 0개와 별 7개가 들어갑니다.
2. 3개 행마다 3개 열을 확인하므로 총 9줄입니다.
3. `if on_border:`로 바꾸면 됩니다.
4. 한 행이나 열의 번호가 1부터 7까지이므로 가운데 번호는 4입니다. `center = 4`로 바꿉니다.
