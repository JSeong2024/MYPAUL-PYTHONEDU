# 6.8. Loop Control

**반복문의 실행 흐름 제어하기**

주문 목록에서 특정 주문 번호를 검색한다고 가정해 봅시다. 찾으려는 주문 번호를 발견했다면 목록의 나머지 항목을 확인하지 않고 검색을 종료할 수 있습니다. 반면 취소된 주문을 발견했다면 해당 주문만 건너뛰고 나머지 주문은 계속 확인해야 합니다.

이처럼 반복문을 즉시 종료하거나 현재 반복에서 남은 코드의 실행을 건너뛰는 등 반복문의 실행 흐름을 직접 제어하는 것을 **반복 제어**(**Loop Control**)라고 합니다.

Python에서는 `break`와 `continue` 키워드를 사용하여 반복문의 실행 흐름을 제어할 수 있습니다. 두 키워드는 `for` 문과 `while` 문에서 모두 사용할 수 있으며, 주로 조건문과 함께 사용합니다.

## 6.8.1. `break` — 반복문 끝내기

`break`는 현재 실행 중인 반복문을 즉시 종료하는 키워드입니다. 아직 처리하지 않은 항목이 남아 있거나 반복문의 조건식이 참이더라도 `break`를 실행하면 반복을 종료합니다.

주문 번호를 앞에서부터 하나씩 확인하다가 찾으려는 주문 번호를 발견하면 검색을 종료하는 프로그램을 작성해 봅시다.

```python
orders = [101, 104, 108, 112]
target = 108

for order in orders:
    print(f"확인: {order}")

    if order == target:
        print(f"{target}번 주문을 찾았습니다.")
        break

print("검색을 마쳤습니다.")
```

**실행 결과**

```text
확인: 101
확인: 104
확인: 108
108번 주문을 찾았습니다.
검색을 마쳤습니다.
```

`orders`에는 확인할 주문 번호를 저장하고, `target`에는 찾으려는 주문 번호를 저장합니다.

`for` 문을 사용하여 주문 번호를 하나씩 꺼낸 뒤 현재 주문 번호가 `target`과 같은지 확인합니다. 두 값이 같으면 주문을 찾았다는 안내 문구를 출력하고 `break`를 실행합니다.

`108`번 주문을 찾은 시점에 반복문이 종료되므로 뒤에 남아 있는 `112`번 주문은 확인하지 않습니다. 반복문을 빠져나온 뒤에는 반복문 바깥에 작성된 `print("검색을 마쳤습니다.")`를 실행합니다.

만약 찾으려는 주문 번호가 목록에 없다면 `order == target`이 한 번도 참이 되지 않으므로 `break`는 실행되지 않습니다. 이 경우 목록의 모든 주문 번호를 확인한 뒤 반복문이 정상적으로 종료됩니다.

> `break`는 프로그램 전체를 종료하는 것이 아니라 현재 실행 중인 반복문을 종료하는 키워드입니다. 따라서 반복문 바깥에 작성된 코드는 계속 실행됩니다.

### 중첩 반복문에서의 `break`

6.6절에서 배운 중첩 반복문에서 `break`를 사용하면 자신을 직접 감싸고 있는 가장 안쪽 반복문 하나만 종료됩니다.

```python
for row in range(1, 4):
    for col in range(1, 4):
        if col == 3:
            break

        print(f"{row}행 {col}열")
```

**실행 결과**

```text
1행 1열
1행 2열
2행 1열
2행 2열
3행 1열
3행 2열
```

안쪽 반복문에서 `col`이 `3`이 되면 `break`를 실행합니다. 이때 안쪽 반복문만 종료되므로 바깥 반복문은 다음 행으로 넘어가 계속 실행됩니다.

따라서 모든 행에서 첫 번째 열과 두 번째 열의 위치만 출력됩니다.

> 중첩 반복문에서 `break`를 한 번 실행한다고 해서 모든 반복문이 동시에 종료되는 것은 아닙니다.

## 6.8.2. `continue` — 이번 차례의 남은 코드 건너뛰기

`continue`는 현재 반복에서 아직 실행하지 않은 코드를 건너뛰고 다음 반복으로 넘어가는 키워드입니다.

`break`와 달리 반복문 자체를 종료하지 않으므로 이후에 처리할 항목이 남아 있다면 반복을 계속 진행합니다.

이번에는 전체 주문 목록에서 취소된 주문만 제외하고, 정상적으로 처리할 주문 번호를 출력하는 프로그램을 작성해 봅시다.

```python
orders = [101, 104, 108, 112]
cancelled = [104, 112]

for order in orders:
    if order in cancelled:
        continue

    print(f"처리할 주문: {order}")

print("주문 확인을 마쳤습니다.")
```

**실행 결과**

```text
처리할 주문: 101
처리할 주문: 108
주문 확인을 마쳤습니다.
```

`orders`에는 전체 주문 번호를 저장하고, `cancelled`에는 취소된 주문 번호를 저장합니다.

`for` 문에서 주문 번호를 하나씩 꺼낼 때마다 `in` 연산자를 사용하여 현재 주문 번호가 취소 목록에 포함되어 있는지 확인합니다.

취소된 주문이라면 `continue`를 실행하여 현재 반복에서 남은 코드인 `print()` 문을 건너뜁니다. 취소된 주문이 아니라면 주문 번호를 출력합니다.

이후 목록에서 더 이상 꺼낼 항목이 없으므로 반복문을 정상적으로 종료하고 `주문 확인을 마쳤습니다.`를 출력합니다.

> `continue`는 현재 반복에서 아직 실행하지 않은 코드만 건너뜁니다. `continue`보다 앞에서 이미 실행한 코드에는 영향을 주지 않습니다.

## 6.8.3. `while`에서 종료 신호로 빠져나오기

6.7.3절에서는 사용자가 `0`을 입력할 때까지 주문 금액을 계속 더하는 프로그램을 작성했습니다. 당시에는 첫 번째 주문 금액을 입력받는 코드와 다음 주문 금액을 입력받는 코드를 반복문 안팎에 각각 작성했습니다.

이번에는 `while True`와 `break`를 사용하여 입력 코드를 한 곳에 작성하고, 반복문 내부에서 종료 여부를 판단하는 구조로 변경해 보겠습니다.

6.7.3절과 마찬가지로 주문 금액은 양의 정수로 입력하며, 모든 입력을 마칠 때만 `0`을 입력한다고 가정합니다.

```python
total = 0

while True:
    amount = int(input("주문 금액 (끝내려면 0): "))

    if amount == 0:
        break

    total += amount

print(f"합계: {total:,}원")
```

**실행 예시**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
```

`while True`는 조건식이 항상 참이므로 조건 검사만으로는 반복이 종료되지 않습니다. 대신 반복문 내부에 조건문과 `break`를 작성하여 원하는 시점에 반복을 종료할 수 있습니다.

이 프로그램은 다음과 같은 순서로 동작합니다.

1. 주문 금액을 입력받아 `amount`에 저장합니다.
2. 입력받은 금액이 `0`인지 확인합니다.
3. `0`이면 `break`를 실행하여 반복문을 종료합니다.
4. `0`이 아니면 현재 주문 금액을 `total`에 더합니다.
5. 다시 첫 번째 단계로 돌아가 다음 주문 금액을 입력받습니다.

사용자가 `4800`, `2500`, `0`을 차례로 입력했을 때 각 변수의 값과 실행 흐름은 다음과 같습니다.

사용자가 `0`을 입력하면 `break`를 실행하므로 그 아래에 작성된 `total += amount`는 실행되지 않습니다. 반복문을 빠져나온 뒤에는 최종 합계를 출력합니다.

이처럼 `while True`와 `break`를 함께 사용하면 반복문 내부에서 값을 입력받고, 그 값에 따라 반복을 종료할 수 있습니다. 동일한 입력 코드를 여러 곳에 작성하지 않아도 되므로 프로그램의 구조를 간결하게 구성할 수 있습니다.

> `while True`를 사용할 때는 어떤 조건에서 반복을 종료할 것인지 명확하게 정해야 합니다. 종료 조건에 도달하지 못하거나 `break`가 실행되지 않으면 반복이 계속될 수 있습니다.

## 6.8.4. `while`에서 `continue`를 사용할 때 주의할 점

`for` 문에서 `continue`를 실행하면 다음 항목을 가져오는 단계로 이동합니다. 반면 `while` 문에서 `continue`를 실행하면 조건식을 다시 검사하는 단계로 이동합니다.

6.7.2절에서 살펴본 것처럼 `while` 문에서는 조건식에 사용되는 변수의 값을 직접 변경해야 하는 경우가 있습니다. 이때 `continue`의 위치에 따라 변수의 값을 변경하는 코드가 실행되지 않을 수 있으므로 주의해야 합니다.

다음은 숫자 `1`부터 `5`까지 확인하면서 짝수를 제외하고 홀수만 출력하는 프로그램입니다.

```python
number = 0

while number < 5:
    number += 1

    if number % 2 == 0:
        continue

    print(number)
```

**실행 결과**

```text
1
3
5
```

먼저 `number += 1`을 실행하여 현재 숫자를 증가시킵니다. 이후 나머지 연산자 `%`를 사용하여 현재 숫자가 짝수인지 확인합니다.

숫자를 `2`로 나눈 나머지가 `0`이라면 짝수이므로 `continue`를 실행하여 출력을 건너뜁니다. 홀수라면 `print(number)`를 실행합니다.

이 예제에서는 `number += 1`을 `continue`보다 먼저 실행하므로 짝수를 만났을 때도 숫자가 정상적으로 증가합니다.

반대로 다음과 같이 숫자를 증가시키는 코드를 `continue`보다 아래에 작성하면 문제가 발생할 수 있습니다.

```python
number = 1

while number <= 5:
    if number % 2 == 0:
        continue

    print(number)
    number += 1
```

처음에는 `1`을 출력하고 `number`의 값을 `2`로 증가시킵니다. 그러나 다음 반복에서는 `number`가 짝수이므로 `continue`를 실행합니다.

이때 `number += 1`까지 건너뛰게 되므로 `number`는 계속 `2`로 유지됩니다. 이후에도 같은 조건을 반복해서 검사하기 때문에 더 이상 숫자를 출력하지 못하고 무한 반복이 발생합니다.

> `while` 문에서 `continue`를 사용할 때는 반복 종료에 필요한 변수의 값이 정상적으로 변경되는지 확인해야 합니다. 의도하지 않은 무한 반복이 발생하면 터미널에서 `Ctrl + C`를 눌러 실행을 중단할 수 있습니다.

## 확인 문제

1. 다음 코드에서 `target = 104`로 변경하면 어떤 주문 번호까지 확인한 뒤 검색을 마칠까요?

   ```python
   orders = [101, 104, 108, 112]
   target = 108

   for order in orders:
       print(f"확인: {order}")

       if order == target:
           print(f"{target}번 주문을 찾았습니다.")
           break

   print("검색을 마쳤습니다.")
   ```

2. 다음 코드에서 `continue`를 `break`로 변경하면 화면에 어떤 주문 번호가 출력될까요?

   ```python
   orders = [101, 104, 108, 112]
   cancelled = [104, 112]

   for order in orders:
       if order in cancelled:
           continue

       print(f"처리할 주문: {order}")

   print("주문 확인을 마쳤습니다.")
   ```

3. 다음 프로그램을 실행하고 첫 번째 주문 금액으로 `0`을 입력하면 합계는 얼마가 출력될까요?

   ```python
   total = 0

   while True:
       amount = int(input("주문 금액 (끝내려면 0): "))

       if amount == 0:
           break

       total += amount

   print(f"합계: {total:,}원")
   ```

4. 다음 중첩 반복문에서 `break`를 `continue`로 변경하면 실행 결과가 달라질까요? 그 이유도 함께 설명해 보세요.

   ```python
   for row in range(1, 4):
       for col in range(1, 4):
           if col == 3:
               break

           print(f"{row}행 {col}열")
   ```

5. 다음 코드를 실행하면 어떤 숫자가 차례대로 출력될까요?

   ```python
   for number in range(1, 8):
       if number == 6:
           break

       if number % 2 == 0:
           continue

       print(number)
   ```

6. 다음 코드를 실행하면 숫자 `1`이 출력된 뒤 무한 반복이 발생합니다. 무한 반복이 발생하는 이유를 설명하고, 숫자 `1`, `3`, `5`를 차례대로 출력한 뒤 반복문이 종료되도록 코드를 수정해 보세요.

   ```python
   number = 1

   while number <= 5:
       if number % 2 == 0:
           continue

       print(number)
       number += 1
   ```
