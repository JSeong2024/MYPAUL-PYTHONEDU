# 6.8. Loop Control

**반복 끝내기와 이번 차례 건너뛰기**

주문 목록에서 찾던 주문이 나오면 검색을 끝낼 수 있습니다. 반면 취소된 주문을 만났을 때는 그 주문만 건너뛰고 다음 주문을 확인해야 합니다. 반복을 끝낼 때는 `break`, 이번 차례만 건너뛸 때는 `continue`를 사용합니다.

## 6.8.1. `break` — 반복문 끝내기

주문 번호를 하나씩 읽다가 찾던 번호가 나오면 `break`를 실행합니다.

```python
orders = [101, 104, 108, 112]
target = 108

for order in orders:
    print(f"확인: {order}")

    if order == target:
        print(f"{target}번 주문을 찾았습니다.")
        break

print("검색을 마쳤습니다.")
```

**실행 결과**

```text
확인: 101
확인: 104
확인: 108
108번 주문을 찾았습니다.
검색을 마쳤습니다.
```

> 만약 현재 주문 번호가 찾는 번호와 같다면, 찾았다는 안내를 출력하고 반복을 끝냅니다.

108번을 찾은 뒤에는 112번을 확인하지 않습니다. 그다음 실행하는 줄은 반복문 밖의 `print("검색을 마쳤습니다.")`입니다. 6.6절처럼 반복문이 중첩되어 있다면 `break`는 자신을 감싸는 가장 가까운 반복문 하나만 끝냅니다.

## 6.8.2. `continue` — 이번 차례의 남은 코드 건너뛰기

이번에는 취소된 주문만 건너뛰고, 처리할 주문 번호를 출력합니다.

```python
orders = [101, 104, 108, 112]
cancelled = [104, 112]

for order in orders:
    if order in cancelled:
        continue

    print(f"처리할 주문: {order}")

print("주문 확인을 마쳤습니다.")
```

**실행 결과**

```text
처리할 주문: 101
처리할 주문: 108
주문 확인을 마쳤습니다.
```

> 만약 현재 주문이 취소 목록에 들어 있다면 이번 차례의 남은 코드를 건너뛰고 다음 주문을 확인합니다.

104번은 취소된 주문이므로 출력하는 줄을 건너뜁니다. 다음 차례에는 108번을 확인하고 출력합니다. 마지막 주문인 112번을 건너뛴 뒤에는 꺼낼 주문이 없으므로 반복을 마칩니다.

## 6.8.3. `while`에서 종료 신호로 빠져나오기

6.7절에서는 0을 입력할 때까지 주문 금액을 더했습니다. 이번에는 금액을 입력받는 코드를 반복문 안에 두고, 0을 입력하면 `break`로 반복을 끝냅니다. 주문 금액은 양의 정수로 입력하고, 입력을 마칠 때는 0을 넣는다고 가정합니다.

```python
total = 0

while True:
    amount = int(input("주문 금액 (끝내려면 0): "))

    if amount == 0:
        break

    total += amount

print(f"합계: {total:,}원")
```

**실행 예시**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
```

`while True`의 조건은 매번 참입니다. 여기서는 0을 읽으면 `break`를 실행하므로, 합계에 더하는 줄을 지나지 않고 반복문 밖의 출력으로 이동합니다.

> `while`에서 `continue`를 실행하면 곧바로 조건을 다시 검사합니다. 반복을 끝내는 데 필요한 값 변경이 `continue`보다 아래에 있으면, 그 줄을 건너뛰면서 같은 값으로 반복할 수 있습니다.

## 확인 문제

1. 6.8.1절에서 `target = 104`로 바꾸면 어떤 주문 번호까지 확인할까요?
2. 6.8.2절에서 `continue`를 `break`로 바꾸면 처리할 주문으로 무엇이 출력될까요?
3. 6.8.3절에서 첫 금액으로 0을 입력하면 합계는 얼마일까요?

<details>
<summary>정답 확인</summary>

1. 101번과 104번을 확인합니다. 104번을 찾으면 `break`로 반복을 끝냅니다.
2. 101번만 출력합니다. 104번을 만나면 반복이 끝나므로 108번까지 가지 않습니다.
3. 합계는 0원입니다. 처음 입력한 값에서 바로 `break`가 실행됩니다.
