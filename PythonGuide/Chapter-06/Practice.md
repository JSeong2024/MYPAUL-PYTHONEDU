# Chapter 06. Practice

Chapter 06에서 배운 반복문을 활용하여 다양한 문제를 해결해 봅시다. `for` 문과 `while` 문을 사용해 데이터를 처리하고, 조건문과 `break`, `continue`를 함께 활용하여 반복문의 실행 흐름을 제어해 보세요.

## Exercise 01. 짝수의 합과 개수 구하기

리스트에 저장된 숫자를 하나씩 꺼내고, 그중 짝수만 골라 합계와 개수를 구하는 프로그램을 작성하세요.

**시작 코드**

```python
numbers = [3, 12, 0, 7, 8, 5]
total = 0
count = 0

# 짝수의 합과 개수를 구합니다.
```

**요구사항**

1. `for` 문을 사용하여 `numbers`에 저장된 숫자를 하나씩 꺼냅니다.
2. 조건문과 나머지 연산자(`%`)를 사용하여 현재 숫자가 짝수인지 판단합니다.
3. 짝수라면 해당 숫자를 `total`에 더하고, `count`의 값을 1만큼 증가시킵니다.
4. 모든 숫자를 확인한 뒤 짝수의 합계와 개수를 출력합니다.

**실행 결과**

```text
짝수의 합: 20
짝수의 개수: 3
```

> 숫자 `0`도 `2`로 나눈 나머지가 `0`이므로 짝수입니다. 합계에는 영향을 주지 않지만 짝수의 개수에는 포함해야 합니다.

## Exercise 02. 가운데 정렬 피라미드 그리기

사용자로부터 피라미드의 높이를 입력받아 별(`*`)로 구성된 피라미드를 그리는 프로그램을 작성하세요.

첫 번째 줄에는 별 하나를 배치하고, 한 줄씩 아래로 내려갈 때마다 별 앞의 공백은 한 칸씩 줄이고 별은 두 개씩 늘립니다. 입력값은 1 이상의 정수라고 가정합니다.

**시작 코드**

```python
height = int(input("높이: "))

# 한 줄씩 공백과 별의 개수를 정해 출력합니다.
```

**요구사항**

1. `for` 문과 `range()`를 사용하여 입력받은 높이만큼 반복합니다.
2. 현재 줄 번호에 따라 별 앞에 배치할 공백의 개수를 계산합니다.
3. 현재 줄 번호에 따라 별의 개수를 계산합니다.
4. 문자열 반복 연산자(`*`)와 연결 연산자(`+`)를 사용하여 공백과 별을 하나의 문자열로 구성합니다.
5. 완성된 문자열을 한 줄씩 출력합니다.

**실행 예시 1**

```text
높이: 3
  *
 ***
*****
```

**실행 예시 2**

```text
높이: 5
    *
   ***
  *****
 *******
*********
```

**실행 예시 3**

```text
높이: 1
*
```

> 피라미드의 높이와 현재 줄 번호를 이용하여 공백과 별의 개수를 계산해 보세요. 높이가 달라지더라도 동일한 규칙을 적용할 수 있어야 합니다.

## Exercise 03. 판매 가능한 메뉴 골라 출력하기

카페에서는 재고가 부족하여 일부 메뉴를 판매하지 못하는 경우가 있습니다. 손님이 4,000원 이하의 메뉴를 찾고 있다고 가정하고, 가격표에서 품절되지 않은 메뉴 중 조건에 맞는 메뉴의 이름과 가격을 출력하는 프로그램을 작성하세요.

**시작 코드**

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000, "주스": 4000}
sold_out = ["쿠키"]

# 판매 가능한 메뉴 중 4,000원 이하인 항목을 출력합니다.
```

**요구사항**

1. 딕셔너리의 `items()` 메서드를 사용하여 메뉴 이름과 가격을 한 쌍씩 꺼냅니다.
2. 현재 메뉴가 품절 목록인 `sold_out`에 포함되어 있는지 확인합니다.
3. 품절된 메뉴라면 `continue`를 사용하여 다음 메뉴로 넘어갑니다.
4. 품절되지 않은 메뉴 중 가격이 4,000원 이하인 메뉴만 출력합니다.
5. f-문자열을 사용하여 가격에 천 단위 구분 기호를 표시합니다.

**실행 결과**

```text
차: 3,000원
주스: 4,000원
```

> 가격이 4,000원 이하인 메뉴를 찾는 것이므로 가격이 정확히 4,000원인 메뉴도 출력 대상에 포함해야 합니다. 쿠키는 가격 조건을 만족하지만 품절된 메뉴이므로 출력하지 않습니다.

## Mini Project. 카페 주문 금액 집계하기

카페에서 여러 주문을 받다 보면 전체 주문 금액과 주문 건수를 확인해야 하는 경우가 있습니다. 주문이 들어올 때마다 금액을 기록하고, 모든 주문의 입력이 끝나면 합계와 주문 건수를 출력하는 프로그램을 만들어 봅시다.

주문이 몇 건 들어올지는 미리 알 수 없으므로 `while` 문을 사용하여 주문 금액을 반복해서 입력받습니다. 잘못된 금액이 입력되었을 때는 해당 입력을 처리하지 않고 다시 입력받도록 구성합니다.

이번 프로젝트에서는 사용자가 정수를 입력한다고 가정합니다.

### 시작 코드

```python
total = 0
count = 0

# 주문 금액을 입력받아 합계와 건수를 계산합니다.
```

`total`은 전체 주문 금액의 합계를 저장하는 변수이고, `count`는 정상적으로 입력된 주문의 건수를 저장하는 변수입니다.

### 요구사항

1. `while` 문을 사용하여 주문 금액을 반복해서 입력받습니다.
2. 입력받은 금액이 `0`이면 `break`를 실행하여 반복문을 종료합니다.
3. 입력받은 금액이 음수이면 `양의 금액을 입력하세요.`라는 안내 문구를 출력하고, `continue`를 실행하여 다음 입력으로 넘어갑니다.
4. 입력받은 금액이 양수이면 해당 금액을 `total`에 더하고, `count`의 값을 1만큼 증가시킵니다.
5. 반복문이 종료되면 전체 주문 금액과 주문 건수를 출력합니다.
6. 전체 주문 금액은 천 단위 구분 기호와 함께 출력합니다.

### 실행 예시

**실행 예시 1 — 정상적인 주문과 잘못된 입력이 함께 있는 경우**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): -100
양의 금액을 입력하세요.
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
주문 건수: 2건
```

음수인 `-100`은 합계와 주문 건수에 반영하지 않습니다. 따라서 정상적으로 입력된 `4800`과 `2500`만 합계에 포함되며, 주문 건수는 2건입니다.

**실행 예시 2 — 주문 없이 입력을 종료하는 경우**

```text
주문 금액 (끝내려면 0): 0
합계: 0원
주문 건수: 0건
```

첫 번째 입력으로 `0`을 입력하면 주문을 기록하지 않고 반복문을 종료합니다.

**실행 예시 3 — 잘못된 금액을 여러 번 입력하는 경우**

```text
주문 금액 (끝내려면 0): -100
양의 금액을 입력하세요.
주문 금액 (끝내려면 0): -500
양의 금액을 입력하세요.
주문 금액 (끝내려면 0): 3000
주문 금액 (끝내려면 0): 0
합계: 3,000원
주문 건수: 1건
```

음수를 여러 번 입력하더라도 합계와 주문 건수는 증가하지 않아야 합니다.
