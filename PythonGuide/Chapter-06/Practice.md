## Exercise 01. 짝수의 합과 개수 구하기

리스트에서 숫자를 하나씩 꺼내고, 짝수만 골라 합계와 개수를 구하세요. `total`과 `count`는 반복을 시작하기 전에 0으로 정합니다. 숫자 0도 짝수이므로 개수에 포함합니다.

```python
numbers = [3, 12, 0, 7, 8, 5]
total = 0
count = 0

# 짝수의 합과 개수를 구합니다.
```

**실행 결과**

```text
짝수의 합: 20
짝수의 개수: 3
```

## Exercise 02. 가운데 정렬 피라미드 그리기

높이를 입력받아 별 피라미드를 그리세요. 높이는 1 이상의 정수로 가정합니다. 첫 줄에는 별 하나를 놓고, 한 줄 내려갈 때마다 앞 공백을 한 칸 줄이고 별을 두 개 늘립니다. 높이가 1이면 별 하나만 출력합니다.

```python
height = int(input("높이: "))

# 한 줄씩 공백과 별의 개수를 정해 출력합니다.
```

**실행 예시**

```text
높이: 3
  *
 ***
*****
```

## Exercise 03. 영업 시간에 판매할 메뉴 골라 출력하기

가격표에서 이름과 가격을 한 쌍씩 꺼내세요. 품절된 메뉴는 `continue`로 건너뛰고, 가격이 4,000원 이하인 메뉴만 가격과 함께 출력합니다. 4,000원인 메뉴도 포함합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000, "주스": 4000}
sold_out = ["쿠키"]

# 판매 가능한 메뉴 중 4,000원 이하인 항목을 출력합니다.
```

**실행 결과**

```text
차: 3,000원
주스: 4,000원
```

## Mini Project. 카페 주문 금액 집계하기

주문 금액을 하나씩 입력받습니다. 손님이 몇 건을 주문할지 미리 알 수 없으므로 0이 들어올 때까지 입력을 받습니다. 입력값은 정수로 가정합니다.

**시작 코드**

```python
total = 0
count = 0

# 주문 금액을 입력받아 합계와 건수를 계산합니다.
```

**요구사항**

1. `while`로 금액을 반복해서 입력받는다.
2. 금액이 0이면 `break`로 반복을 끝낸다.
3. 금액이 음수이면 안내 문구를 출력하고 `continue`로 이번 입력을 건너뛴다.
4. 금액이 양수이면 합계에 더하고 주문 건수를 1 늘린다.
5. 반복이 끝나면 합계와 주문 건수를 출력한다.

**실행 예시**

```text
주문 금액 (끝내려면 0): 4800
주문 금액 (끝내려면 0): -100
양의 금액을 입력하세요.
주문 금액 (끝내려면 0): 2500
주문 금액 (끝내려면 0): 0
합계: 7,300원
주문 건수: 2건
```

첫 입력부터 0이면 합계는 0원, 주문 건수는 0건입니다. 음수를 여러 번 입력해도 합계와 건수는 증가하지 않습니다.
