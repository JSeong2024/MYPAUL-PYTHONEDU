# 6.2. For

**`for`문**

플레이리스트에 담긴 노래 제목을 화면에 한 줄씩 표시하려고 합니다. 노래마다 `print()` 함수를 한 줄씩 일일이 적어도 되지만, 목록이 길어질수록 코드도 그만큼 길어지고 수정하기도 번거로워집니다. 이때 `for`문을 사용하면 목록에서 노래를 하나씩 꺼낼 때마다 동일한 출력 코드를 자동으로 반복 실행할 수 있습니다.

## 6.2.1. 값을 하나씩 꺼내기

`for` 뒤에는 꺼낸 값을 임시로 담을 변수 이름을, `in` 뒤에는 값을 꺼낼 대상을 적습니다. 그리고 조건문과 마찬가지로 줄 끝에는 반드시 콜론(`:`)을 붙입니다.

```text
for (변수) in (값을 꺼낼 대상):
    (코드1)
(코드2)
```

> 값을 하나 꺼내 `변수`에 저장한 뒤, 그 값을 이용해 `코드1`을 실행합니다. 실행이 끝나면 다음 값을 꺼내 같은 과정을 되풀이합니다. 더 이상 꺼낼 값이 없으면 반복을 종료하고 반복문 바깥의 `코드2`를 실행합니다.

같은 작업을 여러 번 되풀이할 때 그 한 차례의 실행을 **반복**(**Iteration**)이라고 합니다. 또한 리스트처럼 여러 값이 모여 있는 대상에서 항목을 처음부터 끝까지 차례대로 살펴보는 과정을 **순회**(**Traversal**)라고 합니다.

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)

print("출력을 마쳤습니다.")
```

**실행 결과**

```text
10
20
30
출력을 마쳤습니다.
```

  <thead>
    <tr><th>반복 차례</th><th><code>number</code>에 들어가는 값</th><th>실행되는 줄</th></tr>
  </thead>
  <tbody>
    <tr><td>첫 번째</td><td>10</td><td><code>print(number)</code></td></tr>
    <tr><td>두 번째</td><td>20</td><td><code>print(number)</code></td></tr>
    <tr><td>세 번째</td><td>30</td><td><code>print(number)</code></td></tr>
  </tbody>
</table>

변수 `number`에는 위치 번호인 인덱스 `0`, `1`, `2`가 아니라, 각 자리에 들어 있는 실제 값 `10`, `20`, `30`이 차례대로 담깁니다. 마지막 줄의 `print("출력을 마쳤습니다.")`는 `for`와 같은 들여쓰기 깊이에 있으므로 반복문이 모두 끝난 뒤 딱 한 번만 실행됩니다.

> 반복 변수(`number`)의 이름은 자유롭게 지을 수 있지만, 리스트 이름의 단수형(`numbers` → `number`, `items` → `item`)처럼 꺼낸 값의 의미를 잘 나타내는 이름을 사용하면 코드를 읽고 이해하기 훨씬 쉬워집니다.

## 6.2.2. 들여쓰기로 반복할 범위 정하기

반복해서 실행할 코드가 여러 줄이라면 모든 줄을 같은 깊이(공백 네 칸)로 들여씁니다. 아래 예제에서는 플레이리스트에서 노래를 하나 꺼낼 때마다 노래 제목과 구분선을 한 세트로 함께 출력합니다.

```python
playlist = ["with", "Santa Baby", "Angel Bite", "with"]

for title in playlist:
    print(title)
    print("---")

print("목록을 다 읽었습니다.")
```

**실행 결과**

```text
with
---
Santa Baby
---
Angel Bite
---
with
---
목록을 다 읽었습니다.
```

플레이리스트에는 `"with"`가 첫 번째와 네 번째 자리에 각각 들어 있으므로 순서대로 두 번 출력됩니다. 만약 `playlist`를 빈 리스트(`[]`)로 바꾸면 꺼낼 값이 하나도 없으므로 들여쓴 두 줄은 단 한 번도 실행되지 않습니다. 반면 마지막 안내 문구는 반복문 바깥에 있으므로 빈 리스트일 때도 정상적으로 출력됩니다.

## 6.2.3. 누적합 구하기

이번에는 리스트의 숫자를 하나씩 꺼내면서 지금까지 더한 값을 누적해 기록해 봅시다. 합계를 저장할 변수 `total`은 반복을 시작하기 전에 반드시 `0`으로 초기화해야 합니다.

```python
numbers = [10, 20, 30]
total = 0

for number in numbers:
    total += number

print(f"합계: {total}")
```

**실행 결과**

```text
합계: 60
```

`total += number`는 `total = total + number`를 줄여 쓴 복합 대입 연산자입니다. 지금까지 누적된 합계(`total`)에 이번에 새로 꺼낸 숫자(`number`)를 더한 뒤, 그 결과를 다시 `total` 변수에 덮어씁니다.

<table align="center">
  <thead>
    <tr><th>차례</th><th>더하기 전</th><th>이번에 더한 수</th><th>더한 뒤</th></tr>
  </thead>
  <tbody>
    <tr><td>첫 번째</td><td>0</td><td>10</td><td>10</td></tr>
    <tr><td>두 번째</td><td>10</td><td>20</td><td>30</td></tr>
    <tr><td>세 번째</td><td>30</td><td>30</td><td>60</td></tr>
  </tbody>
</table>

만약 `total = 0`을 반복문 안쪽에 넣고 매번 더하기 직전에 실행하면, 이전 차례까지 쌓아 둔 합계가 매 반복마다 `0`으로 초기화되어 사라집니다. 그 결과 이 예제에서는 마지막 숫자인 `30`만 남게 되므로 초기화 위치에 주의해야 합니다.

> 리스트에 들어 있는 모든 숫자의 합을 간단히 구할 때는 파이썬 내장 함수 `sum()`을 사용할 수도 있습니다. 위 예제에서 `sum(numbers)`를 실행하면 반복문을 직접 작성하지 않고도 똑같이 `60`을 얻을 수 있습니다.

## 확인 문제

1. 다음 코드에서 `numbers`를 `[8, 4, 8]`로 바꾸면 무엇이 차례대로 출력될까요?

   ```python
   numbers = [10, 20, 30]

   for number in numbers:
       print(number)

   print("출력을 마쳤습니다.")
   ```

2. 다음 코드에서 `print("---")`를 반복문 밖으로 옮겨 마지막 안내 문구 바로 위에 두면, 구분선은 몇 번 출력될까요?

   ```python
   playlist = ["with", "Santa Baby", "Angel Bite", "with"]

   for title in playlist:
       print(title)
       print("---")

   print("목록을 다 읽었습니다.")
   ```

3. 다음 코드에서 `numbers`를 `[5, 12, 3]`으로 바꾸어 보세요. 각 반복 차례가 끝날 때 `total`의 값을 차례대로 적어 보세요.

   ```python
   numbers = [10, 20, 30]
   total = 0

   for number in numbers:
       total += number

   print(f"합계: {total}")
   ```

2. 노래 제목을 모두 출력한 뒤 구분선을 **한 번** 출력합니다.
3. 각 차례가 끝날 때마다 `5 → 17 → 20` 순서로 값이 바뀝니다. 최종 합계는 `20`입니다.
