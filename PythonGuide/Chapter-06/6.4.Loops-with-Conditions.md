# 6.4. Loops with Conditions

**반복문과 조건문 함께 쓰기**

6.2절에서는 리스트에 담긴 모든 수를 하나로 더했습니다. 이번에는 리스트에서 숫자를 하나씩 꺼내되, **짝수일 때만** 골라서 합계에 더해 보겠습니다. 이때 **반복문**(`for`)은 **어떤 값을 차례로 꺼낼지** 정하고, **조건문**(`if`)은 **꺼낸 값으로 무엇을 할지** 결정합니다.

## 6.4.1. 반복할 때마다 조건 확인하기

`for` 문 안에 `if` 문을 작성하면 값을 하나씩 꺼낼 때마다 조건을 검사할 수 있습니다. 파이썬은 **들여쓰기**(**Indentation**)로 코드의 포함 관계를 구분하므로 칸 수를 정확히 맞추어야 합니다. `if` 문은 공백 네 칸을 들여쓰고, 조건이 참일 때 실행할 코드는 공백 여덟 칸을 들여씁니다.

```text
for (변수) in (값을 꺼낼 대상):
    if (조건):
        (코드1)
    (코드2)
(코드3)
```

> 값을 하나 꺼낼 때마다 조건을 검사하여, 조건이 참이면 `(코드1)`을 실행합니다. `(코드2)`는 조건의 참·거짓과 관계없이 값을 꺼낼 때마다 항상 실행됩니다. `(코드3)`은 모든 반복이 완전히 끝난 뒤에 한 번만 실행됩니다.

## 6.4.2. 짝수만 골라 더하기

어떤 수를 2로 나눈 나머지가 0이면 그 수는 짝수입니다. 파이썬에서 나머지를 구하는 **나머지 연산자**(`%`)를 활용하면 `number % 2 == 0`이라는 조건식으로 짝수 여부를 쉽게 판별할 수 있습니다.

```python
numbers = [3, 10, 7, 20, 30]
total = 0

for number in numbers:
    if number % 2 == 0:
        total += number

print(f"짝수의 합: {total}")
```

**실행 결과**

```text
짝수의 합: 60
```

  <thead>
    <tr><th>꺼낸 수</th><th>짝수인가요?</th><th>이번 차례가 끝난 뒤 <code>total</code></th></tr>
  </thead>
  <tbody>
    <tr><td>3</td><td>아니요</td><td>0</td></tr>
    <tr><td>10</td><td>예</td><td>10</td></tr>
    <tr><td>7</td><td>아니요</td><td>10</td></tr>
    <tr><td>20</td><td>예</td><td>30</td></tr>
    <tr><td>30</td><td>예</td><td>60</td></tr>
  </tbody>
</table>

`7`을 꺼냈을 때는 조건이 거짓이므로 `total += number`를 실행하지 않고 건너뜁니다. 해당 차례가 끝나면 다음 요소인 `20`을 꺼내며, 기존 합계인 `10`에 이어서 값을 더합니다. 만약 리스트에 짝수가 하나도 없다면 `total`은 한 번도 더해지지 않으므로 초깃값인 `0`이 그대로 출력됩니다.

## 6.4.3. 합계를 처음에 한 번만 0으로 정하기

만약 합계를 저장하는 변수 초기화 코드(`total = 0`)를 아래처럼 반복문 안쪽에 두면 어떤 결과가 나올까요?

```python
numbers = [10, 20, 7]

for number in numbers:
    total = 0
    if number % 2 == 0:
        total += number

print(f"짝수의 합: {total}")
```

**실행 결과**

```text
짝수의 합: 0
```

반복문이 한 번 돌 때마다 `total`이 계속 `0`으로 초기화되므로 이전까지 계산한 합계가 모두 사라집니다. 첫 번째 차례에서 `10`을 더했더라도 다음 차례가 시작되면서 합계가 다시 `0`이 되어 `20`만 남습니다. 마지막 차례에서도 합계가 또 `0`으로 돌아가고, `7`은 홀수라서 더해지지 않으므로 최종 결과는 `0`이 됩니다. 여러 차례에 걸쳐 값을 누적하려면 6.4.2절처럼 `total = 0`을 반드시 반복문 바깥에 두어야 합니다.

## 6.4.4. 조건을 만족하는 항목 세기

합계는 조건에 맞는 값 자체를 더해서 구하지만, 개수는 조건을 통과할 때마다 `1`씩 더해서 구합니다. 이번에는 6.3절에서 배운 `range()` 함수를 사용해 1부터 10까지의 숫자를 꺼내면서 짝수가 모두 몇 개인지 세어 보겠습니다.

```python
count = 0

for number in range(1, 11):
    if number % 2 == 0:
        count += 1

print(f"짝수의 개수: {count}")
```

**실행 결과**

```text
짝수의 개수: 5
```

1부터 10까지의 수 중 짝수는 `2, 4, 6, 8, 10`으로 총 5개입니다. 개수만 세면 되므로 `count` 변수에는 꺼낸 숫자의 크기가 얼마든 상관없이 조건을 만족할 때마다 `1`씩만 더합니다.

> **합계 구하기**와 **개수 세기**는 누적하는 값만 다를 뿐 기본 구조는 같습니다.
>
> | 구분 | 누적 변수 역할 | 조건 만족 시 실행 코드 |
> | :---: | :---: | :---: |
> | 합계 구하기 | 조건에 맞는 값 자체를 누적 | `total += number` |
> | 개수 세기 | 조건을 만족한 횟수를 누적 | `count += 1` |

## 확인 문제

1. 6.4.2절의 코드에서 `numbers = [5, 12, 3, 8]`로 바꾸면 각 차례가 끝날 때마다 `total`의 값은 어떻게 변할까요?
2. 6.4.2절의 코드에서 `if` 줄을 지우고 `total += number`를 공백 네 칸만 들여쓰면, 처음 리스트(`[3, 10, 7, 20, 30]`)의 합계는 얼마가 출력될까요?
3. 6.4.4절의 코드에서 1부터 10까지의 수 중 3의 배수만 세려면 `if` 조건식을 어떻게 바꾸면 될까요? 실행 결과도 함께 적어 보세요.

<details>
<summary>정답 확인</summary>

1. `0 → 12 → 12 → 20` 순서로 변합니다. (5와 3은 홀수이므로 더해지지 않고 이전 값이 유지됩니다.)
2. 조건 없이 리스트의 다섯 수를 모두 더하므로 `70`이 출력됩니다.
3. `if number % 3 == 0:`으로 바꿉니다. 1부터 10까지 중 3의 배수는 3, 6, 9이므로 실행 결과는 `짝수의 개수: 3`(출력 문구까지 수정했다면 `3의 배수의 개수: 3`)이 됩니다.

</details>
