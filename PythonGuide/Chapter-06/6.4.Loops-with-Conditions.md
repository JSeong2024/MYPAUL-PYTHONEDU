# 6.4. Loops with Conditions

**반복문과 조건문 함께 쓰기**

6.2절에서는 리스트의 모든 수를 더했습니다. 이번에는 숫자를 하나씩 꺼내되, 짝수일 때만 합계에 더해 봅니다. `for`는 **어떤 값을 차례로 꺼낼지**, `if`는 **꺼낸 값으로 무엇을 할지** 정합니다.

## 6.4.1. 반복할 때마다 조건 확인하기

`if`를 `for` 안에 쓰면 값을 하나 꺼낼 때마다 조건을 확인합니다. `if`는 공백 네 칸, 그 조건이 참일 때 실행할 코드는 공백 여덟 칸을 들여씁니다.

```text
for (변수) in (값을 꺼낼 대상):
    if (조건):
        (코드1)
    (코드2)
(코드3)
```

> 값을 하나 꺼낼 때마다 조건을 검사합니다. 만약 조건이 참이라면 코드1을 실행합니다. 코드2는 조건에 관계없이 값을 꺼낼 때마다 실행합니다. 코드3은 반복이 끝난 뒤 실행합니다.

## 6.4.2. 짝수만 골라 더하기

어떤 수를 2로 나눈 나머지가 0이면 짝수입니다. 나머지를 구하는 연산자 `%`를 사용해 `number % 2 == 0`으로 확인합니다.

```python
numbers = [3, 10, 7, 20, 30]
total = 0

for number in numbers:
    if number % 2 == 0:
        total += number

print(f"짝수의 합: {total}")
```

**실행 결과**

```text
짝수의 합: 60
```

7을 꺼냈을 때는 조건이 거짓이므로 `total += number`를 건너뜁니다. 그 차례가 끝나면 다음 수인 20을 꺼냅니다. 합계는 10인 상태에서 다시 이어집니다. 리스트에 짝수가 하나도 없다면 처음 값인 0이 출력됩니다.

## 6.4.3. 합계를 처음에 한 번만 0으로 정하기

`total = 0`을 아래처럼 반복문 안에 두면 어떤 결과가 나올까요?

```python
numbers = [10, 20, 7]

for number in numbers:
    total = 0
    if number % 2 == 0:
        total += number

print(f"짝수의 합: {total}")
```

**실행 결과**

```text
짝수의 합: 0
```

10을 더한 다음 차례에 합계가 다시 0이 되어 20만 남습니다. 마지막 차례에서는 합계가 또 0이 되고, 7은 홀수라 더하지 않습니다. 여러 차례에 걸쳐 합계를 쌓으려면 6.4.2처럼 `total = 0`을 반복문 밖에 둡니다.

## 6.4.4. 조건을 만족하는 항목 세기

합계는 값을 더해서 구합니다. 개수는 조건을 통과할 때마다 1을 더해서 구합니다. 이번에는 6.3절의 `range()`로 1부터 10까지 꺼내면서 짝수가 몇 개인지 세어 봅니다.

```python
count = 0

for number in range(1, 11):
    if number % 2 == 0:
        count += 1

print(f"짝수의 개수: {count}")
```

**실행 결과**

```text
짝수의 개수: 5
```

짝수는 2, 4, 6, 8, 10입니다. `count`에는 숫자의 크기에 관계없이 짝수를 만날 때마다 1씩 더합니다.

## 확인 문제

1. 6.4.2에서 `numbers = [5, 12, 3, 8]`로 바꾸면 각 차례가 끝날 때 `total`은 얼마일까요?
2. 6.4.2에서 `total += number`를 공백 네 칸만 들여쓰고 그 앞의 `if` 줄을 지우면, 처음 리스트의 합계는 얼마일까요?
3. 6.4.4에서 1부터 10까지의 수 중 3의 배수만 세려면 조건을 어떻게 바꾸면 될까요? 결과도 적어 보세요.

<details>
<summary>정답 확인</summary>

1. `0 → 12 → 12 → 20`입니다.
2. 다섯 수를 모두 더하므로 70입니다.
3. `if number % 3 == 0:`으로 바꿉니다. 3, 6, 9가 조건을 만족하므로 3개입니다.

</details>
