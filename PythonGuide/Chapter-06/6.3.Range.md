# 6.3. Range

**범위의 정수로 반복하기**

1번부터 5번까지 번호를 출력할 때는 `for number in [1, 2, 3, 4, 5]:`처럼 쓸 수 있습니다. 100번까지 출력하려면 숫자를 하나씩 적는 대신 `range()`에 시작과 끝을 지정합니다. `for`문은 앞 절에서 리스트의 값을 꺼냈던 것처럼, 이번에는 `range()`가 제공하는 정수를 하나씩 꺼냅니다.

## 6.3.1. 끝값만 정하기

`range(3)`은 0에서 시작해 3보다 작은 정수를 차례대로 제공합니다.

```python
for number in range(3):
    print(number)
```

**실행 결과**

```text
0
1
2
```

> 3은 끝값이므로 포함하지 않습니다. `range(3)`에서 꺼내는 값은 0, 1, 2이고, 반복은 세 번입니다.

반복할 때마다 같은 문장을 출력하거나 같은 작업을 실행하고 싶다면 `for` 블록에서 `number`를 사용하지 않아도 됩니다.

## 6.3.2. 시작값과 끝값 정하기

1번부터 5번까지 출력하려면 1에서 시작하고, 끝값은 6으로 적습니다.

```python
for number in range(1, 6):
    print(number)
```

**실행 결과**

```text
1
2
3
4
5
```

끝값이 포함되지 않으므로 5까지 필요하다면 `range(1, 5 + 1)`로 생각하면 됩니다. 마지막 숫자를 `last`에 저장했다면 `range(1, last + 1)`처럼 쓸 수 있습니다.

## 6.3.3. 간격 정하기

세 번째 값은 **간격**(**Step**)입니다. 간격을 생략하면 1씩 늘어납니다. 2를 주면 2씩 늘어나고, 음수를 주면 숫자가 줄어듭니다.

```python
print(list(range(2, 11, 2)))
print(list(range(5, 0, -1)))
```

**실행 결과**

```text
[2, 4, 6, 8, 10]
[5, 4, 3, 2, 1]
```

`range(5, 0, -1)`은 5에서 시작해 1씩 줄어듭니다. 뒤로 셀 때도 끝값 0은 포함하지 않습니다. `range(5, 0)`처럼 간격을 생략하면 5에서 1씩 늘어나는 방향이므로 꺼낼 값이 없습니다. 간격으로 0을 쓰면 `ValueError`가 발생합니다.

> `list()`는 `range()`가 제공하는 값을 한눈에 보기 위해 사용했습니다. `for`문에는 `range()`를 바로 사용할 수 있습니다.

## 6.3.4. 별 계단 그리기

첫 줄에는 별 하나, 두 번째 줄에는 별 두 개를 출력합니다. 이 규칙을 입력한 높이까지 반복하려면 줄 번호를 1부터 `height`까지 꺼냅니다. 높이에는 1 이상의 정수를 입력한다고 가정합니다.

```python
height = int(input("높이: "))

for row in range(1, height + 1):
    print("*" * row)
```

**실행 예시**

```text
높이: 3
*
**
***
```

높이가 3이면 `range(1, 4)`에서 줄 번호 `1`, `2`, `3`을 차례로 꺼냅니다. `"*" * row`로 별을 줄 번호만큼 이어 붙이면, `print()`를 실행할 때마다 별이 하나씩 더 많은 줄이 나옵니다.

## 확인 문제

1. `range(4)`에서 꺼내는 정수를 순서대로 적어 보세요.
2. 3부터 7까지 모두 출력하려면 `range()`에 어떤 값을 넣어야 할까요?
3. `range(9, 0, -3)`에서 꺼내는 정수를 순서대로 적어 보세요.
4. 별 계단에 높이 4를 입력했을 때, 별을 4개, 3개, 2개, 1개 순서로 출력하려면 `range()`를 어떻게 바꾸면 될까요?

<details>
<summary>정답 확인</summary>

1. `0`, `1`, `2`, `3`을 꺼냅니다.
2. `range(3, 8)`을 사용합니다.
3. `9`, `6`, `3`을 꺼냅니다. 끝값 `0`은 포함하지 않습니다.
4. `range(height, 0, -1)`을 사용합니다. 줄 번호가 4에서 1까지 줄어들면서 별의 개수도 줄어듭니다.
