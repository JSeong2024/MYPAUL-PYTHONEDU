# 6.3. Range

**범위의 정수로 반복하기**

1번부터 5번까지 번호를 출력할 때는 `for number in [1, 2, 3, 4, 5]:`처럼 리스트를 직접 적을 수 있습니다. 하지만 100번까지 출력해야 한다면 숫자를 하나씩 모두 적는 대신 `range()` 함수에 시작과 끝 범위를 지정합니다. `for`문은 6.2절에서 리스트의 값을 하나씩 꺼냈던 것처럼, 이번에는 `range()`가 만들어 내는 정수를 순서대로 꺼내 반복합니다.

## 6.3.1. 끝값만 정하기

`range()`에 숫자 하나만 넣으면 `0`에서 시작해 지정한 끝값보다 작은 정수를 1씩 늘려 가며 차례대로 제공합니다.

```python
for number in range(3):
    print(number)
```

**실행 결과**

```text
0
1
2
```

> `3`은 범위의 끝값이므로 결과에 포함하지 않습니다. 즉, `range(3)`에서 꺼내는 값은 `0`, `1`, `2`이며 총 세 번 반복합니다.

반복할 때마다 단순히 같은 문장을 출력하거나 동일한 작업을 되풀이하고 싶다면, `for` 블록 안에서 반복 변수 `number`를 굳이 사용하지 않아도 괜찮습니다.

> 반복 변수를 코드 블록 내부에서 전혀 사용하지 않을 때는 관례적으로 밑줄(`_`)을 변수 이름으로 쓰기도 합니다. 예를 들어 `for _ in range(3):`처럼 작성하면 '변수 값은 쓰지 않고 횟수만 3번 반복한다'는 의도를 명확히 드러낼 수 있습니다.

## 6.3.2. 시작값과 끝값 정하기

`0`이 아닌 `1`번부터 `5`번까지 출력하려면 첫 번째 인수로 시작값 `1`을 넣고, 두 번째 인수로 끝값 `6`을 적습니다.

```python
for number in range(1, 6):
    print(number)
```

**실행 결과**

```text
1
2
3
4
5
```

지정한 끝값은 범위에 포함되지 않으므로 `5`까지 모두 포함하려면 `range(1, 5 + 1)`처럼 끝값에 `1`을 더해 준다고 생각하면 이해하기 쉽습니다. 만약 마지막 숫자가 변수 `last`에 저장되어 있다면 `range(1, last + 1)` 형태로 작성할 수 있습니다.

## 6.3.3. 간격 정하기

`range()`의 세 번째 인수는 숫자가 변하는 폭인 **간격**(**Step**)을 지정합니다. 간격을 생략하면 기본값인 `1`씩 늘어납니다. 양수 `2`를 주면 `2`씩 늘어나고, 음수를 주면 숫자가 거꾸로 줄어듭니다.

```python
print(list(range(2, 11, 2)))
print(list(range(5, 0, -1)))
```

**실행 결과**

```text
[2, 4, 6, 8, 10]
[5, 4, 3, 2, 1]
```

`range(5, 0, -1)`은 `5`에서 시작해 `1`씩 줄어듭니다. 숫자를 거꾸로 셀 때도 마찬가지로 끝값 `0`은 포함하지 않습니다. 만약 `range(5, 0)`처럼 간격을 생략하면 `5`에서 `1`씩 커지는 기본 방향으로 진행하므로 꺼낼 수 있는 값이 하나도 없습니다. 또한 간격에 `0`을 입력하면 숫자가 변할 수 없으므로 `ValueError` 오류가 발생합니다.

> `list()` 함수는 `range()`가 제공하는 전체 값을 한눈에 확인하기 위해 사용했습니다. 실제 `for`문에서는 `list()`로 변환할 필요 없이 `range()`를 바로 넣어 사용할 수 있습니다.

## 6.3.4. 별 계단 그리기

첫 번째 줄에는 별(`*`) 하나, 두 번째 줄에는 별 두 개를 출력하는 프로그램을 만들어 봅시다. 이 규칙을 사용자가 입력한 높이까지 반복하려면 줄 번호를 `1`부터 `height`까지 차례대로 꺼내야 합니다. 입력하는 높이에는 `1` 이상의 정수가 들어온다고 가정합니다.

```python
height = int(input("높이: "))

for row in range(1, height + 1):
    print("*" * row)
```

**실행 예시**

```text
높이: 3
*
**
***
```

높이에 `3`을 입력하면 `range(1, 4)`에서 줄 번호 `1`, `2`, `3`을 차례대로 꺼냅니다. 문자열 곱셈 `"*" * row`로 별 문자를 줄 번호만큼 반복해 이어 붙이면, `print()` 함수가 실행될 때마다 별이 하나씩 더 많은 줄이 출력됩니다.

## 확인 문제

1. `range(4)`에서 꺼내는 정수를 순서대로 적어 보세요.
2. `3`부터 `7`까지 모두 출력하려면 `range()`에 어떤 값을 넣어야 할까요?
3. `range(9, 0, -3)`에서 꺼내는 정수를 순서대로 적어 보세요.
4. 6.3.4절의 별 계단 예제에서 높이에 `4`를 입력했을 때, 별을 4개, 3개, 2개, 1개 순서로 거꾸로 출력하려면 `range()` 부분을 어떻게 바꾸면 될까요?

<details>
<summary>정답 확인</summary>

1. `0`, `1`, `2`, `3`을 순서대로 꺼냅니다.
2. `range(3, 8)`을 사용합니다.
3. `9`, `6`, `3`을 순서대로 꺼냅니다. 끝값 `0`은 범위에 포함하지 않습니다.
4. `range(height, 0, -1)`로 바꿉니다. 줄 번호 `row`가 `4`에서 `1`까지 `1`씩 줄어들면서 출력되는 별의 개수도 함께 줄어듭니다.

</details>
