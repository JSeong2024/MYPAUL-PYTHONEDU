# 7.2. Defining and Calling Functions

**함수 정의와 호출**

정수 두 개를 입력받아 합을 출력하는 코드를 하나의 함수로 만들어 봅시다. 함수에 `print_sum`이라는 이름을 붙여 두면, 합을 구할 때마다 그 이름으로 실행할 수 있습니다.

## 7.2.1. 함수 정의하기

`def` 뒤에 함수 이름과 소괄호 `()`를 적고, 줄 끝에 콜론(`:`)을 붙입니다. 함수에서 실행할 코드는 공백 네 칸을 들여씁니다.

```text
def 함수_이름():
    (실행할 코드)
```

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")
```

이 코드를 실행하면 파이썬은 `print_sum`이라는 함수를 정의합니다. 화면에 입력 안내도 결과도 나타나지 않습니다. 들여쓴 코드는 함수를 호출할 때 실행되기 때문입니다.

> 소괄호가 비어 있어도 `()`는 씁니다. 여기서는 호출할 때 함수에 값을 넘기지 않고, 함수 안에서 `input()`으로 값을 받습니다.

## 7.2.2. 함수 호출하기

함수 이름 뒤에 소괄호를 붙여 `print_sum()`이라고 쓰면 함수를 **호출**(**Call**)합니다. 아래에서 마지막 줄은 함수 정의 바깥에 있으므로, 정의를 마친 뒤 그 줄에서 함수를 실행합니다.

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")


print_sum()
```

**실행 예시**

```text
첫 번째 정수: 12
두 번째 정수: 3
합: 15
```

> `def print_sum():`에서 함수를 정의합니다. `print_sum()`에 도달하면 함수 안의 코드를 위에서부터 실행합니다. 함수가 끝나면 호출한 줄 다음으로 돌아옵니다.

## 7.2.3. 같은 함수 다시 호출하기

같은 함수를 두 번 호출해 봅시다. 호출할 때마다 함수의 첫 줄부터 다시 실행하므로 정수를 두 개씩 새로 입력받습니다.

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")


print_sum()
print_sum()
print("계산을 마쳤습니다.")
```

**실행 예시**

```text
첫 번째 정수: 12
두 번째 정수: 3
합: 15
첫 번째 정수: -4
두 번째 정수: 9
합: 5
계산을 마쳤습니다.
```

첫 번째 호출이 끝나면 두 번째 `print_sum()`을 실행합니다. 두 번째 호출까지 끝난 뒤 마지막 안내가 한 번 출력됩니다.

## 확인 문제

1. 다음 코드를 실행하면 화면에 무엇이 출력될까요?

   ```python
   def show_message():
       print("계산을 시작합니다.")


   print("준비를 마쳤습니다.")
   ```

2. 다음 프로그램에 호출을 한 줄 추가하여 입력을 받고 합을 출력하도록 고쳐 보세요. `8`과 `-2`를 입력하면 합은 얼마일까요?

   ```python
   def print_sum():
       left = int(input("첫 번째 정수: "))
       right = int(input("두 번째 정수: "))
       print(f"합: {left + right}")
   ```

3. 다음 시작 코드에서 첫 번째 정수에서 두 번째 정수를 뺀 값을 출력하는 `print_difference()` 함수를 완성하고 호출해 보세요. `9`와 `4`를 입력해 `차: 5`가 출력되는지 확인하세요.

   ```python
   def print_difference():
       left = int(input("첫 번째 정수: "))
       right = int(input("두 번째 정수: "))
       # 두 정수의 차를 출력하세요.
   ```
