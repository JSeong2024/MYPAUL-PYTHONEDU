# 7.2. Defining and Calling Functions

**함수 정의와 호출**

정수 두 개를 입력받아 합을 출력하는 코드를 하나의 함수로 만들어 봅시다. 함수에 `print_sum`이라는 이름을 붙여 두면, 합을 구할 때마다 같은 코드를 다시 작성하지 않고 함수를 호출하여 실행할 수 있습니다.

## 7.2.1. 함수 정의하기

함수를 만들고 함수에서 수행할 작업을 작성하는 것을 **함수 정의**(**Function Definition**)라고 합니다.

Python에서는 `def` 키워드를 사용하여 함수를 정의합니다. `def` 뒤에 함수 이름과 소괄호 `()`를 작성하고, 줄 끝에 콜론(`:`)을 붙입니다. 함수 내부에서 실행할 코드는 공백 네 칸을 들여씁니다.

```text
def 함수_이름():
    (실행할 코드)
```

정수 두 개를 입력받아 합을 출력하는 `print_sum()` 함수를 정의해 봅시다.

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")
```

이 코드를 실행하면 Python은 `print_sum`이라는 함수를 정의합니다. 하지만 화면에는 입력 안내 문구나 계산 결과가 나타나지 않습니다. 함수 내부의 코드는 함수를 정의하는 시점이 아니라 호출하는 시점에 실행되기 때문입니다.

> 함수 이름은 변수 이름과 동일한 명명 규칙을 따릅니다. 일반적으로 함수가 수행하는 작업을 알 수 있도록 이름을 정하며, 여러 단어로 구성된 이름은 `print_sum`과 같이 소문자와 밑줄(`_`)을 사용하여 작성합니다.

## 7.2.2. 함수 호출하기

정의된 함수를 실행하는 것을 **함수 호출**(**Function Call**)이라고 합니다. 함수 이름 뒤에 소괄호 `()`를 붙이면 해당 함수를 호출할 수 있습니다.

```text
함수_이름()
```

앞서 정의한 `print_sum()` 함수를 호출해 봅시다.

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")


print_sum()
```

**실행 예시**

```text
첫 번째 정수: 12
두 번째 정수: 3
합: 15
```

프로그램의 실행 순서는 다음과 같습니다.

1. `def` 키워드를 사용하여 `print_sum()` 함수를 정의합니다.
2. `print_sum()`을 호출하면 함수 내부의 코드가 실행됩니다.
3. 정수 두 개를 입력받아 각각 `left`와 `right`에 저장합니다.
4. 두 정수의 합을 계산하여 출력합니다.
5. 함수의 실행이 끝나면 호출한 위치로 돌아와 이후의 코드를 실행합니다. 실행할 코드가 더 없다면 프로그램이 종료됩니다.

함수를 정의하는 것과 호출하는 것은 서로 다른 작업입니다. 함수 정의는 수행할 작업을 작성하는 과정이며, 함수 호출은 정의된 작업을 실제로 실행하는 과정입니다.

> 함수에 전달할 값이 없더라도 함수를 정의하거나 호출할 때 소괄호 `()`를 생략할 수 없습니다. 이 예제에서는 호출할 때 값을 전달하지 않고, 함수 내부에서 `input()`을 사용하여 값을 입력받습니다.

## 7.2.3. 같은 함수 다시 호출하기

한 번 정의한 함수는 필요한 만큼 호출할 수 있습니다. 같은 함수를 두 번 호출하여 서로 다른 정수의 합을 구해 봅시다.

```python
def print_sum():
    left = int(input("첫 번째 정수: "))
    right = int(input("두 번째 정수: "))
    print(f"합: {left + right}")


print_sum()
print_sum()
print("계산을 마쳤습니다.")
```

**실행 예시**

```text
첫 번째 정수: 12
두 번째 정수: 3
합: 15
첫 번째 정수: -4
두 번째 정수: 9
합: 5
계산을 마쳤습니다.
```

첫 번째 `print_sum()`을 호출하면 정수 `12`와 `3`을 입력받아 합을 출력합니다. 함수의 실행이 끝나면 두 번째 `print_sum()`을 호출하여 정수 `-4`와 `9`를 새로 입력받습니다.

두 번째 호출까지 끝나면 마지막 줄의 `print()` 함수가 실행되어 `계산을 마쳤습니다.`라는 문구가 출력됩니다.

이처럼 함수를 사용하면 동일한 기능을 수행하는 코드를 반복해서 작성할 필요가 없습니다. 기능을 수정해야 할 때도 함수 정의 부분만 변경하면 이후의 모든 호출에 변경된 내용이 적용됩니다.

> 함수 내부의 코드는 호출할 때마다 처음부터 실행됩니다. 따라서 같은 함수를 여러 번 호출하더라도 입력값이나 실행 당시의 상태에 따라 서로 다른 결과가 나타날 수 있습니다.

## 확인 문제

1. 다음 코드를 실행하면 화면에 무엇이 출력될까요?

   ```python
   def show_message():
       print("계산을 시작합니다.")


   print("준비를 마쳤습니다.")
   ```

2. 다음 프로그램에 함수 호출 코드를 한 줄 추가하여 정수 두 개를 입력받고 합을 출력하도록 수정하세요. `8`과 `-2`를 입력하면 어떤 결과가 출력될까요?

   ```python
   def print_sum():
       left = int(input("첫 번째 정수: "))
       right = int(input("두 번째 정수: "))
       print(f"합: {left + right}")
   ```

3. 다음 시작 코드에서 첫 번째 정수에서 두 번째 정수를 뺀 값을 출력하는 `print_difference()` 함수를 완성하고 호출해 보세요. `9`와 `4`를 입력하여 `차: 5`가 출력되는지 확인하세요.

   ```python
   def print_difference():
       left = int(input("첫 번째 정수: "))
       right = int(input("두 번째 정수: "))
       # 두 정수의 차를 출력하세요.
   ```

4. 다음 코드를 실행하면 각 문구는 어떤 순서로 출력될까요?

   ```python
   def show_message():
       print("함수를 실행합니다.")


   print("시작")
   show_message()
   print("계속")
   show_message()
   print("종료")
   ```
