# 7.5. Variable Scope

**변수의 범위**

7.4절에서는 함수가 계산한 값을 `return`으로 돌려받았습니다. 함수 안에서 그 값을 변수에 저장했다면 함수 밖에서도 같은 이름으로 읽을 수 있을까요? 함수 안팎에서 이름이 어떻게 쓰이는지 살펴봅시다.

## 7.5.1. 함수 안에서 사용하는 변수

변수 이름을 사용할 수 있는 범위를 **스코프**(**Scope**)라고 합니다. 함수 안에서 처음 대입한 변수는 일반적으로 그 함수 안에서만 사용할 수 있습니다. 이런 변수를 **지역 변수**(**Local Variable**)라고 합니다. 매개변수도 함수 안에서 사용하는 지역 변수입니다.

```python
def print_sum(left, right):
    total = left + right
    print(f"합: {total}")


print_sum(12, 3)
```

**실행 결과**

```text
합: 15
```

`left`와 `right`는 호출할 때 값을 받습니다. `total`은 두 수를 더한 값을 담습니다. 세 이름은 모두 `print_sum()` 안에서 사용합니다.

> 마지막 줄 아래에 `print(total)`을 추가하면 `NameError`가 발생합니다. 함수 밖에는 `total`이라는 이름을 만든 적이 없기 때문입니다.

## 7.5.2. 함수 안팎에 같은 이름이 있을 때

함수 밖에도 `total`이라는 이름을 만들어 봅시다. 함수 안에서 같은 이름에 값을 대입한 뒤, 안팎의 값을 각각 출력합니다.

```python
total = 100


def print_sum(left, right):
    total = left + right
    print(f"함수 안: {total}")


print_sum(12, 3)
print(f"함수 밖: {total}")
```

**실행 결과**

```text
함수 안: 15
함수 밖: 100
```

함수 안의 `total = left + right`는 그 함수에서 사용할 지역 변수에 `15`를 저장합니다. 함수 밖의 `total`에는 처음 저장한 `100`이 그대로 남습니다.

> 이 예제처럼 파일의 맨 바깥에 정의한 변수는 **전역 변수**(**Global Variable**)라고 합니다. 함수에서 사용할 값을 매개변수로 받으면, 호출하는 줄을 보고 어떤 값을 쓰는지 알 수 있습니다.

## 7.5.3. 계산한 값을 함수 밖에서 쓰기

함수 안에서 구한 결과를 바깥에서도 쓰려면 `return`으로 돌려주고, 호출한 쪽에서 변수에 저장합니다.

```python
def add(left, right):
    total = left + right
    return total


result = add(12, 3)
print(f"합: {result}")
print(f"합에 10을 더한 값: {result + 10}")
```

**실행 결과**

```text
합: 15
합에 10을 더한 값: 25
```

`return total`은 `total`에 들어 있는 값 `15`를 돌려줍니다. 호출한 쪽에서는 그 값을 `result`라는 이름으로 사용합니다.

## 확인 문제

1. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요?

   ```python
   total = 50


   def show_total():
       total = 8
       print(total)


   show_total()
   print(total)
   ```

2. 다음 코드는 어디에서 오류가 발생할까요? `multiply()`가 계산한 값을 함수 밖에서 `곱: 24`로 출력하도록 수정해 보세요.

   ```python
   def multiply(left, right):
       product = left * right


   multiply(6, 4)
   print(f"곱: {product}")
   ```

3. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요? 함수에 있는 매개변수 `number`와 함수 밖에 있는 `number`의 값을 각각 확인해 보세요.

   ```python
   number = 20


   def show_number(number):
       print(number)


   show_number(7)
   print(number)
   ```

<details>
<summary>정답 확인</summary>

1. 첫 줄에 `8`, 두 번째 줄에 `50`이 출력됩니다. 함수 안에서 `total`에 대입해도 바깥쪽 `total`은 바뀌지 않습니다.
2. 함수 밖의 `print()`에서 `product`를 찾지 못해 `NameError`가 발생합니다. 함수에서 값을 반환하고, 호출한 쪽에서 받아 출력합니다.

   ```python
   def multiply(left, right):
       product = left * right
       return product


   result = multiply(6, 4)
   print(f"곱: {result}")
   ```

3. 첫 줄에 `7`, 두 번째 줄에 `20`이 출력됩니다. 인수 `7`은 함수 안의 매개변수에 들어갑니다.
