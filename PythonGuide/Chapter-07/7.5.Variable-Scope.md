# 7.5. Variable Scope

**변수의 범위**

7.4절에서는 함수가 계산한 결과를 `return`으로 반환하는 방법을 알아보았습니다. 그렇다면 함수 내부에서 계산한 결과를 변수에 저장하면 함수 외부에서도 같은 변수 이름으로 값을 사용할 수 있을까요? 이번에는 변수를 사용할 수 있는 범위와 함수 내부 및 외부에 정의된 변수의 차이를 알아봅시다.

## 7.5.1. 함수 안에서 사용하는 변수

프로그램에서 변수의 이름을 참조할 수 있는 범위를 **스코프**(**Scope**)라고 합니다.

일반적으로 함수 내부에서 값을 대입하여 정의한 변수는 해당 함수의 지역 범위에 속합니다. 이러한 변수를 **지역 변수**(**Local Variable**)라고 합니다. 함수를 정의할 때 작성한 매개변수 역시 지역 변수에 해당합니다.

```python
def print_sum(left, right):
    total = left + right
    print(f"합: {total}")


print_sum(12, 3)
```

**실행 결과**

```text
합: 15
```

함수를 호출하면 매개변수 `left`와 `right`에 각각 `12`와 `3`이 전달됩니다. 함수 내부에서는 두 수의 합을 계산하여 `total` 변수에 저장한 뒤 화면에 출력합니다.

이 예제에서 `left`, `right`, `total`은 모두 `print_sum()` 함수의 지역 변수입니다. 따라서 함수 내부에서는 사용할 수 있지만, 함수 외부에서는 해당 이름으로 값을 직접 참조할 수 없습니다.

마지막 줄 아래에 `print(total)`을 추가하면 어떻게 될까요?

```python
def print_sum(left, right):
    total = left + right
    print(f"합: {total}")


print_sum(12, 3)
print(total)
```

**실행 결과**

```text
합: 15
NameError: name 'total' is not defined
```

함수 내부에서는 `total`을 사용할 수 있으므로 `합: 15`가 정상적으로 출력됩니다. 그러나 함수 외부에는 `total`이라는 이름이 정의되어 있지 않으므로 마지막 줄에서 `NameError`가 발생합니다.

> 지역 변수는 함수를 호출할 때마다 새롭게 만들어집니다. 같은 함수를 여러 번 호출하더라도 각 호출에서 사용하는 지역 변수는 서로 독립적입니다.

## 7.5.2. 함수 안팎에 같은 이름이 있을 때

함수 외부의 최상위 영역에 정의된 변수를 **전역 변수**(**Global Variable**)라고 합니다. 전역 변수는 해당 파일의 최상위 영역뿐만 아니라 함수 내부에서도 참조할 수 있습니다.

이번에는 함수 외부에 `total`이라는 이름의 전역 변수를 정의하고, 함수 내부에도 같은 이름의 지역 변수를 정의해 봅시다.

```python
total = 100


def print_sum(left, right):
    total = left + right
    print(f"함수 안: {total}")


print_sum(12, 3)
print(f"함수 밖: {total}")
```

**실행 결과**

```text
함수 안: 15
함수 밖: 100
```

함수 내부의 `total = left + right`는 전역 변수 `total`의 값을 변경하는 것이 아니라, 새로운 지역 변수 `total`에 계산 결과인 `15`를 저장합니다.

함수 내부에서는 같은 이름의 전역 변수보다 지역 변수가 우선적으로 참조됩니다. 따라서 함수 내부에서는 `15`가 출력되고, 함수 외부에서는 전역 변수에 저장된 `100`이 출력됩니다.

변수의 이름이 같더라도 서로 다른 범위에 정의되어 있다면 별개의 변수로 사용될 수 있습니다.

함수 내부에 같은 이름의 지역 변수가 없다면 전역 변수의 값을 직접 참조할 수 있습니다.

```python
total = 100


def show_total():
    print(total)


show_total()
```

**실행 결과**

```text
100
```

`show_total()` 함수 내부에는 지역 변수 `total`이 정의되어 있지 않습니다. 따라서 함수 외부에 정의된 전역 변수 `total`을 참조하여 `100`을 출력합니다.

> Python에서는 `global` 키워드를 사용하여 함수 내부에서 전역 변수에 값을 대입할 수도 있습니다. 다만 전역 변수에 대한 의존성이 높아지면 변수의 값이 어디에서 변경되는지 파악하기 어려워질 수 있습니다. 가능한 한 필요한 값은 매개변수로 전달받고, 계산 결과는 `return`으로 반환하는 것이 좋습니다.

## 7.5.3. 계산한 값을 함수 밖에서 쓰기

함수 내부에서 정의한 지역 변수는 함수 외부에서 직접 참조할 수 없습니다. 하지만 7.4절에서 배운 `return`을 사용하면 지역 변수에 저장된 값을 함수 외부로 반환할 수 있습니다.

```python
def add(left, right):
    total = left + right
    return total


result = add(12, 3)
print(f"합: {result}")
print(f"합에 10을 더한 값: {result + 10}")
```

**실행 결과**

```text
합: 15
합에 10을 더한 값: 25
```

프로그램의 실행 순서는 다음과 같습니다.

1. `add(12, 3)`을 호출하여 매개변수 `left`와 `right`에 각각 `12`와 `3`을 전달합니다.
2. 두 수의 합을 계산하여 지역 변수 `total`에 저장합니다.
3. `return total`을 실행하여 `total`에 저장된 값인 `15`를 반환합니다.
4. 함수 외부의 `result` 변수에 반환값 `15`를 저장합니다.
5. `result`를 사용하여 계산 결과와 그 값에 `10`을 더한 결과를 출력합니다.

이때 `return total`은 지역 변수 `total` 자체를 함수 외부에서 사용할 수 있도록 만드는 것이 아니라, 해당 변수에 저장된 값을 반환하는 것입니다. 따라서 함수 외부에서는 여전히 `total`을 직접 참조할 수 없습니다.

이처럼 매개변수와 반환값을 활용하면 함수가 필요한 값을 전달받아 작업을 수행하고, 그 결과를 함수 외부에서 다시 활용할 수 있습니다.

## 확인 문제

1. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요?

   ```python
   total = 50


   def show_total():
       total = 8
       print(total)


   show_total()
   print(total)
   ```

2. 다음 코드에서 오류가 발생하는 위치와 원인을 설명하세요. `multiply()` 함수가 계산한 값을 반환하도록 수정하고, 함수 외부에서 `곱: 24`가 출력되도록 코드를 완성하세요.

   ```python
   def multiply(left, right):
       product = left * right


   multiply(6, 4)
   print(f"곱: {product}")
   ```

3. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요? 함수의 매개변수 `number`와 함수 외부의 전역 변수 `number`를 구분하여 설명하세요.

   ```python
   number = 20


   def show_number(number):
       print(number)


   show_number(7)
   print(number)
   ```

4. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요? `show_price()` 함수에서 `price`를 참조할 수 있는 이유도 설명하세요.

   ```python
   price = 5_000


   def show_price():
       print(price)


   show_price()
   price = 7_000
   show_price()
   ```

<summary>정답 확인</summary>

1. 다음과 같이 출력됩니다.

   ```text
   8
   50
   ```

   `show_total()` 함수 내부에서 `total = 8`을 실행하면 지역 변수 `total`에 `8`이 저장됩니다.

   함수 외부의 전역 변수 `total`과는 별개의 변수이므로 전역 변수에 저장된 값 `50`은 변경되지 않습니다.

2. 마지막 줄의 `print(f"곱: {product}")`에서 `NameError`가 발생합니다. `product`는 `multiply()` 함수의 지역 변수이므로 함수 외부에서는 직접 참조할 수 없습니다.

   `return`을 사용하여 계산 결과를 반환하고, 함수 외부에서 반환값을 변수에 저장하도록 수정합니다.

   ```python
   def multiply(left, right):
       product = left * right
       return product


   result = multiply(6, 4)
   print(f"곱: {result}")
   ```

   **실행 결과**

   ```text
   곱: 24
   ```

   `multiply(6, 4)`가 계산 결과인 `24`를 반환하면 해당 값이 `result` 변수에 저장됩니다.

3. 다음과 같이 출력됩니다.

   ```text
   7
   20
   ```

   `show_number(7)`을 호출하면 인수 `7`이 매개변수 `number`에 전달됩니다. 매개변수는 지역 변수이므로 함수 내부에서는 `7`을 출력합니다.

   함수 외부의 전역 변수 `number`에는 영향을 주지 않으므로 마지막 줄에서는 `20`을 출력합니다.

4. 다음과 같이 출력됩니다.

   ```text
   5000
   7000
   ```

   `show_price()` 함수 내부에는 지역 변수 `price`가 정의되어 있지 않으므로 전역 변수 `price`를 참조합니다.

   첫 번째 호출에서는 전역 변수의 값인 `5000`을 출력합니다. 이후 `price = 7_000`이 실행되어 전역 변수의 값이 변경되므로 두 번째 호출에서는 `7000`을 출력합니다.
