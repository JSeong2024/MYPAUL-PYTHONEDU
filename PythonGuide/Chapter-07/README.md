## Summary

- `def`로 함수를 정의합니다. 함수 이름 뒤에 소괄호를 붙여 호출하면 함수 안의 코드가 실행됩니다.
- 매개변수는 함수 안에서 값을 받을 이름이고, 인수는 함수를 호출할 때 넘기는 값입니다.
- `print()`는 값을 화면에 출력합니다. `return`은 값을 호출한 쪽에 돌려주고 함수 실행을 마칩니다.
- 함수에서 일반 대입으로 만든 지역 변수는 그 함수 안에서 사용합니다. 계산 결과를 밖에서 쓰려면 반환값을 받습니다.
- 한 함수 안에서 다른 함수를 호출해, 그 함수가 돌려준 값을 이어서 사용할 수 있습니다.
