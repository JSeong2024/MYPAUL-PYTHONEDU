# 7.1. Functions

**함수**

화면에 글자를 표시할 때는 `print()`를 쓰고, 사용자가 입력한 내용을 받을 때는 `input()`을 씁니다. 지금까지 써 온 두 도구는 모두 파이썬에 미리 들어 있는 **내장 함수**(**Built-in Function**)입니다.

함수는 특정 작업을 수행하는 코드 묶음입니다. 함수 이름 뒤에 소괄호를 붙여 `print("안녕하세요")`처럼 쓰면, 그 함수가 맡은 작업을 실행합니다. 이렇게 함수를 실행하는 것을 **호출**(**Call**)이라고 합니다.

## 직접 만든 함수는 언제 쓸까요?

사칙연산 계산기에서 두 정수를 입력받아 합을 출력하려면 여러 줄이 필요합니다. 이 작업에 `print_sum`이라는 이름을 붙여 함수를 만들면, 다시 계산하고 싶을 때 `print_sum()`을 호출하면 됩니다. 이렇게 직접 정의한 함수를 **사용자 정의 함수**(**User-Defined Function**)라고 합니다.

7.2절에서는 정수 두 개를 입력받아 합을 출력하는 함수를 직접 만듭니다. 7.3절과 7.4절에서는 호출할 때 값을 전달하고, 계산한 값을 돌려받는 방법을 살펴봅니다.
