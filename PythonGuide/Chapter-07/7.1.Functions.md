# 7.1. Functions

**함수**

화면에 글자를 출력할 때는 `print()`를 사용하고, 사용자에게 값을 입력받을 때는 `input()`을 사용합니다. 지금까지 사용해 온 `print()`와 `input()`은 모두 Python에서 기본적으로 제공하는 **내장 함수**(**Built-in Function**)입니다.

**함수**(**Function**)란 특정 작업을 수행하도록 구성한 코드의 단위입니다. 함수 이름 뒤에 소괄호 `()`를 붙여 `print("안녕하세요")`와 같이 작성하면 해당 함수가 수행할 작업이 실행됩니다. 이처럼 함수를 실행하는 것을 **함수 호출**(**Function Call**)이라고 합니다.

Python에서는 기본적으로 제공하는 내장 함수뿐만 아니라 필요한 기능을 직접 함수로 만들어 사용할 수도 있습니다.

## 직접 만든 함수는 언제 쓸까요?

사칙연산 계산기 프로그램에서 정수 두 개를 입력받아 합을 출력한다고 가정해 봅시다.

```python
left = int(input("첫 번째 정수: "))
right = int(input("두 번째 정수: "))
print(f"합: {left + right}")
```

같은 작업을 프로그램의 여러 곳에서 수행하려면 동일한 코드를 반복해서 작성해야 합니다. 그러나 이 작업을 `print_sum`이라는 이름의 함수로 만들어 두면, 필요한 시점에 `print_sum()`을 호출하는 것만으로 동일한 작업을 수행할 수 있습니다.

이처럼 개발자가 필요한 기능을 직접 정의하여 만든 함수를 **사용자 정의 함수**(**User-Defined Function**)라고 합니다.

함수를 사용하면 다음과 같은 장점이 있습니다.

- **코드 재사용:** 같은 기능을 반복해서 작성하지 않고 함수를 호출하여 사용할 수 있습니다.
- **가독성 향상:** 코드를 기능별로 나누어 프로그램의 구조와 실행 흐름을 쉽게 파악할 수 있습니다.
- **유지보수 편의성:** 특정 기능을 변경할 때 해당 함수의 코드만 수정하면 됩니다.

> 함수는 반복해서 실행하는 코드를 줄이는 데만 사용되는 것이 아닙니다. 한 번만 실행하는 코드라도 독립적인 기능으로 나누면 프로그램의 구조를 명확하게 구성할 수 있습니다.
