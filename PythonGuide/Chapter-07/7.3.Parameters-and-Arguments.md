# 7.3. Parameters and Arguments

**매개변수와 인수**

7.2절의 `print_sum()`은 호출할 때마다 함수 안에서 정수 두 개를 입력받았습니다. 이미 저장해 둔 두 수의 합을 구하려면 어떻게 할까요? 이번에는 입력을 함수 밖에서 받고, 호출할 때 두 값을 함수에 넘겨 봅니다.

## 7.3.1. 매개변수로 값 받기

함수를 정의할 때 소괄호에 **값을 받을 이름**을 적습니다. 이 이름을 **매개변수**(**Parameter**)라고 합니다. 함수를 호출할 때 넘기는 값은 **인수**(**Argument**)라고 합니다.

```text
def 함수_이름(매개변수1, 매개변수2):
    (실행할 코드)

함수_이름(인수1, 인수2)
```

```python
def print_sum(left, right):
    print(f"합: {left + right}")


print_sum(12, 3)
print_sum(-4, 9)
```

**실행 결과**

```text
합: 15
합: 5
```

> `print_sum(12, 3)`을 호출하면 첫 번째 인수 `12`가 `left`에, 두 번째 인수 `3`이 `right`에 들어갑니다. `print_sum(-4, 9)`를 호출하면 이번에는 `left`에 `-4`, `right`에 `9`가 들어갑니다.

## 7.3.2. 입력받은 값을 인수로 넘기기

숫자를 변수에 저장했다면 호출할 때 그 변수 이름을 쓸 수 있습니다. 두 정수를 함수 밖에서 입력받아 `first`와 `second`에 저장해 봅시다.

```python
def print_sum(left, right):
    print(f"합: {left + right}")


first = int(input("첫 번째 정수: "))
second = int(input("두 번째 정수: "))
print_sum(first, second)
```

**실행 예시**

```text
첫 번째 정수: 8
두 번째 정수: -2
합: 6
```

`print_sum(first, second)`는 `first`에 저장된 `8`과 `second`에 저장된 `-2`를 순서대로 넘깁니다. 함수 안에서는 두 값을 `left`와 `right`라는 이름으로 사용합니다. 같은 함수에 `print_sum(8, -2)`처럼 숫자를 바로 넘겨도 합은 같습니다.

## 7.3.3. 인수의 순서와 개수 확인하기

지금까지처럼 인수를 순서대로 넘기면 각 값은 같은 위치의 매개변수에 들어갑니다. 뺄셈에서는 두 값의 순서를 바꾸면 결과도 달라집니다.

```python
def print_difference(left, right):
    print(f"차: {left - right}")


print_difference(9, 4)
print_difference(4, 9)
```

**실행 결과**

```text
차: 5
차: -5
```

이 함수의 매개변수 `left`, `right`에는 각각 값이 필요합니다. `print_difference(9)`처럼 인수를 하나만 넘기거나 `print_difference(9, 4, 2)`처럼 세 개를 넘기면 `TypeError`가 발생합니다.

## 확인 문제

1. 다음 코드에서 첫 번째 호출과 두 번째 호출이 각각 어떤 값을 출력할지 적어 보세요.

   ```python
   def print_sum(left, right):
       print(f"합: {left + right}")


   print_sum(7, 2)
   print_sum(-3, 3)
   ```

2. 다음 함수의 호출에서 인수의 순서만 바꿔 `차: 6`이 나오게 하세요.

   ```python
   def print_difference(left, right):
       print(f"차: {left - right}")


   print_difference(4, 10)
   ```

3. 다음 코드에서 함수가 실행되지 않는 이유를 설명하고, `first`와 `second`를 모두 넘기도록 호출하는 줄을 고쳐 보세요.

   ```python
   def print_sum(left, right):
       print(f"합: {left + right}")


   first = 8
   second = -2
   print_sum(first)
   ```

<summary>정답 확인</summary>

1. 첫 번째 줄에 `합: 9`, 두 번째 줄에 `합: 0`이 출력됩니다.
2. `print_difference(10, 4)`로 호출합니다. `left`가 `10`, `right`가 `4`이므로 `차: 6`이 출력됩니다.
3. 매개변수는 두 개지만 인수를 하나만 넘겼으므로 `TypeError`가 발생합니다. `print_sum(first, second)`로 바꾸면 `합: 6`이 출력됩니다.
