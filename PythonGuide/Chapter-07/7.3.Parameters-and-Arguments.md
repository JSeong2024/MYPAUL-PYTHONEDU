# 7.3. Parameters and Arguments

**매개변수와 인수**

7.2절에서 만든 `print_sum()` 함수는 호출할 때마다 함수 내부에서 정수 두 개를 직접 입력받았습니다. 그렇다면 이미 변수에 저장된 두 수의 합을 구하려면 어떻게 해야 할까요? 이번에는 함수 외부에서 값을 입력받고, 함수를 호출할 때 필요한 값을 전달하는 방법을 알아봅시다.

## 7.3.1. 매개변수로 값 받기

함수를 정의할 때 소괄호 안에 외부에서 전달받은 값을 사용할 변수의 이름을 작성할 수 있습니다. 이러한 변수를 **매개변수**(**Parameter**)라고 합니다. 반면, 함수를 호출할 때 실제로 전달하는 값은 **인수**(**Argument**)라고 합니다.

여러 개의 매개변수와 인수는 쉼표(`,`)로 구분하여 작성합니다.

```text
def 함수_이름(매개변수1, 매개변수2):
    (실행할 코드)

함수_이름(인수1, 인수2)
```

매개변수를 사용하여 두 수의 합을 출력하는 `print_sum()` 함수를 다시 정의해 봅시다.

```python
def print_sum(left, right):
    print(f"합: {left + right}")


print_sum(12, 3)
print_sum(-4, 9)
```

**실행 결과**

```text
합: 15
합: 5
```

`print_sum(12, 3)`을 호출하면 첫 번째 인수 `12`가 매개변수 `left`에, 두 번째 인수 `3`이 매개변수 `right`에 전달됩니다. 함수 내부에서는 `left + right`를 계산하여 `15`를 출력합니다.

이어서 `print_sum(-4, 9)`를 호출하면 `left`에 `-4`, `right`에 `9`가 전달되어 `5`를 출력합니다.

## 7.3.2. 입력받은 값을 인수로 넘기기

함수를 호출할 때는 값을 직접 작성하거나 변수에 저장된 값을 전달할 수 있습니다. 두 정수를 함수 외부에서 입력받아 `first`와 `second` 변수에 저장한 뒤 `print_sum()` 함수로 전달해 봅시다.

```python
def print_sum(left, right):
    print(f"합: {left + right}")


first = int(input("첫 번째 정수: "))
second = int(input("두 번째 정수: "))
print_sum(first, second)
```

**실행 예시**

```text
첫 번째 정수: 8
두 번째 정수: -2
합: 6
```

`print_sum(first, second)`를 호출하면 `first`에 저장된 값 `8`과 `second`에 저장된 값 `-2`가 함수에 전달됩니다. 함수 내부에서는 전달받은 값을 각각 `left`와 `right`라는 이름으로 사용합니다.

이 예제에서 `print_sum(first, second)`를 호출하는 것은 `print_sum(8, -2)`처럼 값을 직접 전달하는 것과 동일한 결과를 얻습니다.

> 인수로 사용하는 변수의 이름과 매개변수의 이름은 같을 필요가 없습니다. 또한 인수에는 숫자나 변수뿐만 아니라 `5 + 3`과 같은 표현식도 사용할 수 있습니다. 이 경우 표현식을 계산한 결과가 함수에 전달됩니다.

## 7.3.3. 인수의 순서와 개수 확인하기

지금까지 살펴본 방식은 인수를 작성한 순서에 따라 매개변수에 값을 전달하는 방식입니다. 이러한 인수를 **위치 인수**(**Positional Argument**)라고 합니다.

덧셈은 두 수의 순서를 바꾸어도 결과가 같지만, 뺄셈은 순서에 따라 계산 결과가 달라집니다. 두 수의 차를 출력하는 `print_difference()` 함수를 정의하고 인수의 순서를 바꾸어 호출해 봅시다.

```python
def print_difference(left, right):
    print(f"차: {left - right}")


print_difference(9, 4)
print_difference(4, 9)
```

**실행 결과**

```text
차: 5
차: -5
```

첫 번째 호출에서는 `left`에 `9`, `right`에 `4`가 전달되어 `9 - 4`를 계산합니다. 두 번째 호출에서는 두 값의 순서가 바뀌므로 `4 - 9`를 계산합니다.

함수를 호출할 때는 인수의 순서뿐만 아니라 개수도 확인해야 합니다. `print_difference()` 함수는 두 개의 매개변수 `left`와 `right`가 모두 값을 전달받아야 실행할 수 있습니다.

이처럼 위 함수에 필요한 인수의 개수와 실제로 전달한 인수의 개수가 일치하지 않으면 `TypeError`가 발생하며, 함수 내부의 코드는 실행되지 않습니다.

> Python에서는 매개변수에 기본값을 지정하거나 가변 개수의 인수를 전달받도록 함수를 정의할 수도 있습니다. 이러한 경우에는 매개변수와 인수의 개수가 반드시 같을 필요는 없습니다.

## 확인 문제

1. 다음 코드에서 첫 번째 호출과 두 번째 호출이 각각 어떤 값을 출력할지 적어 보세요.

   ```python
   def print_sum(left, right):
       print(f"합: {left + right}")


   print_sum(7, 2)
   print_sum(-3, 3)
   ```

2. 다음 함수의 호출 코드에서 인수의 순서만 바꾸어 `차: 6`이 출력되도록 수정하세요.

   ```python
   def print_difference(left, right):
       print(f"차: {left - right}")


   print_difference(4, 10)
   ```

3. 다음 코드에서 오류가 발생하는 이유를 설명하고, `first`와 `second`의 값을 모두 전달하도록 함수 호출 부분을 수정하세요.

   ```python
   def print_sum(left, right):
       print(f"합: {left + right}")


   first = 8
   second = -2
   print_sum(first)
   ```

4. 다음 코드에서 매개변수와 인수를 각각 찾고, 함수에 전달되는 값과 실행 결과를 적어 보세요.

   ```python
   def print_product(left, right):
       print(f"곱: {left * right}")


   number = 4
   print_product(number, 2 + 3)
   ```
