# 7.6. Organizing Code with Functions

**함수로 코드 나누기**

사칙연산 계산기에는 두 정수를 계산하는 일, 연산자를 보고 어떤 계산을 할지 고르는 일, 입출력을 처리하는 일이 있습니다. 계산을 함수로 나누면 같은 연산을 다른 곳에서도 호출할 수 있습니다.

## 7.6.1. 함수 안에서 다른 함수 호출하기

`calculate()`가 연산자를 확인한 뒤 `add()` 또는 `subtract()`를 호출하도록 만들어 봅시다. 이 예제에는 `+` 또는 `-`만 넘깁니다.

```python
def add(left, right):
    return left + right


def subtract(left, right):
    return left - right


def calculate(left, operator, right):
    if operator == "+":
        return add(left, right)

    return subtract(left, right)


result = calculate(12, "-", 3)
print(f"계산 결과: {result}")
```

**실행 결과**

```text
계산 결과: 9
```

> 만약 연산자가 `+`라면 `add()`를 호출합니다. 이 예제에서 나머지 연산자는 `-`이므로 `subtract()`를 호출합니다.

`return subtract(left, right)`에서는 먼저 `subtract(12, 3)`을 실행해 `9`를 받습니다. `calculate()`도 그 값을 돌려주므로, 처음 호출한 줄의 `result`에 `9`가 저장됩니다.

## 7.6.2. 사칙연산 계산기로 확장하기

곱셈과 나눗셈도 함수로 만들고, **정수 → 연산자 → 정수** 순서로 입력받습니다. 계산 함수를 호출하기 전에 지원하지 않는 연산자와 0으로 나누는 경우를 확인합니다. 두 수에는 정수를 입력한다고 가정합니다.

```python
def add(left, right):
    return left + right


def subtract(left, right):
    return left - right


def multiply(left, right):
    return left * right


def divide(left, right):
    return left / right


def calculate(left, operator, right):
    if operator == "+":
        return add(left, right)
    elif operator == "-":
        return subtract(left, right)
    elif operator == "*":
        return multiply(left, right)
    else:
        return divide(left, right)


first = int(input("첫 번째 정수: "))
operator = input("연산자 (+, -, *, /): ")
second = int(input("두 번째 정수: "))

if operator not in ["+", "-", "*", "/"]:
    print("지원하지 않는 연산자입니다.")
elif operator == "/" and second == 0:
    print("0으로 나눌 수 없습니다.")
else:
    result = calculate(first, operator, second)
    print(f"계산 결과: {result}")
```

**실행 예시**

```text
첫 번째 정수: 12
연산자 (+, -, *, /): *
두 번째 정수: 3
계산 결과: 36
```

입력 부분에서 연산자를 검사했으므로, `calculate()`의 마지막 `else`에 도달하는 연산자는 `/`뿐입니다. `12 / 3`의 결과는 `4.0`입니다. 파이썬에서 `/`로 나누면 결과가 정수로 떨어져도 실수로 반환됩니다.

## 확인 문제

1. 다음 코드가 출력하는 값과, `calculate()` 안에서 호출하는 함수의 이름을 적어 보세요.

   ```python
   def add(left, right):
       return left + right


   def subtract(left, right):
       return left - right


   def calculate(left, operator, right):
       if operator == "+":
           return add(left, right)

       return subtract(left, right)


   print(calculate(5, "+", 8))
   ```

2. 다음 코드에는 `multiply()`에서 받은 값을 돌려주는 부분이 빠져 있습니다. 현재 어떤 값이 출력되며, `36`이 출력되게 하려면 어느 줄을 바꿔야 할까요?

   ```python
   def multiply(left, right):
       return left * right


   def calculate_product(left, right):
       multiply(left, right)


   print(calculate_product(12, 3))
   ```

<details>
<summary>정답 확인</summary>

1. `calculate()`는 `add(5, 8)`을 호출합니다. 덧셈 결과를 돌려받아 다시 반환하므로 `13`이 출력됩니다.
2. `multiply()`는 `36`을 반환하지만, `calculate_product()`는 `return` 없이 끝나므로 `None`이 출력됩니다. `multiply(left, right)`를 `return multiply(left, right)`로 바꾸면 `36`이 출력됩니다.

</details>
