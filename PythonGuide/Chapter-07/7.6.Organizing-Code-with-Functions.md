# 7.6. Organizing Code with Functions

**함수로 코드 나누기**

사칙연산 계산기 프로그램을 만들려면 두 수를 계산하는 기능, 연산자에 따라 계산 방법을 선택하는 기능, 사용자에게 값을 입력받고 결과를 출력하는 기능이 필요합니다.

이러한 기능을 역할에 따라 함수로 나누면 프로그램의 구조를 쉽게 파악할 수 있으며, 각 기능을 독립적으로 수정하거나 재사용할 수 있습니다. 지금까지 배운 함수의 정의와 호출, 매개변수, 인수, 반환값을 활용하여 사칙연산 계산기를 만들어 봅시다.

## 7.6.1. 함수 안에서 다른 함수 호출하기

함수 외부에서뿐만 아니라 함수 내부에서도 다른 함수를 호출할 수 있습니다. 여러 함수가 서로 값을 전달하고 결과를 반환하도록 구성하면 하나의 작업을 여러 함수로 나누어 처리할 수 있습니다.

`calculate()` 함수가 전달받은 연산자를 확인하고, 조건에 따라 `add()` 또는 `subtract()` 함수를 호출하도록 만들어 봅시다. 이 예제에서는 연산자로 `"+"` 또는 `"-"`만 전달한다고 가정합니다.

```python
def add(left, right):
    return left + right


def subtract(left, right):
    return left - right


def calculate(left, operator, right):
    if operator == "+":
        return add(left, right)

    return subtract(left, right)


result = calculate(12, "-", 3)
print(f"계산 결과: {result}")
```

**실행 결과**

```text
계산 결과: 9
```

`calculate()` 함수는 매개변수 `left`, `operator`, `right`를 통해 두 수와 연산자를 전달받습니다. `operator`의 값이 `"+"`이면 `add()` 함수를 호출하고, 그렇지 않으면 `subtract()` 함수를 호출합니다.

이 예제에서는 `operator`의 값이 `"-"`이므로 `return subtract(left, right)`가 실행됩니다. 이때 `subtract()` 함수가 반환한 값은 다시 `calculate()` 함수의 반환값으로 사용됩니다.

함수 내부에서 다른 함수를 호출하면 호출된 함수의 실행이 끝난 뒤 기존 함수로 돌아와 나머지 작업을 수행합니다.

> `return subtract(left, right)`는 다음 두 줄과 동일하게 동작합니다.
>
> ```python
> result = subtract(left, right)
> return result
> ```
>
> 다른 함수의 반환값을 별도의 변수에 저장하지 않고 바로 반환할 수도 있습니다.

## 7.6.2. 사칙연산 계산기로 확장하기

이번에는 곱셈을 수행하는 `multiply()` 함수와 나눗셈을 수행하는 `divide()` 함수를 추가하여 사칙연산 계산기로 확장해 봅시다.

사용자에게 **정수 → 연산자 → 정수** 순서로 값을 입력받습니다. 계산 함수를 호출하기 전에 지원하지 않는 연산자를 입력했는지, 나누는 수가 `0`인지 확인하여 잘못된 계산을 방지합니다. 두 수에는 정수가 입력된다고 가정합니다.

```python
def add(left, right):
    return left + right


def subtract(left, right):
    return left - right


def multiply(left, right):
    return left * right


def divide(left, right):
    return left / right


def calculate(left, operator, right):
    if operator == "+":
        return add(left, right)
    elif operator == "-":
        return subtract(left, right)
    elif operator == "*":
        return multiply(left, right)
    else:
        return divide(left, right)


first = int(input("첫 번째 정수: "))
operator = input("연산자 (+, -, *, /): ")
second = int(input("두 번째 정수: "))

if operator not in ["+", "-", "*", "/"]:
    print("지원하지 않는 연산자입니다.")
elif operator == "/" and second == 0:
    print("0으로 나눌 수 없습니다.")
else:
    result = calculate(first, operator, second)
    print(f"계산 결과: {result}")
```

**실행 예시 1 — 곱셈**

```text
첫 번째 정수: 12
연산자 (+, -, *, /): *
두 번째 정수: 3
계산 결과: 36
```

**실행 예시 2 — 나눗셈**

```text
첫 번째 정수: 12
연산자 (+, -, *, /): /
두 번째 정수: 3
계산 결과: 4.0
```

**실행 예시 3 — 지원하지 않는 연산자**

```text
첫 번째 정수: 12
연산자 (+, -, *, /): %
두 번째 정수: 3
지원하지 않는 연산자입니다.
```

**실행 예시 4 — 0으로 나누는 경우**

```text
첫 번째 정수: 12
연산자 (+, -, *, /): /
두 번째 정수: 0
0으로 나눌 수 없습니다.
```

함수 외부의 조건문에서는 입력값을 다음 순서로 검사합니다.

1. `not in` 연산자를 사용하여 입력한 연산자가 지원하는 사칙연산 기호에 포함되어 있는지 확인합니다.
2. 연산자가 `"/"`이고 두 번째 정수가 `0`인지 확인합니다.
3. 두 조건에 모두 해당하지 않으면 `calculate()` 함수를 호출하여 계산 결과를 출력합니다.

`calculate()` 함수를 호출하기 전에 연산자의 유효성을 검사했으므로 함수 내부의 마지막 `else` 블록에는 연산자가 `"/"`인 경우에만 도달합니다.

> 두 정수를 `/` 연산자로 나누면 계산 결과가 정수로 나누어떨어지더라도 반환값의 자료형은 실수형(`float`)입니다. 따라서 `12 / 3`의 결과는 `4`가 아닌 `4.0`입니다.

이처럼 하나의 프로그램을 여러 기능으로 나누고 각 기능을 함수로 구성하는 방식을 **기능 분해**(**Functional Decomposition**)라고 합니다.

함수마다 담당하는 역할이 명확하면 특정 기능을 수정하거나 새로운 기능을 추가하기 쉽습니다. 또한 각 함수를 독립적으로 호출하여 정상적으로 동작하는지 확인할 수 있습니다.

> 모든 코드를 반드시 함수로 나누어야 하는 것은 아닙니다. 프로그램의 규모와 기능을 고려하여 반복해서 사용하거나 독립적으로 관리할 필요가 있는 코드를 함수로 구성하는 것이 좋습니다.

## 확인 문제

1. 다음 코드의 실행 결과와 `calculate()` 함수 내부에서 호출되는 함수의 이름을 적어 보세요.

   ```python
   def add(left, right):
       return left + right


   def subtract(left, right):
       return left - right


   def calculate(left, operator, right):
       if operator == "+":
           return add(left, right)

       return subtract(left, right)


   print(calculate(5, "+", 8))
   ```

2. 다음 코드에는 `multiply()` 함수의 반환값을 다시 반환하는 부분이 빠져 있습니다. 현재 코드의 실행 결과를 적고, `36`이 출력되도록 수정하세요.

   ```python
   def multiply(left, right):
       return left * right


   def calculate_product(left, right):
       multiply(left, right)


   print(calculate_product(12, 3))
   ```

3. 다음 코드를 실행하면 각 줄에 어떤 값이 출력될까요? `add()` 함수가 총 몇 번 호출되는지도 확인해 보세요.

   ```python
   def add(left, right):
       return left + right


   def double(number):
       return add(number, number)


   print(double(5))
   print(add(double(3), 4))
   ```
