# 7.4. Return Values

**함수의 반환값**

7.3절의 `print_sum()` 함수는 두 수의 합을 계산하여 화면에 출력했습니다. 하지만 계산한 합을 두 배로 늘리거나 다른 연산에 활용하려면 함수에서 계산한 결과를 전달받을 수 있어야 합니다. 이번에는 함수가 작업을 수행한 결과를 호출한 곳으로 반환하는 방법을 알아봅시다.

## 7.4.1. `return`으로 값 돌려주기

함수가 호출한 곳으로 돌려주는 값을 **반환값**(**Return Value**)이라고 합니다. Python에서는 `return` 키워드를 사용하여 값을 반환하며, `return` 뒤에는 반환할 값, 변수 또는 표현식을 작성할 수 있습니다.

```text
def 함수_이름(매개변수):
    (실행할 코드)
    return (돌려줄 값)

결과 = 함수_이름(인수)
```

두 수의 합을 계산하여 반환하는 `add()` 함수를 정의해 봅시다.

```python
def add(left, right):
    return left + right


result = add(12, 3)
print(f"합: {result}")
print(f"합의 두 배: {result * 2}")
```

**실행 결과**

```text
합: 15
합의 두 배: 30
```

프로그램의 실행 순서는 다음과 같습니다.

1. `add(12, 3)`을 호출하면 매개변수 `left`와 `right`에 각각 `12`와 `3`이 전달됩니다.
2. 함수 내부에서 `left + right`를 계산합니다.
3. `return` 문을 통해 계산 결과인 `15`를 반환하고 함수의 실행을 종료합니다.
4. 반환값 `15`가 `result` 변수에 저장됩니다.
5. `result`에 저장된 값과 그 값의 두 배를 각각 출력합니다.

이처럼 함수의 반환값을 변수에 저장하면 함수 내부에서 계산한 결과를 함수 외부에서도 활용할 수 있습니다.

> 함수의 반환값을 반드시 변수에 저장해야 하는 것은 아닙니다. `print(add(12, 3))`처럼 다른 함수의 인수로 사용하거나, `add(12, 3) * 2`처럼 다른 연산에 바로 활용할 수도 있습니다.

## 7.4.2. `print()`와 `return` 비교하기

`print()`는 값을 화면에 출력하는 함수이고, `return`은 값을 반환하면서 현재 함수의 실행을 종료하는 키워드입니다. 두 기능의 차이를 확인하기 위해 같은 두 수를 더하는 함수를 각각 정의하고, 반환값을 비교해 봅시다.

```python
def print_sum(left, right):
    print(f"합: {left + right}")


def add(left, right):
    return left + right


printed = print_sum(12, 3)
returned = add(12, 3)

print(f"print_sum()의 반환값: {printed}")
print(f"add()의 반환값: {returned}")
```

**실행 결과**

```text
합: 15
print_sum()의 반환값: None
add()의 반환값: 15
```

`print_sum()` 함수는 두 수의 합을 계산하여 화면에 `합: 15`를 출력합니다. 그러나 `return` 문 없이 함수의 실행이 끝나므로 `printed` 변수에는 `None`이 저장됩니다.

Python에서 `None`은 값이 없음을 나타내는 특별한 값입니다. 함수에서 반환할 값을 별도로 지정하지 않으면 `None`을 반환합니다.

반면, `add()` 함수는 계산 결과인 `15`를 반환하지만 화면에 직접 출력하지는 않습니다. 반환값은 `returned` 변수에 저장되며, 함수 외부의 `print()`를 통해 화면에 출력됩니다.

이처럼 값을 화면에 출력하는 것과 값을 반환하는 것은 서로 다른 동작입니다. 계산 결과를 다른 연산이나 함수에서 활용하려면 `return`을 사용하여 값을 반환하는 것이 좋습니다.

> `return` 뒤에 반환할 값을 작성하지 않고 `return`만 사용하면 함수의 실행을 종료하고 `None`을 반환합니다.

## 7.4.3. `return`이 실행되면 함수 끝내기

함수 내부에서 `return` 문이 실행되면 지정된 값을 반환하고 함수의 실행을 종료합니다. 따라서 현재 실행 흐름에서 `return` 문 이후에 남아 있는 코드는 실행되지 않습니다.

주문 금액이 10,000원 이상이면 주문 금액의 5%를 할인하고, 10,000원 미만이면 할인하지 않는 프로그램을 작성해 봅시다.

```python
def calculate_discount(total):
    if total < 10_000:
        return 0

    return total * 5 // 100


for total in [9_999, 12_000]:
    discount = calculate_discount(total)
    price = total - discount
    print(f"결제 금액: {price:,}원")
```

**실행 결과**

```text
결제 금액: 9,999원
결제 금액: 11,400원
```

주문 금액에 따라 함수의 실행 흐름은 다음과 같이 달라집니다.

- `9,999`원을 전달하면 `total < 10_000` 조건이 참이므로 `return 0`이 실행됩니다. 이 시점에서 함수의 실행이 종료되므로 아래에 있는 할인액 계산 코드는 실행되지 않습니다.
- `12,000`원을 전달하면 `total < 10_000` 조건이 거짓이므로 `if` 문 내부의 코드를 건너뜁니다. 이후 `return total * 5 // 100`이 실행되어 할인액인 `600`을 반환합니다.

함수 외부에서는 반환받은 할인액을 `discount` 변수에 저장하고, 주문 금액에서 할인액을 빼 최종 결제 금액을 계산합니다.

하나의 함수에 여러 개의 `return` 문을 작성할 수 있습니다. 조건문과 함께 사용하면 조건에 따라 서로 다른 값을 반환할 수 있습니다.

> `return` 문은 반복문을 종료하는 `break` 문과 달리 현재 함수의 실행을 종료합니다. 함수 내부의 반복문에서 `return` 문이 실행되더라도 반복문뿐만 아니라 함수 전체의 실행이 종료됩니다.

> Python에서는 매개변수와 반환값에 기대하는 자료형을 명시할 수 있습니다. 이를 **타입 힌트**(**Type Hint**)라고 합니다.
>
> ```python
> def add(left: int, right: int) -> int:
>     return left + right
> ```
>
> `left: int`와 `right: int`는 각 매개변수에 정수형 값을 전달할 것으로 기대한다는 의미이며, `-> int`는 함수의 반환값이 정수형일 것으로 기대한다는 의미입니다.
>
> 타입 힌트는 코드를 읽는 사람이나 코드 편집기, 정적 분석 도구에 자료형 정보를 제공합니다. Python은 타입 힌트만으로 실행 중에 자료형의 일치 여부를 자동으로 검사하거나 강제하지 않습니다.

## 확인 문제

1. 다음 코드를 실행하면 두 줄에 각각 무엇이 출력될까요?

   ```python
   def print_sum(left, right):
       print(left + right)


   result = print_sum(7, 2)
   print(result)
   ```

2. 다음 함수가 두 수의 차를 화면에 출력하는 대신 반환하도록 함수 내부의 코드를 한 줄 수정하세요. 수정한 코드를 실행하여 `차의 두 배: 10`이 출력되는지 확인하세요.

   ```python
   def difference(left, right):
       print(left - right)


   result = difference(9, 4)
   print(f"차의 두 배: {result * 2}")
   ```

3. 다음 함수는 전달받은 수가 음수이면 `0`을 반환하고, 그렇지 않으면 원래 값을 반환합니다. 두 번의 호출 결과를 차례대로 적어 보세요.

   ```python
   def non_negative(number):
       if number < 0:
           return 0

       return number


   print(non_negative(-3))
   print(non_negative(8))
   ```

4. 다음 코드를 실행하면 어떤 문구와 값이 출력될까요? 실행되지 않는 코드가 있다면 그 이유도 설명하세요.

   ```python
   def calculate():
       print("계산을 시작합니다.")
       return 10 + 5
       print("계산을 마쳤습니다.")


   result = calculate()
   print(result)
   ```

<summary>정답 확인</summary>

1. 다음과 같이 출력됩니다.

   ```text
   9
   None
   ```

   `print_sum()` 함수는 `7 + 2`를 계산하여 화면에 `9`를 출력합니다. 그러나 반환할 값을 지정하지 않았으므로 `result` 변수에는 `None`이 저장됩니다.

2. `print(left - right)`를 `return left - right`로 변경합니다.

   ```python
   def difference(left, right):
       return left - right


   result = difference(9, 4)
   print(f"차의 두 배: {result * 2}")
   ```

   **실행 결과**

   ```text
   차의 두 배: 10
   ```

   `difference(9, 4)`는 계산 결과인 `5`를 반환합니다. 반환값이 `result` 변수에 저장되므로 함수 외부에서 `result * 2`를 계산할 수 있습니다.

3. 다음과 같이 출력됩니다.

   ```text
   0
   8
   ```

   첫 번째 호출에서는 `number < 0` 조건이 참이므로 `return 0`이 실행되어 함수가 종료됩니다.

   두 번째 호출에서는 조건이 거짓이므로 `if` 문 내부의 코드를 건너뛰고 `return number`를 실행하여 `8`을 반환합니다.

4. 다음과 같이 출력됩니다.

   ```text
   계산을 시작합니다.
   15
   ```

   함수 내부의 첫 번째 `print()`가 실행된 뒤 `return 10 + 5`를 통해 `15`를 반환하고 함수의 실행을 종료합니다.

   따라서 `return` 문 아래에 있는 `print("계산을 마쳤습니다.")`는 실행되지 않습니다. 함수 외부에서는 반환값 `15`가 `result` 변수에 저장된 뒤 화면에 출력됩니다.
