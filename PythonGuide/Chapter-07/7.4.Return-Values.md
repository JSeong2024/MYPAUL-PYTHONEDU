# 7.4. Return Values

**함수의 반환값**

7.3절의 `print_sum()`은 합을 화면에 출력했습니다. 합을 두 배로 계산하거나 다른 함수에 넘기려면 계산 결과를 변수에 담아야 합니다. 이번에는 함수가 계산한 값을 호출한 쪽으로 돌려주도록 만들어 봅시다.

## 7.4.1. `return`으로 값 돌려주기

함수가 호출한 쪽에 돌려주는 값을 **반환값**(**Return Value**)이라고 합니다. `return` 뒤에 돌려줄 값을 적습니다.

```text
def 함수_이름(매개변수):
    (실행할 코드)
    return (돌려줄 값)

결과 = 함수_이름(인수)
```

```python
def add(left, right):
    return left + right


result = add(12, 3)
print(f"합: {result}")
print(f"합의 두 배: {result * 2}")
```

**실행 결과**

```text
합: 15
합의 두 배: 30
```

> `add(12, 3)`을 호출하면 함수에서 합을 구해 `15`를 돌려줍니다. 그 값이 `result`에 들어갑니다. 이후 호출한 쪽에서 `result`를 출력하거나 다른 계산에 쓸 수 있습니다.

## 7.4.2. `print()`와 `return` 비교하기

같은 두 수를 더하는 함수를 각각 호출하고, 호출 결과를 변수에 저장해 봅시다.

```python
def print_sum(left, right):
    print(f"합: {left + right}")


def add(left, right):
    return left + right


printed = print_sum(12, 3)
returned = add(12, 3)

print(f"print_sum()의 반환값: {printed}")
print(f"add()의 반환값: {returned}")
```

**실행 결과**

```text
합: 15
print_sum()의 반환값: None
add()의 반환값: 15
```

`print_sum()`은 화면에 합을 표시하고, `return` 없이 끝나므로 `None`을 반환합니다. 이때 `None`은 돌려준 결과값이 없음을 나타냅니다. `add()`는 합을 돌려주고, 그 값을 화면에 보여 주는 작업은 함수 밖의 `print()`가 맡습니다.

## 7.4.3. `return`이 실행되면 함수 끝내기

한 번 호출한 함수에서 `return`을 실행하면 값을 돌려주고 그 호출을 마칩니다. 아래 함수에서 주문 금액이 10,000원 미만이면 첫 번째 `return`으로 끝납니다.

```python
def calculate_discount(total):
    if total < 10_000:
        return 0

    return total * 5 // 100


for total in [9_999, 12_000]:
    discount = calculate_discount(total)
    price = total - discount
    print(f"결제 금액: {price:,}원")
```

**실행 결과**

```text
결제 금액: 9,999원
결제 금액: 11,400원
```

9,999원 주문은 `return 0`에서 함수가 끝납니다. 12,000원 주문은 첫 조건이 거짓이므로 아래에서 5%인 600원을 돌려줍니다. 두 경우 모두 함수 밖에서 받은 할인액을 주문 금액에서 뺍니다.

> `def add(left: int, right: int) -> int:`처럼 매개변수와 반환값에 기대하는 자료형을 표시할 수 있습니다. 이를 **타입 힌트**(**Type Hint**)라고 합니다. 이 표시는 자료형을 알려 주며, 실행 중에 자료형을 자동으로 검사하지는 않습니다.

## 확인 문제

1. 다음 코드에서 두 줄에 각각 무엇이 출력될까요?

   ```python
   def print_sum(left, right):
       print(left + right)


   result = print_sum(7, 2)
   print(result)
   ```

2. 아래 함수가 두 수의 차를 화면에 출력하는 대신 호출한 쪽에 돌려주도록 함수 내부의 한 줄을 바꿔 보세요. 수정한 뒤 `차의 두 배: 10`이 출력되는지 확인하세요.

   ```python
   def difference(left, right):
       print(left - right)


   result = difference(9, 4)
   print(f"차의 두 배: {result * 2}")
   ```

3. 입력값이 음수일 때는 0을, 그 외에는 원래 값을 돌려주는 함수입니다. 두 호출의 결과를 차례대로 적어 보세요.

   ```python
   def non_negative(number):
       if number < 0:
           return 0

       return number


   print(non_negative(-3))
   print(non_negative(8))
   ```

<details>
<summary>정답 확인</summary>

1. 첫 줄에 `9`, 두 번째 줄에 `None`이 출력됩니다. 함수는 합을 출력하고 `return` 없이 끝납니다.
2. `print(left - right)`를 `return left - right`로 바꿉니다. `result`가 `5`이므로 `차의 두 배: 10`이 출력됩니다.
3. 첫 줄에 `0`, 두 번째 줄에 `8`이 출력됩니다. `-3`을 넘긴 호출은 첫 `return`에서 끝납니다.

</details>
