# 5.1. Conditions

카페에서 주문을 받으려면 먼저 주문한 메뉴가 등록되어 있는지 확인해야 합니다. 결제를 진행할 때는 손님에게 받은 돈이 결제 금액 이상인지 확인합니다. 두 질문 모두 ‘예(참)’ 또는 ‘아니요(거짓)’로 명확하게 답할 수 있습니다.

프로그램에서 이처럼 **참(`True`)인지 거짓(`False`)인지 판단할 기준**을 **조건**(**Condition**)이라고 합니다. 조건을 평가한 결과는 항상 불리언(`bool`) 자료형인 `True` 또는 `False`로 나옵니다. 챕터 2에서 배운 비교 연산자와 챕터 4에서 배운 `in` 연산자를 활용해 조건을 만들어 봅시다.

## 5.1.1. 값 비교하기

손님이 낸 돈과 결제 금액이 모두 7,300원이라고 가정해 봅시다. 받은 돈이 결제 금액 **이상**인지 확인하려면 비교 연산자 `>=`를 사용합니다.

```python
price = 7_300
paid = 7_300

can_pay = paid >= price
print(can_pay)

paid = 7_299
print(paid >= price)
```

**실행 결과**

```text
True
False
```

`paid >= price`는 ‘받은 돈이 결제 금액 이상인가?’를 묻는 조건입니다. 두 금액이 7,300원으로 같을 때도 ‘이상’이라는 조건을 만족하므로 첫 번째 결과는 `True`가 됩니다. 반면 1원이 부족한 7,299원을 낸 두 번째 경우는 조건을 만족하지 못하므로 `False`가 출력됩니다.

> `can_pay = paid >= price`에서 `=`는 오른쪽의 비교 연산 결과(`True` 또는 `False`)를 왼쪽 변수에 저장하는 대입 연산자입니다. 두 값이 서로 같은지 비교할 때는 `==`를 사용해야 하므로 혼동하지 않도록 주의하세요.

## 5.1.2. 메뉴가 등록되어 있는지 확인하기

멤버십 연산자 `in`을 딕셔너리와 함께 사용하면 특정 값이 딕셔너리의 **키**(**Key**)로 등록되어 있는지 확인할 수 있습니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

print("커피" in menu)
print("주스" in menu)
```

**실행 결과**

```text
True
False
```

‘커피가 메뉴판(`menu`)에 등록되어 있는가?’는 참이므로 `True`가 나오고, ‘주스가 메뉴판에 등록되어 있는가?’는 거짓이므로 `False`가 나옵니다.

> 딕셔너리에서 `in` 연산자는 기본적으로 **키**(**Key**)만 검사합니다. 만약 `4800 in menu`처럼 가격(값)을 기준으로 확인하면 키 목록에 `4800`이 없으므로 `False`를 반환합니다.

지금까지는 조건을 판단한 결과를 단순히 화면에 출력하기만 했습니다. 5.2절에서는 ‘만약 메뉴가 등록되어 있다면 가격을 출력한다’처럼, 조건의 결과에 따라 실행할 코드를 다르게 선택하는 방법을 배웁니다.
