# 5.1. Conditions

카페에서 주문을 받으려면 먼저 메뉴가 등록되어 있는지 확인해야 합니다. 결제할 때는 받은 돈이 결제 금액 이상인지 확인합니다. 두 질문은 모두 참 또는 거짓으로 답할 수 있습니다.

프로그램에서 이렇게 **참인지 거짓인지 판단할 기준**을 조건이라고 합니다. 챕터 2에서 배운 비교 연산자와 챕터 4에서 배운 `in`으로 조건을 만들어 봅시다.

## 5.1.1. 값 비교하기

손님이 낸 돈과 결제 금액이 모두 7,300원입니다. 받은 돈이 결제 금액 **이상**인지 확인하려면 `>=`를 씁니다.

```python
price = 7_300
paid = 7_300

can_pay = paid >= price
print(can_pay)

paid = 7_299
print(paid >= price)
```

**실행 결과**

```text
True
False
```

`paid >= price`는 ‘받은 돈이 결제 금액 이상인가?’라는 뜻입니다. 두 금액이 같아도 참이므로 첫 결과는 `True`입니다. 1원이 부족한 두 번째 경우는 `False`입니다.

> `can_pay = paid >= price`에서 `=`는 오른쪽 비교의 결과를 변수에 저장합니다. 두 값이 같은지 비교할 때는 `==`를 사용합니다.

## 5.1.2. 메뉴가 등록되어 있는지 확인하기

`in`을 딕셔너리와 함께 쓰면 찾는 값이 **키**로 등록되어 있는지 확인할 수 있습니다.

```python
menu = {"커피": 4800, "쿠키": 2500}

print("커피" in menu)
print("주스" in menu)
```

**실행 결과**

```text
True
False
```

‘커피가 가격표에 있는가?’는 참이고, ‘주스가 가격표에 있는가?’는 거짓입니다. 지금은 판단 결과를 화면에 출력했습니다. 5.2에서는 ‘만약 메뉴가 등록되어 있다면 가격을 출력한다’처럼, 그 결과에 따라 실행할 코드를 정합니다.
