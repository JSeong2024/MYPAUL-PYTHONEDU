# 5.5. Nested Conditions

카페에서 주문한 메뉴의 가격을 읽으려면 먼저 가격표에 등록된 메뉴인지 확인해야 합니다. 등록되어 있다면 그때 가격을 읽고, 받은 돈이 충분한지 확인합니다.

## 5.5.1. 조건문 안에 조건문 넣기

`if` 블록 안에 또 다른 `if`를 넣는 구조를 **중첩 조건문**(**Nested Conditional Statement**)이라고 합니다. 안쪽 `if`는 바깥쪽 `if`의 블록에 속하므로, 바깥 조건이 참일 때만 검사합니다.

```text
if (조건1):
    if (조건2):
        (코드1)
    else:
        (코드2)
else:
    (코드3)
(코드4)
```

> 만약 조건1이 참이라면 조건2를 검사합니다. 조건2도 참이라면 코드1을, 그게 아니라면 코드2를 실행합니다.  
> 조건1이 거짓이라면 안쪽 조건문을 건너뛰고 코드3을 실행합니다.

코드4는 조건문 밖에 있으므로 어느 분기를 거쳤든 그다음에 실행됩니다. 들여쓰기를 비교하면 어느 `else`가 어느 `if`에 속하는지 알 수 있습니다. 안쪽 `if`와 `else`는 공백 네 칸, 그 아래 실행할 코드는 공백 여덟 칸을 들여씁니다.

## 5.5.2. 메뉴를 확인한 뒤 결제하기

바깥 조건문은 주문한 메뉴가 등록되어 있는지 확인합니다. 등록되어 있으면 `menu[item]`으로 가격을 읽고, 안쪽 조건문에서 받은 돈과 비교합니다.

```python
menu = {"커피": 4800, "쿠키": 2500}
item = "커피"
paid = 5000

if item in menu:
    price = menu[item]

    if paid >= price:
        change = paid - price
        print(f"결제 완료. 거스름돈은 {change:,}원입니다.")
    else:
        shortage = price - paid
        print(f"{shortage:,}원이 부족합니다.")
else:
    print(f"판매하지 않는 메뉴입니다. ({item})")

print("주문 확인을 마쳤습니다.")
```

**실행 결과**

```text
결제 완료. 거스름돈은 200원입니다.
주문 확인을 마쳤습니다.
```

## 5.5.3. 조건을 묶을 때와 중첩할 때

5.4에서 배운 `and`로도 두 조건을 함께 확인할 수 있습니다. 다음처럼 쓰면 `item in menu`가 참일 때만 오른쪽의 가격 비교를 검사합니다.

```python
menu = {"커피": 4800, "쿠키": 2500}
item = "주스"
paid = 5000

if item in menu and paid >= menu[item]:
    print("결제할 수 있습니다.")
else:
    print("결제할 수 없습니다.")
```

**실행 결과**

```text
결제할 수 없습니다.
```

결제 가능 여부만 알려 주려면 이 형태로 충분합니다. 메뉴가 없을 때와 돈이 부족할 때 **서로 다른 안내**를 보여 주려면 5.5.2처럼 각각의 경우를 나누어 처리할 수 있습니다.
