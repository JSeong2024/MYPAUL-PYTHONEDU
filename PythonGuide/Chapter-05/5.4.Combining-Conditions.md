# 5.4. Combining Conditions

카페에서 회원 할인을 받으려면 회원이어야 하고, 주문 금액도 10,000원 이상이어야 합니다. 이처럼 한 가지 결정을 내리기 위해 여러 조건을 확인할 때는 `and`, `or`, `not`을 사용합니다.

## 5.4.1. `and` — 두 조건이 모두 참일 때

`and`로 연결한 조건은 양쪽이 모두 참일 때 참입니다.

```python
is_member = True
total = 10_000

if is_member and total >= 10_000:
    print("회원 할인을 적용합니다.")
else:
    print("회원 할인을 적용하지 않습니다.")
```

**실행 결과**

```text
회원 할인을 적용합니다.
```

> 만약 회원이면서 주문 금액이 10,000원 이상이라면 회원 할인을 적용합니다. 그게 아니라면 회원 할인을 적용하지 않습니다.

<table align="center">
  <thead>
    <tr><th>회원 여부</th><th>주문 금액</th><th>할인 적용</th></tr>
  </thead>
  <tbody>
    <tr><td>회원</td><td>10,000원</td><td>예</td></tr>
    <tr><td>회원</td><td>9,999원</td><td>아니요</td></tr>
    <tr><td>비회원</td><td>10,000원</td><td>아니요</td></tr>
    <tr><td>비회원</td><td>9,999원</td><td>아니요</td></tr>
  </tbody>
</table>

`is_member`에는 이미 참·거짓 값이 들어 있으므로 `is_member == True`로 비교할 필요가 없습니다.

## 5.4.2. `or` — 둘 중 하나 이상이 참일 때

쿠폰이 있거나 주문 금액이 30,000원 이상이면 배송비를 면제한다고 가정해 봅시다.

```python
has_coupon = False
total = 30_000

if has_coupon or total >= 30_000:
    print("배송비를 면제합니다.")
else:
    print("배송비가 부과됩니다.")
```

**실행 결과**

```text
배송비를 면제합니다.
```

> 만약 쿠폰이 있거나 주문 금액이 30,000원 이상이라면 배송비를 면제합니다. 두 조건이 모두 참이어도 배송비를 면제합니다.

쿠폰은 없어도 금액 조건을 충족하므로 이 예제에서는 배송비가 면제됩니다. `has_coupon`을 `True`로, `total`을 `29_999`로 바꾸어도 결과는 같습니다. 두 조건이 모두 거짓일 때만 `else`가 실행됩니다.

## 5.4.3. `not` — 참과 거짓 뒤집기

`not`은 뒤에 오는 조건의 참과 거짓을 뒤집습니다. 영업 중인지 나타내는 값으로 마감 안내를 표시해 봅시다.

```python
is_open = False

if not is_open:
    print("오늘 영업은 끝났습니다.")
```

**실행 결과**

```text
오늘 영업은 끝났습니다.
```

> 만약 영업 중이 아니라면 마감 안내를 출력합니다.

`is_open`이 `False`이므로 `not is_open`은 `True`입니다. 메뉴 등록 여부를 검사할 때는 `if item not in menu:`처럼 쓸 수 있습니다. ‘만약 주문한 메뉴가 가격표에 없다면’이라는 뜻입니다.

## 5.4.4. 괄호로 조건 묶기

가게가 문을 열었고, 주문 방법이 방문 수령 또는 배달일 때만 주문을 받는다고 가정해 봅시다.

```python
is_open = False
method = "배달"

if is_open and (method == "방문 수령" or method == "배달"):
    print("주문을 접수합니다.")
else:
    print("주문을 접수할 수 없습니다.")
```

**실행 결과**

```text
주문을 접수할 수 없습니다.
```

> 만약 가게가 영업 중이고, 주문 방법이 방문 수령이나 배달이라면 주문을 접수합니다.

괄호를 빼면 `and`가 `or`보다 먼저 묶입니다. 그러면 `(is_open and method == "방문 수령") or method == "배달"`로 판단하므로, 가게가 문을 닫아도 배달 주문은 접수됩니다. 두 주문 방법에 영업 조건을 공통으로 적용하려면 위 예제처럼 주문 방법을 괄호로 묶습니다.

## 확인 문제

1. 회원이 9,999원을 주문하면 5.4.1에서 어떤 문장이 출력될까요?
2. 쿠폰이 있고 주문 금액도 30,000원 이상이라면 5.4.2에서 배송비가 면제될까요?
3. `item`이 `"물"`이고 `menu = {"물": 0}`일 때, `item not in menu`는 참일까요?
4. 5.4.4에서 괄호를 빼고 가게가 문을 닫은 상태에서 배달을 선택하면 어떤 문장이 출력될까요?

<details>
<summary>정답 확인</summary>

1. 금액 조건이 거짓이므로 `회원 할인을 적용하지 않습니다.`가 출력됩니다.
2. 면제됩니다. `or`는 두 조건이 모두 참이어도 참입니다.
3. 거짓입니다. 가격이 0원이어도 물은 가격표에 등록된 키입니다.
4. `주문을 접수합니다.`가 출력됩니다. 영업 여부와 방문 수령 조건이 먼저 묶이고, 배달 조건만 참이어도 전체가 참이 됩니다.

</details>
