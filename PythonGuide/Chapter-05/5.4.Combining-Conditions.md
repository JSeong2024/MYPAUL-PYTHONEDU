# 5.4. Combining Conditions

카페에서 회원 할인을 받으려면 회원이어야 하고, 주문 금액도 10,000원 이상이어야 합니다. 파이썬에서는 `and`, `or`, `not` 같은 **논리 연산자**(**Logical Operator**)를 사용해 여러 조건을 하나로 연결하거나 참과 거짓을 반대로 뒤집을 수 있습니다.

## 5.4.1. `and` — 두 조건이 모두 참일 때

`and` 연산자로 연결한 조건식은 양쪽의 두 조건이 **모두 참(`True`)**일 때만 전체 결과가 참이 됩니다. 둘 중 하나라도 거짓이면 전체는 거짓(`False`)으로 평가됩니다.

```python
is_member = True
total = 10_000

if is_member and total >= 10_000:
    print("회원 할인을 적용합니다.")
else:
    print("회원 할인을 적용하지 않습니다.")
```

**실행 결과**

```text
회원 할인을 적용합니다.
```

> 만약 회원이고 주문 금액이 10,000원 이상이라면 회원 할인을 적용합니다. 두 조건 중 하나라도 만족하지 못하면 할인을 적용하지 않습니다.

  <thead>
    <tr><th>회원 여부</th><th>주문 금액</th><th>할인 적용</th></tr>
  </thead>
  <tbody>
    <tr><td>회원</td><td>10,000원</td><td>예</td></tr>
    <tr><td>회원</td><td>9,999원</td><td>아니요</td></tr>
    <tr><td>비회원</td><td>10,000원</td><td>아니요</td></tr>
    <tr><td>비회원</td><td>9,999원</td><td>아니요</td></tr>
  </tbody>
</table>

> `is_member` 변수에는 이미 불리언 값(`True` 또는 `False`)이 저장되어 있으므로 `if is_member == True:`처럼 길게 쓰지 않고 `if is_member:`라고 간결하게 작성해도 됩니다.

## 5.4.2. `or` — 둘 중 하나 이상이 참일 때

`or` 연산자로 연결한 조건식은 양쪽 조건 중 **어느 하나라도 참**이면 전체가 참으로 평가됩니다. 예를 들어 할인 쿠폰이 있거나 주문 금액이 30,000원 이상이면 배송비를 면제해 주는 경우를 살펴봅시다.

```python
has_coupon = False
total = 30_000

if has_coupon or total >= 30_000:
    print("배송비를 면제합니다.")
else:
    print("배송비가 부과됩니다.")
```

**실행 결과**

```text
배송비를 면제합니다.
```

> 만약 쿠폰이 있거나 주문 금액이 30,000원 이상이라면 배송비를 면제합니다. 두 조건이 모두 참인 경우에도 마찬가지로 배송비가 면제됩니다.

위 예제에서는 두 번째 조건인 금액 조건만 참입니다. 만약 `has_coupon`을 `True`로, `total`을 `29_999`로 바꾸면 이번에는 쿠폰 조건만 참이 되지만 실행 결과는 똑같습니다. `or`로 연결한 조건은 양쪽 조건이 모두 거짓일 때만 `else` 분기가 실행됩니다.

> `and`와 `or` 연산자는 왼쪽 조건만으로 전체 결과가 이미 확정되면 오른쪽 조건은 아예 검사하지 않고 건너뜁니다. 이를 **단락 평가**(**Short-circuit Evaluation**)라고 합니다. 예를 들어 `and`에서 왼쪽이 `False`이거나, `or`에서 왼쪽이 `True`이면 뒤쪽 조건은 평가하지 않습니다.

## 5.4.3. `not` — 참과 거짓 뒤집기

`not` 연산자는 조건의 논리값을 반대로 뒤집어, 참이면 `False`를, 거짓이면 `True`를 반환합니다. 가게의 영업 상태 변수를 이용해 마감 안내를 출력해 봅시다.

```python
is_open = False

if not is_open:
    print("오늘 영업은 끝났습니다.")
```

**실행 결과**

```text
오늘 영업은 끝났습니다.
```

> 만약 영업 중이 아니라면(`not is_open`) 영업 마감 안내 문구를 출력합니다.

현재 `is_open`이 `False`이므로 `not is_open`은 `True`가 되어 안내 문구가 출력됩니다. 또한 `not`은 5.1.2절에서 배운 `in` 연산자와 결합해 `not in` 형태로도 자주 쓰입니다. 예를 들어 `if item not in menu:`는 ‘만약 주문한 메뉴가 메뉴판에 등록되어 있지 않다면’이라는 뜻으로 자연스럽게 읽을 수 있습니다.

> `not is_open`은 `is_open == False`와 같은 의미이지만, 파이썬에서는 `not`을 사용하는 표현을 훨씬 더 자연스럽고 읽기 좋은 코드로 권장합니다.

지금까지 배운 세 가지 논리 연산자의 동작을 정리하면 다음과 같습니다.

| 연산자 | 사용 예시 | 참(`True`)이 되는 조건 | 설명 |
| :---: | :---: | :---: | :---: |
| `and` | `A and B` | `A`와 `B`가 모두 참일 때 | 두 조건을 동시에 만족해야 할 때 사용 |
| `or` | `A or B` | `A` 또는 `B` 중 하나라도 참일 때 | 여러 조건 중 하나만 만족해도 될 때 사용 |
| `not` | `not A` | `A`가 거짓(`False`)일 때 | 기존 조건의 참·거짓 결과를 반대로 뒤집음 |

## 5.4.4. 괄호로 조건 묶기

가게가 현재 영업 중이어야 하고, 동시에 주문 방법이 `'방문 수령'` 또는 `'배달'`일 때만 주문을 접수하는 프로그램을 작성해 봅시다.

```python
is_open = False
method = "배달"

if is_open and (method == "방문 수령" or method == "배달"):
    print("주문을 접수합니다.")
else:
    print("주문을 접수할 수 없습니다.")
```

**실행 결과**

```text
주문을 접수할 수 없습니다.
```

> 만약 가게가 영업 중이고, 주문 방법이 방문 수령이나 배달 중 하나라면 주문을 접수합니다.

만약 위 코드에서 괄호를 빼면 **연산자 우선순위**(**Operator Precedence**)에 따라 `and`가 `or`보다 먼저 계산되어 다음과 같이 묶입니다.

```python
print((is_open and method == "방문 수령") or method == "배달")
```

위 예제의 변수값(`is_open = False`, `method = "배달"`)으로 이 코드를 실행하면 의도와 달리 `True`가 출력됩니다. 가게가 닫혀 있어 왼쪽의 `(is_open and method == "방문 수령")` 부분은 거짓이 되지만, `or` 오른쪽의 `method == "배달"` 조건만 참이어도 전체 결과가 참이 되기 때문입니다. 이처럼 두 주문 방법에 영업 조건을 공통으로 적용하려면 처음 예제처럼 `or`로 연결한 두 조건을 괄호로 명확하게 묶어 주어야 합니다.

> 논리 연산자는 **`not` → `and` → `or`** 순서로 우선순위가 높습니다. 연산 순서가 헷갈리거나 여러 조건을 함께 조합할 때는 실행 순서를 명확히 드러내기 위해 괄호 `()`를 적극적으로 사용하는 것이 좋습니다.

## 확인 문제

2. 할인 쿠폰이 있고 주문 금액도 `30,000`원 이상이라면, 5.4.2절의 코드에서 배송비가 면제될까요?
3. `item`이 `"물"`이고 `menu = {"물": 0}`일 때, 조건식 `item not in menu`는 참(`True`)일까요, 거짓(`False`)일까요?
4. 5.4.4절의 조건식에서 괄호를 제거한 뒤, 가게가 문을 닫은 상태(`is_open = False`)에서 주문 방법을 `"배달"`로 선택하면 어떤 문장이 출력될까요?
