# 5.4. Combining Conditions

카페에서 회원 할인을 받으려면 회원이어야 하고, 주문 금액도 10,000원 이상이어야 합니다. 파이썬에서는 `and`, `or`, `not` 같은 **논리 연산자**(**Logical Operator**)로 조건을 연결하거나 참과 거짓을 뒤집을 수 있습니다.

## 5.4.1. `and` — 두 조건이 모두 참일 때

`and`로 연결한 두 조건은 모두 참일 때만 전체가 참입니다.

```python
is_member = True
total = 10_000

if is_member and total >= 10_000:
    print("회원 할인을 적용합니다.")
else:
    print("회원 할인을 적용하지 않습니다.")
```

**실행 결과**

```text
회원 할인을 적용합니다.
```

> 만약 회원이고 주문 금액이 10,000원 이상이라면 회원 할인을 적용합니다. 그게 아니라면 할인을 적용하지 않습니다.

  <thead>
    <tr><th>회원 여부</th><th>주문 금액</th><th>할인 적용</th></tr>

> `is_member`에 이미 `True` 또는 `False`가 들어 있으므로 `if is_member:`라고 써도 됩니다.

## 5.4.2. `or` — 둘 중 하나 이상이 참일 때

`or` 연산자로 연결한 조건식은 양쪽 조건 중 **어느 하나라도 참**이면 전체가 참으로 평가됩니다. 예를 들어 할인 쿠폰이 있거나 주문 금액이 30,000원 이상이면 배송비를 면제해 주는 경우를 살펴봅시다.

```python
has_coupon = False
total = 30_000

if has_coupon or total >= 30_000:
    print("배송비를 면제합니다.")
else:
    print("배송비가 부과됩니다.")
```

**실행 결과**

```text
배송비를 면제합니다.
```

> 만약 쿠폰이 있거나 주문 금액이 30,000원 이상이라면 배송비를 면제합니다. 두 조건이 모두 참이어도 면제합니다.

위 예제에서는 금액 조건만 참입니다. `has_coupon`을 `True`로, `total`을 `29_999`로 바꾸면 쿠폰 조건만 참이지만 결과는 같습니다. 두 조건이 모두 거짓일 때만 `else`가 실행됩니다.

## 5.4.3. `not` — 참과 거짓 뒤집기

`not`은 조건이 참이면 `False`, 거짓이면 `True`를 반환합니다. 가게의 영업 여부로 마감 안내를 표시해 봅시다.

```python
is_open = False

if not is_open:
    print("오늘 영업은 끝났습니다.")
```

**실행 결과**

```text
오늘 영업은 끝났습니다.
```

> 만약 영업 중이 아니라면(`not is_open`) 영업 마감 안내 문구를 출력합니다.

`is_open`이 `False`이므로 `not is_open`은 `True`입니다. `if item not in menu:`는 ‘만약 주문한 메뉴가 가격표에 없다면’으로 읽을 수 있습니다.

## 5.4.4. 괄호로 조건 묶기

가게가 영업 중이어야 하고, 동시에 주문 방법이 '방문 수령' 또는 '배달'일 때만 주문을 접수하는 프로그램을 작성해 봅시다.

```python
is_open = False
method = "배달"

if is_open and (method == "방문 수령" or method == "배달"):
    print("주문을 접수합니다.")
else:
    print("주문을 접수할 수 없습니다.")
```

**실행 결과**

```text
주문을 접수할 수 없습니다.
```

> 만약 가게가 영업 중이고, 주문 방법이 방문 수령이나 배달이라면 주문을 접수합니다.

괄호를 빼면 **연산자 우선순위**(**Operator Precedence**)에 따라 `and`가 `or`보다 먼저 묶입니다.

```python
print((is_open and method == "방문 수령") or method == "배달")
```

위 예제의 변수로 이 줄을 실행하면 `True`가 출력됩니다. 가게가 닫혀 있어 왼쪽은 거짓이지만, 배달 조건만 참이어도 전체가 참이기 때문입니다. 두 주문 방법에 영업 조건을 공통으로 적용하려면 처음 예제처럼 `or`로 연결한 두 조건을 괄호로 묶습니다.

## 확인 문제

1. 회원이 `9,999`원을 주문하면 5.4.1절의 코드에서는 어떤 문장이 출력될까요?
2. 할인 쿠폰이 있고 주문 금액도 `30,000`원 이상이라면, 5.4.2절의 코드에서 배송비가 면제될까요?
3. `item`이 `"물"`이고 `menu = {"물": 0}`일 때, 조건식 `item not in menu`는 참(`True`)일까요, 거짓(`False`)일까요?
4. 5.4.4절의 조건식에서 괄호를 제거한 뒤, 가게가 문을 닫은 상태(`is_open = False`)에서 주문 방법을 `"배달"`로 선택하면 어떤 문장이 출력될까요?

<details>
<summary>정답 확인</summary>

1. 주문 금액 조건(`total >= 10_000`)이 거짓이므로 `회원 할인을 적용하지 않습니다.`가 출력됩니다.
2. **네, 면제됩니다.** `or` 연산자는 양쪽 조건이 모두 참일 때도 전체 결과를 참(`True`)으로 평가합니다.
3. **거짓(`False`)입니다.** 가격이 `0`원이라도 `"물"`은 `menu` 딕셔너리에 등록된 키이므로 `item in menu`가 참이 되고, 이를 뒤집은 `item not in menu`는 거짓이 됩니다.
4. `주문을 접수합니다.`가 출력됩니다. 괄호가 없으면 `and`가 먼저 결합하여 `(is_open and method == "방문 수령")` 부분이 거짓이 되더라도, 뒤쪽의 `method == "배달"` 조건이 참이므로 `or` 연산 전체가 참으로 평가되기 때문입니다.
