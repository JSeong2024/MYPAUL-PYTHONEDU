# 5.2. If & Else

외출하기 전에 창밖을 봅니다. 비가 오는지에 따라 우산을 챙길지 결정합니다.

> 비가 온다 → 우산을 가져간다.  
> 비가 오지 않는다 → 우산을 가져가지 않는다.

프로그램에서도 **조건문**(**Conditional Statement**)을 쓰면, 잔액이 충분할 때만 결제를 진행하는 것처럼 조건에 따라 실행할 코드를 정할 수 있습니다.

## 5.2.1. `if` — 조건을 만족할 때 실행하기

`if` 키워드 뒤에 검사할 조건식을 적고 줄 끝에 콜론(`:`)을 붙입니다. 조건을 만족할 때 실행할 코드는 다음 줄에 **들여쓰기**(**Indentation**)를 적용해 작성합니다.

```text
if (조건):
    (코드1)
(코드2)
```

조건이 참이면 코드1을 실행한 뒤 코드2를 실행합니다. 조건이 거짓이면 코드2만 실행합니다. 파이썬에서는 **불리언**(**Boolean**) 값 `True`와 정수 `1`이 모두 참으로 평가되며, 반대로 `False`와 정수 `0`은 거짓으로 평가됩니다. 또한 조건식을 감싸는 괄호 `()`는 생략할 수 있습니다.

```python
is_raining = True

if is_raining:
    print("우산을 챙깁니다.")

print("외출합니다.")
```

**실행 결과**

```text
우산을 챙깁니다.
외출합니다.
```

이제 첫 줄의 `is_raining = True`를 `is_raining = False`로 바꾼 뒤 다시 실행해 보세요. 우산을 챙긴다는 문장은 건너뛰고 마지막 줄의 `외출합니다.`만 출력되는 것을 확인할 수 있습니다.

## 5.2.2. 들여쓰기로 실행 범위 정하기

들여쓰기를 보면 어느 줄까지 `if`에 속하는지 알 수 있습니다.

```text
if (조건):
    (코드1)
(코드2)
```

> 조건이 참이면, 코드1 실행 → 코드2 실행  
> 조건이 거짓이면, 코드2만 실행

`코드1`은 안쪽으로 들여썼기 때문에 `if` 블록 내부에 포함됩니다. 반면 `코드2`는 `if`와 같은 위치에서 시작하므로 조건의 참·거짓 여부와 관계없이 항상 실행됩니다.

같은 블록에 속한 문장은 같은 깊이로 들여씁니다. 아래 예제에서는 공백 네 칸을 사용했습니다.

```python
is_raining = False

if is_raining:
    print("우산을 챙깁니다.")
    print("우산을 펼칩니다.")

print("외출합니다.")
```

**실행 결과**

```text
외출합니다.
```

앞선 두 개의 `print()` 문은 모두 `if` 블록에 속해 있고, 마지막 `print()` 문은 `if`와 같은 열에서 시작하므로 조건과 무관하게 실행됩니다.

> 만약 마지막 `print("외출합니다.")` 줄에도 공백 네 칸을 넣어 함께 들여쓰면 어떻게 될까요?
> ```python
> is_raining = False
>
> if is_raining:
>     print("우산을 챙깁니다.")
>     print("우산을 펼칩니다.")
>
>     print("외출합니다.")
> ```
> 세 줄 모두 `if` 블록에 포함되므로, 조건 `is_raining`이 `False`일 때 세 문장을 전부 건너뛰어 화면에 아무것도 출력되지 않습니다.

## 5.2.3. `else` — 조건을 만족하지 않을 때 실행하기

비가 오지 않을 때도 별도의 안내 문구를 표시하려면 `else`를 함께 사용합니다. `else:`는 `if`와 같은 세로 위치에 맞춰 적고, 조건이 거짓일 때 실행할 코드는 그 아래에 들여써서 작성합니다.

```text
if (조건):
    (코드1)
else:
    (코드2)
(코드3)
```

> 조건이 참이면 → 코드1 실행 → 코드3 실행  
> 조건이 거짓이면 → 코드2 실행 → 코드3 실행

코드3은 조건문 밖에 있으므로 어느 쪽이 실행되어도 그다음에 실행됩니다.

```python
is_raining = False

if is_raining:
    print("우산을 챙깁니다.")
else:
    print("우산을 두고 나갑니다.")

print("외출합니다.")
```

**실행 결과**

```text
우산을 두고 나갑니다.
외출합니다.
```

`is_raining` 값을 `True`로 바꾸어 실행하면 첫 번째 출력 줄이 `우산을 챙깁니다.`로 바뀝니다. 이처럼 `if`와 `else` 블록 중 어느 한쪽만 선택적으로 실행되며, 조건문 바깥에 있는 마지막 외출 안내는 두 경우 모두 공통으로 출력됩니다.

> 조건이 거짓일 때 특별히 처리할 작업이 없다면 `else` 없이 `if` 문만 단독으로 작성하면 됩니다.
> ```python
> is_raining = False
>
> if is_raining:
>     print("우산을 챙깁니다.")
> 
> print("외출합니다.")
> ```

## 5.2.4. 등록된 메뉴의 가격만 읽기

앞선 챕터 4에서 만든 카페 가격표 딕셔너리에 손님이 주문한 메뉴가 등록되어 있는지 확인해 봅시다. `item in menu` 표현식은 `item` 변수에 담긴 메뉴 이름이 `menu` 딕셔너리의 키로 존재하는지 검사하여 참 또는 거짓을 알려 줍니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "물": 0}
item = "쿠키"

if item in menu:
    print(f"{item}: {menu[item]:,}원")
else:
    print(f"판매하지 않는 메뉴입니다. ({item})")
```

**실행 결과**

```text
쿠키: 2,500원
```

`item` 변수에 대입하는 메뉴 이름을 바꾸어 가며 세 가지 경우의 실행 결과를 비교해 보세요.

<table align="center">
  <thead>
    <tr><th>주문 메뉴</th><th>실행되는 분기</th><th>출력</th></tr>
  </thead>
  <tbody>
    <tr><td>쿠키</td><td><code>if</code></td><td>쿠키: 2,500원</td></tr>
    <tr><td>물</td><td><code>if</code></td><td>물: 0원</td></tr>
    <tr><td>주스</td><td><code>else</code></td><td>판매하지 않는 메뉴입니다. (주스)</td></tr>
  </tbody>
</table>

`물`은 가격이 `0`원이지만 딕셔너리에 등록된 키이므로 `if` 분기가 정상적으로 실행됩니다. 반면 `주스`를 주문하면 등록되지 않은 메뉴이므로 `else` 분기가 실행됩니다. 이때 `menu[item]`을 조회하는 `if` 내부 코드를 건너뛰기 때문에, 존재하지 않는 키를 읽을 때 발생하는 `KeyError` 예외도 안전하게 예방할 수 있습니다.

## 확인 문제

1. `is_raining` 변수가 `False`일 때, 위 우산 예제에서 `else` 블록 전체를 지우면 화면에 어떤 문장만 남을까요?
2. 결제할 상품 금액이 `7,300`원입니다. 손님에게 받은 돈을 `paid` 변수에 저장한 뒤, 금액이 충분하면 `결제할 수 있습니다.`를, 부족하면 `금액이 부족합니다.`를 출력하는 조건문을 작성해 보세요. 작성을 마친 뒤 `paid`가 `7300`일 때와 `7299`일 때도 각각 정상 동작하는지 확인해 보세요.
3. 가격표 예제의 조건문은 그대로 두고, `print(f"{item}: {menu[item]:,}원")`을 조건문 아래에 들여쓰기 없이 한 줄 더 추가합니다. `item`에 `"주스"`를 넣고 실행하면 어떤 일이 생길까요?

<details>
<summary>정답 확인</summary>

1. `if` 블록을 건너뛰고 조건문 바깥에 있는 `외출합니다.`만 출력됩니다.
2. `if paid >= 7300:` 조건식으로 비교합니다. 받은 돈이 `7,300`원일 때는 조건이 참이므로 결제할 수 있고, `7,299`원일 때는 거짓이므로 금액이 부족하다고 출력됩니다.
3. `else`에서 미등록 안내가 먼저 출력됩니다. 이어서 조건문 밖의 줄에서 `menu["주스"]`를 읽으려 하므로 `KeyError`가 발생합니다.

</details>
