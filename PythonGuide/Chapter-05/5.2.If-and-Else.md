# 5.2. If & Else

외출하기 전에 창밖을 봅니다. 비가 오면 우산을 가져가고, 비가 오지 않으면 우산을 두고 나갑니다.

> 비가 온다 → 우산을 가져간다.  
> 비가 오지 않는다 → 우산을 가져가지 않는다.

프로그램에서도 **조건문**(**Conditional Statement**)을 사용하면 특정 조건을 만족할 때만 코드를 실행할 수 있습니다. 미등록 메뉴에만 안내를 띄우거나, 잔액이 충분할 때만 결제하는 것도 같은 방식입니다.

## 5.2.1. `if` — 조건을 만족할 때 실행하기

`if` 뒤에 검사할 조건을 쓰고 줄 끝에 콜론(`:`)을 붙입니다. 조건을 만족할 때 실행할 코드는 다음 줄에 들여씁니다.

~~~text
if (조건):
    실행할 코드
~~~

조건이 참으로 평가되면 들여쓴 코드가 실행됩니다. 불리언 값 `True`와 정수 `1`은 모두 참으로 평가됩니다. `False`와 `0`은 거짓으로 평가됩니다. 조건을 감싼 괄호는 생략할 수 있습니다.

~~~python
is_raining = True

if is_raining:
    print("우산을 챙깁니다.")

print("외출합니다.")
~~~

**실행 결과**

~~~text
우산을 챙깁니다.
외출합니다.
~~~

`is_raining = False`로 바꾸고 다시 실행해 보세요. 우산을 챙긴다는 문장은 건너뛰고 `외출합니다.`만 출력합니다.

## 5.2.2. 들여쓰기로 실행 범위 정하기

조건에 따라 실행할 줄이 여러 개라면 같은 깊이로 들여씁니다. 아래 예제에서는 공백 네 칸을 사용했습니다.

~~~python
is_raining = False

if is_raining:
    print("우산을 챙깁니다.")
    print("우산을 펼칩니다.")

print("외출합니다.")
~~~

**실행 결과**

~~~text
외출합니다.
~~~

앞의 두 `print()`는 모두 `if`에 속합니다. 마지막 `print()`는 `if`와 같은 위치에서 시작하므로 조건에 관계없이 실행됩니다.

> 마지막 줄도 공백 네 칸을 넣어 들여쓰면 어떻게 될까요? 조건이 `False`이므로 세 줄 모두 건너뜁니다.

## 5.2.3. `else` — 조건을 만족하지 않을 때 실행하기

비가 오지 않을 때도 안내를 표시하려면 `else`를 씁니다. `else:`는 `if`와 같은 깊이에 놓고, 그 아래 실행할 코드를 들여씁니다.

~~~python
is_raining = False

if is_raining:
    print("우산을 챙깁니다.")
else:
    print("우산을 두고 나갑니다.")

print("외출합니다.")
~~~

**실행 결과**

~~~text
우산을 두고 나갑니다.
외출합니다.
~~~

`is_raining`을 `True`로 바꾸면 첫 줄이 `우산을 챙깁니다.`로 바뀝니다. `if`와 `else` 중 한 쪽만 실행되고, 마지막 외출 안내는 두 경우 모두 출력됩니다. 거짓일 때 할 일이 없다면 5.2.1처럼 `if`만 써도 됩니다.

## 5.2.4. 등록된 메뉴의 가격만 읽기

챕터 4에서 만든 가격표에 손님이 주문한 메뉴가 있는지 확인해 봅시다. `item in menu`는 `item`에 담긴 메뉴 이름이 딕셔너리의 키로 등록되어 있는지 알려 줍니다.

~~~python
menu = {"커피": 4800, "쿠키": 2500, "물": 0}
item = "쿠키"

if item in menu:
    print(f"{item}: {menu[item]:,}원")
else:
    print(f"판매하지 않는 메뉴입니다. ({item})")
~~~

**실행 결과**

~~~text
쿠키: 2,500원
~~~

`item`을 바꿔 세 경우를 비교해 보세요.

<table align="center">
  <thead>
    <tr><th>주문 메뉴</th><th>실행되는 분기</th><th>출력</th></tr>
  </thead>
  <tbody>
    <tr><td>쿠키</td><td><code>if</code></td><td>쿠키: 2,500원</td></tr>
    <tr><td>물</td><td><code>if</code></td><td>물: 0원</td></tr>
    <tr><td>주스</td><td><code>else</code></td><td>판매하지 않는 메뉴입니다. (주스)</td></tr>
  </tbody>
</table>

물은 가격이 `0`이어도 등록된 메뉴이므로 `if`가 실행됩니다. 주스를 주문하면 `else`가 실행됩니다. 이때 `menu[item]`이 있는 줄을 건너뛰므로 없는 키를 읽을 때 발생하는 `KeyError`도 피할 수 있습니다.

## 확인 문제

1. `is_raining`이 `False`일 때, 우산 예제의 `else`를 지우면 어떤 문장이 남을까요?
2. 결제 금액이 7,300원입니다. 받은 돈을 `paid`에 담고, 돈이 충분하면 `결제할 수 있습니다.`, 부족하면 `금액이 부족합니다.`를 출력해 보세요. 받은 돈이 7,300원이거나 7,299원일 때도 확인해 보세요.
3. 가격표 예제에서 `print(f"{item}: {menu[item]:,}원")`을 `if`와 같은 깊이로 옮겨 조건문 전체 아래에 두었습니다. 주스를 주문하면 어떤 일이 생길까요?

3. 미등록 안내를 출력한 뒤 조건문 밖에서 `menu["주스"]`를 읽으므로 `KeyError`가 발생합니다.
