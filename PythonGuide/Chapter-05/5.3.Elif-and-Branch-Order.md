# 5.3. Elif & Branch Order

**5.2절**(If & Else)에서는 `if`와 `else`를 사용해 두 가지 갈래 중 하나를 선택하는 방법을 배웠습니다. 하지만 카페의 금액별 할인율처럼 조건을 세 가지 이상의 경우로 나누어 처리해야 할 때도 많습니다. 이럴 때는 `elif`를 사용해 여러 조건을 차례대로 검사할 수 있습니다.

## 5.3.1. `elif` — 다음 조건 검사하기

`elif`(else if의 줄임말)는 앞에서 검사한 조건이 모두 거짓일 때 새로운 조건을 추가로 검사하는 키워드입니다. `if`, `elif`, `else`는 모두 같은 세로 깊이에 맞춰 작성하고, 각 분기에서 실행할 코드는 공백 네 칸으로 들여씁니다.

```text
if (조건1):
    (코드1)
elif (조건2):
    (코드2)
else:
    (코드3)
(코드4)
```

> 조건1이 참이면, 코드1 실행 → 코드4 실행  
> 조건1이 거짓이고 조건2가 참이면, 코드2 실행 → 코드4 실행  
> 두 조건이 모두 거짓이면, 코드3 실행 → 코드4 실행

`if`와 `elif`로 이어진 **조건문**(**Conditional Statement**)은 위에서부터 순서대로 조건을 확인하며, 가장 먼저 참이 되는 분기 하나만 실행한 뒤 전체 조건문을 빠져나옵니다. 따라서 `조건1`이 참이라면 `조건2`는 아예 검사하지 않고 건너뜁니다. `elif`는 필요한 만큼 여러 개를 이어 붙일 수 있으며, 모든 조건이 거짓일 때 특별히 처리할 작업이 없다면 마지막 `else`는 생략해도 됩니다.

## 5.3.2. 할인율 정하기

주문 금액에 따라 할인율을 다르게 적용하는 카페 프로그램을 작성해 봅시다. 할인 규칙은 다음과 같습니다.

* `30,000`원 이상 주문 시: **10%** 할인
* `10,000`원 이상 `30,000`원 미만 주문 시: **5%** 할인
* `10,000`원 미만 주문 시: 할인 없음(**0%**)

```python
total = 30_000

if total >= 30_000:
    rate = 10
elif total >= 10_000:
    rate = 5
else:
    rate = 0

print(f"할인율: {rate}%")
```

**실행 결과**

```text
할인율: 10%
```

> **참고:** 코드에 쓰인 `30_000`은 일반 정수 `30000`과 완전히 같은 값입니다. 파이썬에서는 큰 숫자를 표기할 때 자릿수 구분용 쉼표(`,`) 대신 밑줄(`_`)을 넣어 가독성을 높일 수 있습니다.

마지막 `print()` 문은 조건문 바깥에 있으므로, 어떤 분기가 실행되든 해당 분기에서 결정된 `rate` 값을 출력합니다. `total` 변수에 아래 표의 금액들을 차례대로 대입해 보며 경계값에서의 동작을 확인해 보세요.

## 5.3.3. 조건의 순서가 결과를 바꿀 때

`30,000`원은 `total >= 30_000` 조건과 `total >= 10_000` 조건을 모두 만족합니다. 만약 두 조건의 검사 순서를 바꾸어 `10,000`원 이상인지를 먼저 검사하면 어떤 결과가 나올까요?

```python
total = 30_000

if total >= 10_000:
    print("할인율: 5%")
elif total >= 30_000:
    print("할인율: 10%")
else:
    print("할인율: 0%")
```

**실행 결과**

```text
할인율: 5%
```

`30,000`원을 주문했는데도 10%가 아닌 5% 할인이 적용되었습니다. 첫 번째 조건인 `total >= 10_000`이 이미 참으로 평가되었기 때문에, 그 아래에 있는 `elif total >= 30_000:` 분기는 검사조차 하지 않고 건너뛰기 때문입니다.

> **주의:** 여러 조건이 겹칠 수 있는 범위 비교에서는 **조건을 작성하는 순서**가 프로그램의 논리적 정확도를 결정합니다. 이 할인 예제처럼 포함 범위가 좁고 까다로운 조건(**기준 금액이 큰 조건**)부터 위쪽에 먼저 배치해야 의도한 대로 정확하게 분기할 수 있습니다.

## 5.3.4. `if`를 두 번 쓰면 어떻게 될까요?

이번에는 서로 배타적인 할인율이 아니라, 조건을 만족할 때마다 각각 독립적으로 적용되는 두 가지 혜택을 가정해 봅시다.

* `10,000`원 이상 주문 시: 스탬프 적립
* `30,000`원 이상 주문 시: 사은품 추가 증정

```python
total = 30_000

if total >= 10_000:
    print("스탬프를 적립합니다.")

if total >= 30_000:
    print("사은품을 드립니다.")
```

**실행 결과**

```text
스탬프를 적립합니다.
사은품을 드립니다.
```

두 개의 `if` 문은 서로 연결되지 않은 별개의 조건문입니다. 따라서 각각 독립적으로 조건을 검사하므로, `30,000`원을 주문하면 두 조건이 모두 참이 되어 스탬프와 사은품 혜택을 전부 받게 됩니다. 만약 두 번째 `if`를 `elif`로 바꾸면 하나의 조건문으로 묶이기 때문에 첫 번째 분기만 실행되어 스탬프만 적립됩니다.

## 확인 문제

1. 5.3.1절의 구조에서 `조건1`과 `조건2`가 모두 참이라면, 어떤 코드가 어떤 순서로 실행될까요?
2. 5.3.2절 예제의 첫 번째 조건식을 `total > 30_000`으로 수정하면, 주문 금액(`total`)이 정확히 `30,000`원일 때 할인율은 몇 퍼센트로 출력될까요?
3. 5.3.4절의 예제에서 `30,000`원 조건을 먼저 `if`로 작성하고, `10,000`원 조건을 그 아래에 `elif`로 이어서 작성했습니다. 이때 `30,000`원을 주문하면 어떤 혜택만 적용될까요?
