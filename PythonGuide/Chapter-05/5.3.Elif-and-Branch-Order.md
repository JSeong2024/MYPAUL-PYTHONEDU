# 5.3. Elif & Branch Order

**`elif`와 분기 순서**

5.2절에서는 `if`와 `else`를 사용해 두 가지 갈래 중 하나를 선택했습니다. 이번 절에서는 `elif`를 추가해 주문 금액에 따라 할인율을 세 가지 구간으로 나누어 봅니다.

## 5.3.1. `elif` — 다음 조건 검사하기

`elif`는 *else if*의 줄임말입니다. 앞에서 검사한 조건이 모두 거짓일 때 다음 조건을 검사합니다. `if`, `elif`, `else`는 같은 깊이에 쓰고 각 줄 끝에 콜론(`:`)을 붙입니다. 각 분기에서 실행할 코드는 공백 네 칸을 들여씁니다.

```text
if (조건1):
    (코드1)
elif (조건2):
    (코드2)
else:
    (코드3)
(코드4)
```

> 만약 `조건1`이 참이라면 `코드1`을 실행합니다.  
> 그렇지 않고 `조건2`가 참이라면 `코드2`를 실행합니다.  
> 위 조건들이 모두 거짓이라면 `코드3`을 실행합니다.

이 예제에서 `코드4`는 어느 분기를 실행하든 조건문이 끝난 뒤 실행됩니다.

조건을 위에서부터 검사해 처음으로 참인 분기를 실행합니다. 그 아래 조건은 건너뜁니다. `elif`는 여러 개 쓸 수 있습니다. 모든 조건이 거짓일 때 할 일이 없다면 `else`를 생략할 수 있습니다.

## 5.3.2. 할인율 정하기

주문 금액에 따라 할인율을 다르게 적용하는 카페 프로그램을 작성해 봅시다. 할인 규칙은 다음과 같습니다.

* `30,000`원 이상 주문 시: **10%** 할인
* `10,000`원 이상 `30,000`원 미만 주문 시: **5%** 할인
* `10,000`원 미만 주문 시: 할인 없음(**0%**)

```python
total = 30_000

if total >= 30_000:
    rate = 10
elif total >= 10_000:
    rate = 5
else:
    rate = 0

print(f"할인율: {rate}%")
```

**실행 결과**

```text
할인율: 10%
```

> `30_000`과 `30000`은 같은 정수입니다. 숫자 사이에 밑줄(`_`)을 넣으면 자릿수를 읽기 쉽습니다.

`elif` 조건식에 `total < 30_000`을 다시 적을 필요는 없습니다. 첫 번째 조건(`total >= 30_000`)이 거짓일 때만 `elif`로 넘어오므로, 이 시점의 주문 금액은 이미 30,000원 미만이기 때문입니다.

어느 분기가 실행되든 조건문 바깥의 `print()` 함수가 해당 분기에서 결정된 할인율(`rate`)을 출력합니다. `total`의 값을 아래 표의 금액으로 직접 바꾸어 보며 구간이 나뉘는 경계값을 확인해 보세요.

## 5.3.3. 조건의 순서가 결과를 바꿀 때

`30,000`원은 `total >= 30_000` 조건과 `total >= 10_000` 조건을 모두 만족합니다. 만약 두 조건의 검사 순서를 바꾸어 `10,000`원 이상인지를 먼저 검사하면 어떤 결과가 나올까요?

```python
total = 30_000

if total >= 10_000:
    print("할인율: 5%")
elif total >= 30_000:
    print("할인율: 10%")
else:
    print("할인율: 0%")
```

**실행 결과**

```text
할인율: 5%
```

30,000원은 첫 조건인 `total >= 10_000`을 만족하므로 5%가 출력됩니다. 30,000원 이상인 금액은 모두 첫 조건을 만족하므로, 이 순서에서는 10% 할인 분기가 실행될 수 없습니다.

> 조건이 겹치면 두 조건을 모두 만족하는 값에 어떤 분기를 적용할지 먼저 정합니다. 이 예제에서는 10% 할인이 우선이므로 `total >= 30_000`을 먼저 검사합니다.

## 5.3.4. `if`를 두 번 쓰면 어떻게 될까요?

이번에는 하나만 선택해야 하는 할인율이 아니라, 조건을 만족할 때마다 각각 독립적으로 적용되는 두 가지 혜택을 가정해 봅시다.

* `10,000`원 이상 주문 시: 스탬프 적립
* `30,000`원 이상 주문 시: 사은품 추가 증정

```python
total = 30_000

if total >= 10_000:
    print("스탬프를 적립합니다.")

if total >= 30_000:
    print("사은품을 드립니다.")
```

**실행 결과**

```text
스탬프를 적립합니다.
사은품을 드립니다.
```

두 `if`문은 각각 조건을 검사합니다. 30,000원 주문은 두 조건을 모두 만족하므로 스탬프와 사은품을 모두 받습니다. 두 번째 `if`를 `elif`로 바꾸면 첫 분기만 실행되어 스탬프만 적립됩니다.

> 할인율처럼 여러 선택지 중 하나를 고를 때는 `if`와 `elif`를 이어 씁니다. 스탬프와 사은품처럼 조건을 충족한 혜택을 각각 적용할 때는 `if`문을 따로 씁니다.

## 확인 문제

2. 5.3.2절 예제의 첫 번째 조건식을 `total > 30_000`으로 수정하면, 주문 금액(`total`)이 정확히 `30,000`원일 때 할인율은 몇 퍼센트로 출력될까요?
3. 5.3.4절의 예제에서 `30,000`원 조건을 먼저 `if`로 작성하고, `10,000`원 조건을 그 아래에 `elif`로 이어서 작성했습니다. 이때 `30,000`원을 주문하면 어떤 혜택만 적용될까요?
