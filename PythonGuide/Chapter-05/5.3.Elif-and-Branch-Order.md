# 5.3. Elif & Branch Order

앞 절에서는 비가 오는지에 따라 두 가지 행동 중 하나를 골랐습니다. 카페 할인처럼 주문 금액에 따라 세 가지 이상으로 나누려면 `elif`로 다음 조건을 검사합니다.

## 5.3.1. `elif` — 다음 조건 검사하기

`elif`는 앞에서 검사한 조건이 모두 거짓일 때 다음 조건을 검사합니다. `if`, `elif`, `else`는 같은 깊이에 쓰고, 각 분기에서 실행할 코드는 공백 네 칸을 들여씁니다.

```text
if (조건1):
    (코드1)
elif (조건2):
    (코드2)
else:
    (코드3)
(코드4)
```

> 조건1이 참이면, 코드1 실행 → 코드4 실행  
> 조건1이 거짓이고 조건2가 참이면,코드2 실행 → 코드4 실행  
> 두 조건이 모두 거짓이면, 코드3 실행 → 코드4 실행

조건1이 참이면 조건2는 검사하지 않습니다. `elif`는 필요한 만큼 추가할 수 있습니다. 모든 조건이 거짓일 때 할 일이 없다면 `else`를 생략할 수 있습니다.

## 5.3.2. 할인율 정하기

이 카페는 30,000원 이상 주문하면 10%, 10,000원 이상 30,000원 미만이면 5%를 할인합니다. 10,000원 미만이면 할인이 없습니다.

```python
total = 30_000

if total >= 30_000:
    rate = 10
elif total >= 10_000:
    rate = 5
else:
    rate = 0

print(f"할인율: {rate}%")
```

**실행 결과**

```text
할인율: 10%
```

> `30_000`은 `30000`과 같은 정수입니다. 숫자 사이에 밑줄을 넣으면 자릿수를 읽기 쉽습니다.

`print()`는 조건문 밖에 있습니다. 어느 분기가 실행되든 그 분기에서 정한 할인율을 출력합니다. `total`을 다음 값으로 바꿔 보세요.

## 5.3.3. 조건의 순서가 결과를 바꿀 때

30,000원은 `total >= 30_000`과 `total >= 10_000`을 모두 만족합니다. 이번에는 10,000원 이상인지 먼저 검사해 봅시다.

```python
total = 30_000

if total >= 10_000:
    print("할인율: 5%")
elif total >= 30_000:
    print("할인율: 10%")
else:
    print("할인율: 0%")
```

**실행 결과**

```text
할인율: 5%
```

30,000원 이상인 주문은 첫 조건을 이미 만족하므로 10% 할인 분기까지 갈 수 없습니다. 이 할인 규칙에서는 **기준 금액이 큰 조건부터** 검사하면 각 주문에 맞는 할인율을 정할 수 있습니다.

## 5.3.4. `if`를 두 번 쓰면 어떻게 될까요?

서로 따로 적용되는 혜택이 두 가지 있다고 가정해 봅시다. 10,000원 이상 주문하면 스탬프를 받고, 30,000원 이상이면 사은품도 받습니다.

```python
total = 30_000

if total >= 10_000:
    print("스탬프를 적립합니다.")

if total >= 30_000:
    print("사은품을 드립니다.")
```

**실행 결과**

```text
스탬프를 적립합니다.
사은품을 드립니다.
```

두 `if`문은 각각 조건을 검사하므로, 30,000원을 주문하면 두 혜택을 모두 받습니다. 두 번째 `if`를 `elif`로 바꾸면 첫 분기만 실행되어 스탬프만 적립됩니다.

3. 5.3.4에서 30,000원 조건을 먼저 쓰고, 10,000원 조건을 `elif`로 쓰면 30,000원 주문에 어떤 혜택이 적용될까요?
