## Mini Project. 카페 주문 접수하기

손님에게 메뉴 이름, 수량, 받은 돈을 차례로 입력받아 주문 한 건을 처리하세요. 수량과 받은 돈은 정수로 입력받으며, 받은 돈은 0 이상이라고 가정합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}

item = input("메뉴: ")
quantity = int(input("수량: "))
paid = int(input("받은 돈: "))
```

1. 메뉴가 등록되지 않았으면 `판매하지 않는 메뉴입니다.`를 출력한다.
2. 메뉴가 등록되어 있고 수량이 1보다 작으면 `수량은 1 이상이어야 합니다.`를 출력한다.
3. 메뉴와 수량이 모두 유효하면 단가에 수량을 곱해 주문 금액을 구한다.
4. 주문 금액이 30,000원 이상이면 10%, 10,000원 이상 30,000원 미만이면 5%, 10,000원 미만이면 0%를 적용한다. 할인액은 `total * rate // 100`으로 구해 1원 미만을 버린다. 주문 금액에서 할인액을 빼 결제 금액을 구한다.
5. 결제 금액을 출력한다. 받은 돈이 충분하면 거스름돈을, 부족하면 부족한 금액을 출력한다.

**실행 예시**

```text
메뉴: 커피
수량: 3
받은 돈: 15000
결제 금액: 13,680원
결제 완료. 거스름돈: 1,320원
```

미등록 메뉴나 수량 0도 입력해 보세요. 커피 3잔에 13,680원을 받았을 때는 거스름돈이 0원인지 확인하세요.
