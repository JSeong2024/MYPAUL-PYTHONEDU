# Chapter 03. Solutions

## Exercise Solutions

### Q-01

**정답: ③ `str`**

`input()`은 입력한 값을 문자열로 돌려줍니다. 숫자로 계산하려면 `int()`나 `float()`로 변환해야 합니다.

### Q-02

**정답: ③ `A-B-C`**

`sep="-"`는 쉼표로 구분한 값 사이에 하이픈을 넣습니다.

### Q-03

**정답: ② `float("3.5")`**

문자열 `"3.5"`를 실수로 바꿉니다. `int("3.5")`는 직접 변환할 수 없어 `ValueError`가 발생합니다.

### Q-04

**정답: ② `f"{12500:,}"`**

`:,`는 세 자리마다 쉼표를 넣어 숫자를 표시합니다.

### Q-05

**정답: `105`**

`first`와 `second`가 모두 문자열이므로 두 문자열이 연결됩니다. 덧셈 결과 `15`를 얻으려면 `int(first) + int(second)`로 계산해야 합니다.

### Q-06

**모범답안**

```python
print(f"총액: {3500}원")
```

**실행 결과**

```text
총액: 3500원
```

변수를 사용할 수도 있습니다.

```python
total = 3500
print(f"총액: {total}원")
```

### Q-07

**정답**

```text
지수: 92.7점
```

`:.1f`는 소수점 아래 한 자리까지 표시합니다.

### Q-08

**정답: `24`**

`int()`로 두 입력을 정수로 바꾸었으므로 `4 * 6`을 계산합니다.

### Q-09

**정답**

```text
첫째 / 둘째
```

첫 번째 `print()`는 `end=" / "`로 줄바꿈 대신 공백·슬래시·공백을 출력합니다.

### Q-10

**모범답안**

```python
number = int(input("숫자: "))
print(number + 3)
```

`input()`의 결과는 문자열이므로 정수 `3`을 바로 더할 수 없습니다. `int()`로 변환한 뒤 계산해야 합니다.

**실행 예시**

```text
숫자: 3
6
```

### Q-11

**모범답안**

```python
name = "민수"
print(f"안녕하세요, {name}님!")
```

**실행 결과**

```text
안녕하세요, 민수님!
```

문자열 앞에 `f`가 없으면 `{name}`이 그대로 출력됩니다.
