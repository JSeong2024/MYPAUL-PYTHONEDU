# Chapter 03. Input, Output & String Formatting

지난 장에서는 변수에 값을 저장하고 계산하는 방법을 배웠습니다. 하지만 상품의 가격이나 수량을 코드에 미리 적어 두면, 다른 값을 계산할 때마다 코드를 수정해야 합니다.

이번 장에서는 프로그램을 실행하는 사람이 값을 직접 입력하고, 계산 결과를 읽기 좋은 형태로 출력하는 방법을 살펴봅니다. Python에서 입력과 출력에 사용하는 기본 함수인 `input()`과 `print()`, 자료형 변환, f-string을 차례대로 다룹니다.

## 3.1. Output — `print()`

### 3.1.1. 값 출력하기

`print()`는 괄호 안의 값을 화면에 출력합니다. 문자열뿐 아니라 숫자와 변수도 출력할 수 있습니다.

```python
print("Hello, Python!")
print(2026)

price = 1500
print(price)
```

**실행 결과**

```text
Hello, Python!
2026
1500
```

따옴표로 감싼 `"Hello, Python!"`은 문자열입니다. 반면 `2026`은 숫자입니다. 변수 `price`를 출력하면 변수 이름이 아닌, 해당 변수가 가리키는 값이 나타납니다.

### 3.1.2. 여러 값 함께 출력하기

쉼표로 값을 구분하면 한 줄에 함께 출력할 수 있습니다.

```python
product = "사과"
price = 1500

print("상품:", product)
print("가격:", price, "원")
```

**실행 결과**

```text
상품: 사과
가격: 1500 원
```

여러 값을 쉼표로 구분하면 값 사이에 기본적으로 공백 한 칸이 들어갑니다. 따라서 `1500`과 `원` 사이에도 공백이 생깁니다.

공백을 없애거나 출력 형식을 세밀하게 조정하려면 뒤에서 배울 f-string을 이용할 수 있습니다.

### 3.1.3. 구분자와 줄바꿈

`print()`는 기본적으로 값을 출력한 뒤 줄을 바꿉니다. `sep`과 `end`를 사용하면 이 동작을 바꿀 수 있습니다.

```python
print("2026", "11", "10", sep="-")
print("Python", end=" ")
print("Guide")
```

**실행 결과**

```text
2026-11-10
Python Guide
```

- `sep`은 쉼표로 구분한 값 사이에 넣을 내용을 정합니다. 기본값은 공백 한 칸입니다.
- `end`는 출력 마지막에 붙일 내용을 정합니다. 기본값은 줄바꿈입니다.

문자열 안에서 줄을 바꾸고 싶을 때는 `\n`을 사용할 수도 있습니다.

```python
print("첫째 줄\n둘째 줄")
```

**실행 결과**

```text
첫째 줄
둘째 줄
```

`\n`은 줄바꿈을 나타내는 특별한 표기입니다. 화면에 `\`와 `n`이 그대로 나타나는 것이 아니라, 그 위치에서 줄이 바뀝니다.

## 3.2. Input — `input()`

### 3.2.1. 키보드로 값 입력받기

`input()`은 프로그램을 실행하는 사람이 키보드로 입력한 내용을 받는 함수입니다. 사용자가 내용을 입력하고 Enter 키를 누르면, 입력한 값을 사용할 수 있습니다.

```python
name = input("이름을 입력하세요: ")
print("반갑습니다,", name)
```

**실행 예시**

```text
이름을 입력하세요: 민수
반갑습니다, 민수
```

`input()`의 괄호 안에 적은 문자열은 입력을 요청하는 안내 문구입니다. 안내 문구 뒤에 공백을 넣으면 입력한 내용이 문구에 붙어 보이지 않아 읽기 편합니다.

위 예시에서 `민수`는 사용자가 입력한 값입니다. 프로그램이 미리 출력한 문장이 아닙니다.

### 3.2.2. 입력받은 값은 문자열입니다

`input()`으로 받은 값은 숫자처럼 보여도 **문자열(`str`)** 입니다. 다음 코드를 실행해 봅시다.

```python
first = input("첫 번째 숫자: ")
second = input("두 번째 숫자: ")

print(first + second)
```

**실행 예시**

```text
첫 번째 숫자: 3
두 번째 숫자: 5
35
```

`3`과 `5`를 입력했는데 결과는 `8`이 아니라 `35`입니다. `first`와 `second`가 숫자가 아닌 문자열이기 때문입니다. 문자열에 `+`를 사용하면 두 문자열을 이어 붙입니다.

숫자를 계산하려면 입력받은 문자열을 숫자 자료형으로 바꿔야 합니다.

## 3.3. Type Conversion — 자료형 변환

### 3.3.1. 정수와 실수로 변환하기

**자료형 변환(Type Conversion)** 은 값을 다른 자료형으로 바꾸는 것입니다.

- `int()`는 정수로 변환합니다.
- `float()`는 실수로 변환합니다.
- `str()`은 문자열로 변환합니다.

```python
first = int(input("첫 번째 숫자: "))
second = int(input("두 번째 숫자: "))

print(first + second)
```

**실행 예시**

```text
첫 번째 숫자: 3
두 번째 숫자: 5
8
```

`input()`이 받은 문자열을 `int()`가 정수로 바꾸므로, 이번에는 두 값을 더한 결과가 출력됩니다. 괄호가 여러 겹으로 보인다면 안쪽부터 읽으면 됩니다.

```python
age_text = input("나이: ")
age = int(age_text)
```

위의 두 줄을 `age = int(input("나이: "))`처럼 한 줄로 작성할 수도 있습니다. 처음에는 두 줄로 나누어 작성해도 괜찮습니다. 값이 어떤 과정을 거쳐 바뀌는지 확인하기 쉽기 때문입니다.

소수점이 포함된 값을 입력받을 때는 `float()`를 사용합니다.

```python
height = float(input("키(cm): "))
print(height)
```

**실행 예시**

```text
키(cm): 172.5
172.5
```

### 3.3.2. 문자열로 변환하기

숫자와 문자열은 `+`로 바로 연결할 수 없습니다.

```python
age = 20
print("나이: " + age)
```

이 코드는 `TypeError`가 발생합니다. `"나이: "`는 문자열이고 `age`는 정수이기 때문입니다.

숫자를 문자열로 바꾸면 연결할 수 있습니다.

```python
age = 20
print("나이: " + str(age))
```

**실행 결과**

```text
나이: 20
```

다만 출력할 문장을 만들기 위해 매번 `str()`을 사용해야 하는 것은 아닙니다. 뒤에서 배우는 f-string을 사용하면 더 간단하게 표현할 수 있습니다.

### 3.3.3. 변환할 수 없는 값

자료형 변환은 값의 내용에 따라 실패할 수 있습니다.

```python
number = int("apple")
```

`"apple"`은 정수로 해석할 수 없으므로 `ValueError`가 발생합니다. `int("3.5")`도 마찬가지로 오류가 발생합니다. 소수점이 있는 문자열을 정수로 바로 바꿀 수는 없습니다.

이번 장에서는 사용자가 안내에 맞는 값을 입력한다고 가정합니다. 잘못된 입력이 들어와도 프로그램이 중단되지 않도록 처리하는 방법은 이후 예외 처리 과정에서 다룹니다.

## 3.4. String Formatting — f-string

### 3.4.1. 문자열에 변수 넣기

앞에서는 문자열과 숫자를 함께 출력하기 위해 쉼표나 `str()`을 사용했습니다. 하지만 출력할 문장이 길어지면 공백이나 연결 기호를 관리하기 번거로울 수 있습니다.

Python의 **f-string(Formatted String Literal)** 을 사용하면 문자열 안에 변수나 계산식을 넣을 수 있습니다. 문자열 앞에 `f`를 붙이고, 값을 넣을 자리를 중괄호 `{}`로 감싸면 됩니다.

```python
name = "민수"
age = 20

print(f"{name}님의 나이는 {age}세입니다.")
```

**실행 결과**

```text
민수님의 나이는 20세입니다.
```

문자열의 모양을 그대로 유지하면서 값을 넣을 수 있어 읽기 편합니다. 이 가이드북에서는 일반적인 결과 출력에 f-string을 주로 사용합니다.

중괄호 안에는 변수뿐 아니라 계산식도 넣을 수 있습니다.

```python
price = 1800
quantity = 4

print(f"총 {quantity}개, 결제 금액은 {price * quantity}원입니다.")
```

**실행 결과**

```text
총 4개, 결제 금액은 7200원입니다.
```

계산 결과를 다른 곳에서도 사용한다면 변수에 먼저 저장하는 편이 낫습니다.

```python
price = 1800
quantity = 4
total = price * quantity

print(f"총 {quantity}개, 결제 금액은 {total}원입니다.")
```

### 3.4.2. 소수점 자리 표시하기

계산한 값의 소수점 아래 자릿수를 일정하게 표시하고 싶을 때가 있습니다. 다음은 `:.2f`를 사용한 예입니다.

```python
average = 87.456

print(f"평균: {average:.2f}점")
```

**실행 결과**

```text
평균: 87.46점
```

`:.2f`는 소수점 아래 두 자리까지 표시하라는 뜻입니다. 실제 계산에 사용되는 `average`의 값이 바뀌는 것은 아닙니다. **출력할 때 보이는 모습**을 정하는 기능입니다.

같은 값을 소수점 아래 한 자리로 표시하려면 `:.1f`를 사용하면 됩니다.

```python
average = 87.456
print(f"평균: {average:.1f}점")
```

**실행 결과**

```text
평균: 87.5점
```

표시하는 과정에서 반올림이 일어날 수 있습니다. 다만 컴퓨터에서 실수를 저장하는 방식 때문에 일부 값은 사람이 예상하는 십진수 반올림 결과와 다르게 보일 수도 있습니다.

### 3.4.3. 큰 숫자 읽기 쉽게 표시하기

가격처럼 자릿수가 큰 숫자에는 쉼표를 넣으면 읽기 쉬워집니다.

```python
amount = 1250000

print(f"금액: {amount:,}원")
```

**실행 결과**

```text
금액: 1,250,000원
```

`:,`는 숫자를 세 자리씩 구분해 표시합니다. 소수점 자릿수와 함께 사용할 수도 있습니다.

```python
price = 12345.678
print(f"가격: {price:,.2f}원")
```

**실행 결과**

```text
가격: 12,345.68원
```

지금은 `:.2f`와 `:,` 정도만 익혀도 충분합니다. 정렬, 너비, 진법 등 다른 출력 서식은 필요할 때 확인하면 됩니다.

## 3.5. Input to Output — 간단한 계산 프로그램

입력, 자료형 변환, 계산, 출력을 한 프로그램에 연결해 봅시다.

상품의 단가와 구매 수량을 입력받아 총액을 계산하는 예제입니다.

```python
product = input("상품명: ")
price = int(input("단가(원): "))
quantity = int(input("수량: "))

total = price * quantity

print("--------------------")
print(f"상품: {product}")
print(f"수량: {quantity}개")
print(f"총액: {total:,}원")
```

**실행 예시**

```text
상품명: 사과
단가(원): 1800
수량: 4
--------------------
상품: 사과
수량: 4개
총액: 7,200원
```

프로그램이 하는 일은 복잡하지 않습니다. 입력받은 상품명은 문자열 그대로 사용하고, 단가와 수량은 `int()`로 정수로 바꿉니다. 두 값을 곱한 뒤 f-string으로 결과를 출력합니다.

여기서는 입력한 값을 한 번 계산하고 프로그램을 종료합니다. 여러 번 주문을 받거나, 입력이 잘못되었을 때 다시 입력하도록 하는 기능은 조건문과 반복문을 배운 뒤 구현할 수 있습니다.

## Summary

- `print()`는 문자열, 숫자, 변수의 값을 출력합니다. `sep`과 `end`로 값 사이의 구분자와 출력 끝 문자를 조절할 수 있습니다.
- `input()`은 키보드 입력을 받아 **문자열(`str`)** 로 돌려줍니다.
- 숫자를 계산하려면 필요에 따라 `int()`나 `float()`로 변환합니다. `str()`은 값을 문자열로 바꿀 때 사용합니다.
- f-string은 문자열 안에 변수나 계산 결과를 넣어 출력할 수 있게 합니다.
- `:.2f`는 소수점 아래 두 자리, `:,`는 세 자리마다 쉼표를 넣는 출력 형식입니다.

### Advanced 
#### 1. 카페 주문 영수증

카페에서 커피와 쿠키를 주문합니다. 수량을 입력받아 결제 금액을 계산하고, 받은 돈에서 거스름돈을 구하는 프로그램을 작성합니다.

**주어진 정보**

| 항목 | 값 |
|---|---:|
| 커피 단가 | 4,800원 |
| 쿠키 단가 | 2,500원 |
| 할인 금액 | 1,000원 |

**요구사항**

1. 커피 수량, 쿠키 수량, 받은 돈을 각각 입력받아 정수로 변환한다.
2. 상품별 금액을 계산하고 주문 금액을 구한다.
3. 주문 금액에서 1,000원을 할인한 결제 금액을 계산한다.
4. 받은 돈에서 결제 금액을 빼 거스름돈을 구한다.
5. 금액은 모두 세 자리마다 쉼표를 넣고 `원`을 붙여 출력한다.

**실행 예시**

```text
커피 수량: 2
쿠키 수량: 3
받은 돈(원): 25000
--------------------
커피: 9,600원
쿠키: 7,500원
주문 금액: 17,100원
할인: 1,000원
결제 금액: 16,100원
받은 돈: 25,000원
거스름돈: 8,900원
```

**입력 조건**

커피와 쿠키 수량은 0 이상의 정수이며, 합계가 1개 이상이라고 가정합니다. 받은 돈은 결제 금액 이상이고, 할인 후 결제 금액도 0원 이상인 경우만 다룹니다. 입력값 검사와 다시 입력받는 기능은 이 프로젝트의 범위에 포함하지 않습니다.

**확인할 사항**

- 수량을 바꾸면 상품별 금액과 결제 금액이 함께 달라지는가?
- 입력받은 금액을 정수로 바꾸어 계산하는가?
- 출력 형식을 바꾸기 위해 금액에 쉼표를 넣더라도 계산 결과에는 영향을 주지 않는가?
- 받은 돈과 결제 금액이 같으면 거스름돈이 0원으로 표시되는가?

해설은 [Solutions](./solutions/README.md)에서 확인할 수 있습니다.
