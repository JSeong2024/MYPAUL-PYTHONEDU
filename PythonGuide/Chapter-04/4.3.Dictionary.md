# 4.3. Dictionary

앞 절에서는 플레이리스트의 첫 곡을 `playlist[0]`으로 읽었습니다. 이번에는 재생 순서 대신 **아티스트 이름으로 곡 제목을 찾고 싶다면** 어떻게 저장해야 할지 살펴봅니다.

## 4.3.1. 딕셔너리 만들기 — 키와 값

**딕셔너리**(**Dictionary**)는 **키**(**Key**)와 그에 연결된 **값**(**Value**)을 한 쌍으로 저장합니다. 중괄호 안에 각 쌍을 `키: 값`으로 적고, 여러 쌍은 쉼표로 구분합니다. 아래에서는 아티스트 이름이 키이고 곡 제목이 값입니다.

~~~python
playdict = {
    "RESCENE": "with",
    "aespa & Eartha Kitt": "Santa Baby",
    "TXT": "Angel Bite",
}

print(len(playdict))
~~~

**실행 결과**

~~~text
3
~~~

`"RESCENE": "with"`는 키와 값 한 쌍입니다. `len(playdict)`는 이런 쌍을 셉니다. 빈 딕셔너리는 `{}`로 만듭니다.

키를 모두 문자열로 쓸 필요는 없습니다. 예를 들어 `a = {"apple": 10, 3: "2"}`에서 `"apple"`은 문자열 키이고 `3`은 정수 키입니다. `a[3]`으로 읽는 값은 따옴표로 감싼 문자열 `"2"`입니다.

## 4.3.2. 키로 값 읽기

리스트와 딕셔너리는 모두 대괄호로 값을 읽습니다. 리스트의 대괄호에는 **위치를 나타내는 인덱스**, 딕셔너리의 대괄호에는 **저장할 때 정한 키**를 넣습니다.

~~~python
playlist = ["with", "Santa Baby", "Angel Bite", "with"]
playdict = {
    "RESCENE": "with",
    "aespa & Eartha Kitt": "Santa Baby",
    "TXT": "Angel Bite",
}

print(playlist[0])
print(playdict["RESCENE"])

artist = "TXT"
print(playdict[artist])
~~~

**실행 결과**

~~~text
with
with
Angel Bite
~~~

`playlist[0]`은 ‘첫 번째 곡’을, `playdict["RESCENE"]`은 ‘RESCENE에 연결해 둔 곡’을 읽습니다. 위 딕셔너리에서 항목을 적는 순서를 바꿔도 `playdict["RESCENE"]`의 값은 `"with"`입니다. `playdict[artist]`는 변수에 담긴 `"TXT"`를 키로 사용합니다.

> `playdict[0]`에서 `0`은 정수 키입니다. 위 딕셔너리에는 그 키가 없으므로 `KeyError`가 발생합니다.

이 예제에서는 아티스트마다 곡을 한 곡씩 연결했습니다. 재생 순서와 반복 재생을 기록할 때는 앞 절의 플레이리스트처럼 리스트를 씁니다. 다음 예제에서는 메뉴 이름을 키로, 가격을 값으로 써서 항목을 추가하고 수정해 봅니다.

## 4.3.3. 메뉴 추가와 가격 수정

대괄호 안에 키를 적고 값을 대입합니다. 등록된 키에 대입하면 그 키의 값이 바뀌고, 새 키에 대입하면 항목이 추가됩니다.

~~~python
menu = {"커피": 4800, "쿠키": 2500}

menu["쿠키"] = 2800
menu["차"] = 2800

print(menu)
print(len(menu))
~~~

**실행 결과**

~~~text
{'커피': 4800, '쿠키': 2800, '차': 2800}
3
~~~

쿠키 가격을 바꾸어도 쿠키 항목은 한 개입니다. 차를 추가할 때만 항목 수가 늘어납니다. 아래처럼 생성할 때 같은 키를 두 번 쓰면 마지막에 적은 값이 남습니다.

~~~python
menu = {"커피": 4800, "커피": 5200}

print(menu)
~~~

**실행 결과**

~~~text
{'커피': 5200}
~~~

키 하나에는 값 하나가 연결됩니다. 가격이 같은 메뉴는 여러 개 있어도 됩니다. 위 가격표에서 쿠키와 차는 각각 다른 키이므로 가격이 같아도 함께 저장됩니다.

## 4.3.4. 없는 키 확인하기 — `in`과 `get()`

`menu["주스"]`처럼 없는 키를 대괄호로 조회하면 `KeyError`가 발생합니다. 등록 여부만 필요하면 `in`으로 확인합니다. 키가 없을 때 대신 사용할 값이 필요하면 `get()`을 사용합니다.

~~~python
menu = {"커피": 4800, "쿠키": 2500, "물": 0}

print("물" in menu)
print(4800 in menu)
print(menu.get("커피"))
print(menu.get("주스"))
print(menu.get("주스", "미등록"))
print(menu.get("물", "미등록"))
~~~

**실행 결과**

~~~text
True
False
4800
None
미등록
0
~~~

`in`은 키만 확인하므로, 가격 `4800`이 값에 들어 있어도 `4800 in menu`는 `False`입니다. 값에서 찾으려면 `4800 in menu.values()`처럼 씁니다.

`get()`은 키가 없을 때 기본으로 `None`을 반환합니다. 두 번째 인수로 `"미등록"`을 전달하면 없는 키에만 그 값을 반환합니다. 물은 등록된 메뉴이므로 실제 가격인 `0`을 반환합니다. `get()`으로 주스를 조회해도 가격표에 주스가 추가되지는 않습니다.

## 4.3.5. 키와 값을 함께 삭제하기

항목을 지우려면 `del`을 사용합니다. 지운 값을 기록해 두어야 할 때는 `pop()`으로 꺼냅니다.

~~~python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}

del menu["쿠키"]
removed_price = menu.pop("차")

print(menu)
print(removed_price)
print(menu.pop("주스", "미등록"))
~~~

**실행 결과**

~~~text
{'커피': 4800}
3000
미등록
~~~

`del menu["쿠키"]`를 실행하면 쿠키라는 키와 그 가격이 함께 사라집니다. `pop("차")`는 차를 삭제하면서 삭제 직전 가격인 `3000`을 반환합니다. 없는 키에 `del`을 쓰거나 기본값 없이 `pop()`을 호출하면 `KeyError`가 발생합니다.

## 4.3.6. 이름만, 가격만, 이름과 가격 함께 보기

가격표에서 메뉴 이름만 필요할 때도 있고, 목록에 있는 각 가격이 어떤 메뉴의 가격인지 알아야 할 때도 있습니다.

<table align="center">
  <thead>
    <tr><th>코드</th><th>얻는 정보</th><th>가격표 예시</th></tr>
  </thead>
  <tbody>
    <tr><td><code>menu.keys()</code></td><td>키</td><td>커피, 쿠키</td></tr>
    <tr><td><code>menu.values()</code></td><td>값</td><td>4800, 2500</td></tr>
    <tr><td><code>menu.items()</code></td><td>키와 값의 쌍</td><td>(커피, 4800), (쿠키, 2500)</td></tr>
  </tbody>
</table>

~~~python
menu = {"커피": 4800, "쿠키": 2500}

print(list(menu.keys()))
print(list(menu.values()))
print(list(menu.items()))
~~~

**실행 결과**

~~~text
['커피', '쿠키']
[4800, 2500]
[('커피', 4800), ('쿠키', 2500)]
~~~

세 메서드가 반환하는 것은 딕셔너리의 현재 내용을 보여 주는 **뷰**(**View**)입니다. 위 예제에서는 출력을 읽기 쉽게 `list()`로 바꾸었습니다. 만들어진 리스트는 변환할 때의 항목을 담습니다. `items()`에서 가져온 각 쌍은 `('커피', 4800)`처럼 키가 먼저, 값이 나중에 오는 튜플입니다.

## 4.3.7. 가격표를 한 줄씩 출력하기

`for`는 여러 항목을 차례대로 꺼낼 때 사용합니다. 딕셔너리를 그대로 넣으면 키를 하나씩 꺼냅니다. 메뉴 이름과 가격을 한 번에 꺼내려면 `items()`를 사용합니다.

~~~python
dict_a = {"커피": 4800, "쿠키": 2500}

for key in dict_a:
    print(key)

for key, value in dict_a.items():
    print(f"{key}: {value:,}원")
~~~

**실행 결과**

~~~text
커피
쿠키
커피: 4,800원
쿠키: 2,500원
~~~

첫 반복에서 `key`에는 `"커피"`, 그다음에는 `"쿠키"`가 들어갑니다. 두 번째 반복에서는 `("커피", 4800)` 한 쌍을 받아 이름은 `key`에, 가격은 `value`에 넣습니다. 콜론 다음 줄을 들여쓰면 그 줄이 항목마다 실행됩니다.

`key`와 `value`는 변수 이름입니다. 짧게 쓸 때는 `k`를 키, `v`를 값으로 정할 수 있습니다.

~~~python
dict_a = {"차": 3000, "주스": 4500}

for k, v in dict_a.items():
    print(f"{k} {v:,}원")
~~~

**실행 결과**

~~~text
차 3,000원
주스 4,500원
~~~

## 4.3.8. 값에 리스트와 딕셔너리 담기

키 하나에 여러 정보를 연결할 때는 그 정보들을 묶어서 값으로 저장합니다. 먼저 음료마다 판매하는 크기를 목록으로 담아 봅시다.

~~~python
sizes = {
    "커피": ["보통", "큰 컵"],
    "차": ["보통"],
}

print(sizes["커피"])
print(sizes["커피"][-1])

sizes["차"].append("큰 컵")
print(sizes["차"])
~~~

**실행 결과**

~~~text
['보통', '큰 컵']
큰 컵
['보통', '큰 컵']
~~~

`sizes["커피"]`로 크기 목록을 꺼낸 뒤 `[-1]`로 그 목록의 마지막 항목을 읽습니다. `sizes["차"].append("큰 컵")`은 차에 연결된 리스트에 크기 하나를 추가합니다.

가격과 품절 상태처럼 각 값에 이름이 필요하면 안쪽에도 딕셔너리를 둘 수 있습니다.

~~~python
menu = {
    "커피": {"가격": 4800, "품절": False},
    "쿠키": {"가격": 2500, "품절": False},
}

print(menu["쿠키"]["가격"])

menu["쿠키"]["품절"] = True

print(menu["쿠키"]["품절"])
print(menu["커피"]["품절"])
~~~

**실행 결과**

~~~text
2500
True
False
~~~

`menu["쿠키"]`로 쿠키 정보를 찾고, 그 안에서 `["가격"]`으로 가격을 읽습니다. 쿠키의 품절 상태를 바꾸어도 커피의 정보는 그대로입니다.

## 확인 문제

1. `menu = {"차": 3000, "주스": 4500}`에서 차 가격을 읽고, 주스 가격을 4,800원으로 수정해 보세요.
2. `{"물": 0}`에서 `get()`을 사용해 `"물"`과 `"차"`를 각각 조회해 보세요. 없는 메뉴에 사용할 기본값은 `"미등록"`입니다.
3. `{"차": 3000, "쿠키": 2500}`에서 쿠키를 삭제하고, 삭제된 가격을 별도로 출력해 보세요.
4. `{"커피": 4800, "차": 3000}`의 키와 값을 한 쌍씩 꺼내 `커피: 4,800원`과 같은 형식으로 출력해 보세요.
5. `{"차": ["보통"], "커피": ["보통", "큰 컵"]}`에서 차의 크기 목록에 `"큰 컵"`을 추가해 보세요. 커피의 크기 목록도 바뀌었는지 확인하세요.
