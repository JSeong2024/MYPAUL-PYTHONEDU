# 4.4. Tuple & Set

카페 가격표에서 메뉴 이름과 가격을 한 묶음으로 읽을 때는 **튜플**(**Tuple**)을 만납니다. 플레이리스트에서 같은 곡 제목을 한 번씩만 세려면 **집합**(**Set**)을 쓸 수 있습니다. 두 자료구조를 만들어 보고, 각각 어떤 상황에 알맞은지 살펴봅니다.

## 4.4.1. 튜플 — 만들고 나면 항목을 바꿀 수 없습니다

튜플의 핵심은 **불변성**(**Immutability**)입니다. 튜플을 만든 뒤에는 항목을 교체하거나 추가하거나 삭제할 수 없습니다.

4.3에서 `menu.items()`를 사용했을 때 `("커피", 4800)`처럼 키와 값이 한 쌍으로 나왔습니다. 이처럼 여러 값을 순서대로 묶어 둔 것이 튜플입니다. 보통 소괄호 안에 값을 쉼표로 구분해 적습니다.

~~~python
item = ("커피", 4800)

print(item[0])
print(f"{item[1]:,}원")
~~~

**실행 결과**

~~~text
커피
4,800원
~~~

리스트와 마찬가지로 인덱스로 값을 읽습니다. 이 예제에서는 인덱스 `0`이 메뉴 이름, `1`이 가격입니다. 같은 좌석 정보를 리스트와 튜플에 넣고, 두 번째 항목을 8로 바꿔 봅시다.

~~~python
seat_list = ["B", 7]
seat_tuple = ("B", 7)

seat_list[1] = 8
print(seat_list)

seat_tuple[1] = 8
~~~

**실행 결과**

~~~text
['B', 8]
TypeError: 'tuple' object does not support item assignment
~~~

리스트의 두 번째 항목은 `8`로 바뀝니다. 튜플에 같은 대입을 시도하면 `TypeError`가 발생합니다. 좌석 정보를 바꿔야 한다면 `seat_tuple = ("B", 8)`처럼 새 튜플을 만들어 변수에 대입할 수 있습니다. 이 대입은 변수가 가리키는 튜플을 바꿉니다. 기존 튜플 `("B", 7)`은 그대로입니다.

> 항목 하나만 담을 때는 `("커피",)`처럼 쉼표를 붙입니다. `("커피")`는 괄호로 감싼 문자열입니다.

### 튜플은 언제 쓸까요?

메뉴 이름과 가격처럼 **각 자리의 역할이 정해진 값을 함께 전달할 때** 튜플이 어울립니다. 좌석을 `("B", 7)`처럼 구역과 번호로 묶는 것도 같은 예입니다. 이때 첫 자리는 구역이고 두 번째 자리는 번호입니다. 반면 주문이 들어올 때마다 항목을 추가하고 접수가 취소되면 빼야 하는 주문 목록에는 리스트가 편합니다.

## 4.4.2. 집합 — 중복 없이 모으기

4.2의 플레이리스트에는 `"with"`가 두 번 들어 있습니다. 재생할 곡은 4개지만, 곡 제목은 3종류입니다. 리스트를 `set()`에 전달하면 같은 값이 하나로 모입니다.

~~~python
playlist = ["with", "Santa Baby", "Angel Bite", "with"]
unique_titles = set(playlist)

print(len(playlist))
print(len(unique_titles))
print("with" in unique_titles)
~~~

**실행 결과**

~~~text
4
3
True
~~~

집합에는 인덱스가 없습니다. 예를 들어 첫 곡을 읽으려면 리스트에서 `playlist[0]`을 사용합니다. 집합에서는 제목이 들어 있는지 `in`으로 확인할 수 있습니다. `set(playlist)`는 새 집합을 만들기 때문에 재생 순서와 중복은 원래 리스트에 그대로 남습니다.

집합은 `{"with", "Angel Bite"}`처럼 중괄호로 만들 수도 있습니다. **빈 집합은 `set()`**, 빈 딕셔너리는 `{}`로 만듭니다.

## 4.4.3. 두 집합에서 공통 항목 찾기

두 재생목록에 모두 들어 있는 곡을 찾고 싶을 때는 두 집합의 **교집합**을 구합니다. 기호 `&`는 양쪽에 모두 있는 값만 모읍니다.

~~~python
my_titles = {"with", "Santa Baby", "Angel Bite"}
friend_titles = {"Santa Baby", "Angel Bite", "Starlight"}

common_titles = my_titles & friend_titles

print(sorted(common_titles))
print(len(common_titles))
~~~

**실행 결과**

~~~text
['Angel Bite', 'Santa Baby']
2
~~~

집합에서는 항목의 출력 순서를 정해 두지 않습니다. 여기서는 매번 같은 순서로 결과를 확인할 수 있게 `sorted()`로 정렬한 리스트를 출력했습니다.

### 집합은 언제 쓸까요?

**종류 수를 세거나, 특정 항목이 있는지 확인하거나, 두 목록의 공통 항목을 찾을 때** 집합이 어울립니다. 예를 들어 행사 입장 기록이 `["P01", "P02", "P01"]`이라면 리스트의 길이로 입장 3건을, 집합의 길이로 입장한 사람 2명을 구할 수 있습니다. 재입장 기록까지 필요하므로 원래 리스트도 함께 둡니다.

## 확인 문제

1. `seat = ("B", 7)`에서 구역과 좌석 번호를 각각 꺼내 보세요. `seat[1] = 8`을 실행하면 어떤 일이 생길까요?
2. `["with", "Angel Bite", "with"]`에서 재생할 곡의 개수와 서로 다른 제목의 개수를 구해 보세요.
3. `{"커피", "쿠키"}`와 `{"쿠키", "차"}`에서 양쪽에 모두 있는 메뉴를 구해 보세요.

<summary>정답 확인</summary>

1. `seat[0]`은 `"B"`, `seat[1]`은 `7`입니다. 튜플의 개별 항목을 교체하면 `TypeError`가 발생합니다.
2. 리스트의 길이는 `3`, `set()`으로 만든 집합의 길이는 `2`입니다.
3. `{"커피", "쿠키"} & {"쿠키", "차"}`의 결과는 `{"쿠키"}`입니다.
