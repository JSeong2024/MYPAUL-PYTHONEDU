# Chapter 04. Python Data Structures

챕터 3에서는 커피와 쿠키의 주문 수량을 각각 입력받아 결제 금액을 계산했습니다. 메뉴가 하나 늘어날 때마다 수량을 담을 변수도 하나씩 추가해야 한다면, 메뉴가 열 개일 때는 어떻게 관리해야 할까요?

이번 챕터에서는 여러 값을 한곳에 모아 다루는 **자료구조**(**Data Structure**)를 살펴봅니다. 주문은 접수 순서대로 기록하고, 가격은 메뉴 이름으로 찾는 방법을 배웁니다.

## 4.1. List — 순서대로 값 관리하기

리스트는 여러 값을 순서대로 저장합니다. 대괄호 안에 값을 쉼표로 구분해 적습니다. 각 값의 위치를 나타내는 번호를 **인덱스**(**Index**)라고 하며, 첫 번째 값의 인덱스는 `0`입니다.

### 예제 4-1. 주문 순서 확인하기

~~~python
orders = ["커피", "쿠키", "커피"]

print(orders[0])
print(orders[1])
print(len(orders))
~~~

**실행 결과**

~~~text
커피
쿠키
3
~~~

같은 메뉴가 두 번 들어 있어도 각각의 주문으로 남습니다. `len(orders)`는 주문 목록에 들어 있는 항목 수를 반환합니다. 이 리스트의 세 항목은 `orders[0]`, `orders[1]`, `orders[2]`로 읽을 수 있습니다. `orders[3]`에 접근하면 `IndexError`가 발생합니다.

### 첫 번째인데 왜 인덱스는 0일까요?

사람에게 주문 순서를 말할 때는 ‘첫 번째 주문’이라고 합니다. 코드에서는 같은 자리를 ‘인덱스 0’이라고 부릅니다. 파이썬의 리스트는 맨 앞에서 얼마나 떨어져 있는지로 앞쪽 인덱스를 읽으면 이해하기 쉽습니다. 첫 항목은 맨 앞에서 0칸, 두 번째 항목은 1칸 떨어져 있습니다. 첫 자리에 1을 붙이는 규칙도 가능하지만, 파이썬 리스트는 0부터 시작하도록 정해져 있습니다.

### 마지막 항목은 왜 `-1`일까요?

뒤에서 읽을 때는 리스트가 끝난 바로 다음 자리를 기준으로 삼습니다. 항목이 3개라면 그 자리는 인덱스 `3`에 해당합니다. 거기서 왼쪽으로 한 칸 가면 마지막 항목이므로 `orders[-1]`은 `orders[3 - 1]`과 같습니다. `orders[-2]`는 뒤에서 두 번째입니다. `-0`은 `0`과 같은 정수이므로 `orders[-0]`은 첫 항목을 읽습니다.

~~~python
orders = ["커피", "쿠키", "차"]

print(orders[0])
print(orders[2])
print(orders[-1])
print(orders[-2])
print(orders[::-1])
print(orders)
~~~

**실행 결과**

~~~text
커피
차
차
쿠키
['차', '쿠키', '커피']
['커피', '쿠키', '차']
~~~

`orders[-1]`은 마지막 항목 하나를 읽습니다. `orders[::-1]`은 **슬라이싱**(**Slicing**)으로, 시작과 끝을 비우고 이동 간격에 `-1`을 넣어 뒤에서 앞으로 한 칸씩 읽습니다. 결과는 순서가 뒤집힌 새 리스트입니다. 원래 `orders`는 그대로입니다. `orders.sort(reverse=True)`는 값을 내림차순으로 정렬하며 원본 리스트를 변경합니다.

### 예제 4-2. 주문 수정하기

~~~python
orders = ["커피", "쿠키"]

orders[1] = "샌드위치"
orders.append("커피")

print(orders)
~~~

**실행 결과**

~~~text
['커피', '샌드위치', '커피']
~~~

`orders[1] = "샌드위치"`는 두 번째 주문을 바꿉니다. `append()`는 리스트 맨 뒤에 항목을 추가합니다. 위치가 정해진 항목을 삭제할 때는 `del orders[1]`처럼 작성합니다. 가운데 항목을 삭제하면 뒤에 있던 항목이 한 칸씩 앞으로 이동합니다.

## 4.2. Tuple — 여러 값을 한 묶음으로 다루기

튜플도 값을 순서대로 저장하며, 인덱스로 값을 읽을 수 있습니다. 상품명과 가격처럼 정해진 자리에 각 값을 담아 한 묶음으로 다룰 때 사용할 수 있습니다.

### 예제 4-3. 메뉴 항목 읽기

~~~python
item = ("커피", 4800)

print(item[0])
print(f"{item[1]:,}원")
~~~

**실행 결과**

~~~text
커피
4,800원
~~~

튜플에 들어 있는 항목은 개별적으로 바꿀 수 없습니다. 위 코드에서 `item[1] = 5000`을 실행하면 `TypeError`가 발생합니다. `item = ("커피", 5000)`처럼 변수에 새 튜플을 대입할 수는 있습니다. 항목이 하나인 튜플을 만들 때는 `("커피",)`처럼 쉼표를 붙입니다.

## 4.3. Dictionary — 키로 값 찾기

딕셔너리는 **키**(**Key**)와 **값**(**Value**)을 한 쌍으로 저장합니다. 예를 들어 `"쿠키"`를 키로, `2500`을 값으로 저장하면 `menu["쿠키"]`로 가격을 읽을 수 있습니다.

### 예제 4-4. 가격 조회하고 수정하기

~~~python
menu = {"커피": 4800, "쿠키": 2500}

print(menu["쿠키"])

menu["쿠키"] = 2800
menu["샌드위치"] = 6000

print(f"쿠키: {menu['쿠키']:,}원")
print(f"샌드위치: {menu['샌드위치']:,}원")
~~~

**실행 결과**

~~~text
2500
쿠키: 2,800원
샌드위치: 6,000원
~~~

기존 키에 값을 대입하면 가격이 바뀝니다. 새 키에 값을 대입하면 메뉴가 추가됩니다. `menu["차"]`처럼 등록되지 않은 키를 대괄호로 조회하면 `KeyError`가 발생합니다. 등록 여부만 확인하려면 `"차" in menu`를 사용합니다. 이 식의 결과는 `False`입니다.

## 4.4. Set — 중복 없이 값 모으기

집합은 같은 값을 한 번만 저장합니다. 집합에는 인덱스가 없으므로, 특정 항목의 존재 여부를 확인하거나 중복을 제거할 때 사용합니다.

### 예제 4-5. 주문한 메뉴의 종류 세기

~~~python
orders = ["커피", "쿠키", "커피"]
ordered_items = set(orders)

print(len(ordered_items))
print("쿠키" in ordered_items)
~~~

**실행 결과**

~~~text
2
True
~~~

주문은 세 건이고, 주문한 메뉴는 두 종류입니다. `set(orders)`는 리스트의 값을 읽어 새 집합을 만듭니다. 원래 주문 목록에는 커피 두 건이 그대로 남습니다.

집합은 `{"커피", "쿠키"}`처럼 만들 수도 있습니다. 빈 집합은 `set()`으로 만듭니다. `{}`는 빈 딕셔너리입니다.

## Summary

- 리스트와 튜플은 인덱스로 값을 읽습니다. 첫 번째 항목은 `[0]`, 마지막 항목은 `[-1]`로 읽습니다. `[::-1]`은 순서를 뒤집은 새 리스트를 만듭니다.
- 리스트는 항목을 수정할 수 있습니다. 튜플은 생성 후 각 자리에 있는 항목을 바꿀 수 없습니다.
- 딕셔너리는 키로 값을 조회합니다. 같은 키에 다시 대입하면 값이 갱신됩니다.
- 집합은 중복된 값을 하나로 모읍니다. 항목이 들어 있는지는 `in`으로 확인할 수 있습니다.

## Mini Project

### 카페 주문 요약표 만들기

메뉴 가격표와 두 건의 주문을 이용해 주문별 금액과 합계를 출력합니다. 같은 메뉴가 두 번 들어올 수도 있습니다. 커피가 두 번 들어오면 주문은 2건이고 메뉴는 1종입니다.

**시작 코드**

~~~python
menu = {"커피": 4800, "쿠키": 2500, "샌드위치": 6000}
orders = ["커피", "쿠키"]
~~~

**요구사항**

1. 인덱스를 사용해 첫 번째와 두 번째 주문의 메뉴 이름을 읽는다.
2. 딕셔너리에서 각 메뉴의 가격을 찾아 주문별 가격과 합계를 구한다.
3. 주문 건수와 주문한 메뉴의 종류 수를 출력한다.
4. 각 금액에 천 단위 구분 기호와 `원`을 표시한다.

**실행 예시**

~~~text
첫 번째 주문: 커피 4,800원
두 번째 주문: 쿠키 2,500원
합계: 7,300원
전체 주문: 2건
메뉴 종류: 2종
~~~

**확인할 사항**

- `orders`를 `["커피", "커피"]`로 바꾸면 전체 주문은 2건, 메뉴 종류는 1종, 합계는 9,600원으로 표시되는가?
- `menu`에서 커피 가격을 5,000원으로 바꾸면 새 가격이 합계에 반영되는가?

주문은 가격표에 등록된 메뉴 두 건으로 가정합니다. 챕터 5의 조건문을 배우면 등록되지 않은 메뉴에 다른 안내를 표시할 수 있습니다. 챕터 6의 반복문을 배우면 주문이 몇 건이든 같은 방식으로 합계를 구할 수 있습니다.
