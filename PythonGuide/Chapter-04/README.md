## Summary

- 리스트는 순서대로 항목을 담고 인덱스로 읽습니다. 항목을 추가하거나 바꿀 수 있습니다.
- 딕셔너리는 키와 값을 한 쌍으로 담고 키로 값을 읽습니다.
- 튜플은 순서대로 값을 묶으며, 만든 뒤 개별 항목을 교체할 수 없습니다.
- 집합은 중복 없이 값을 담으며, 포함 여부와 공통 항목을 확인할 때 사용합니다.
