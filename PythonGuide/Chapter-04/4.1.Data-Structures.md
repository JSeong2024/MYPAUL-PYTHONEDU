# 4.1. Data Structures

챕터 3에서는 카페에서 받은 주문의 수량과 금액을 변수에 담아 계산했습니다. 이번에는 음악 앱이 곡 정보를 어떻게 다루는지 생각해 봅시다.

플레이리스트를 열었을 때는 첫 곡부터 어떤 순서로 재생되는지 알아야 합니다. 같은 곡을 두 번 넣었다면 두 자리 모두 필요합니다. 아티스트 이름으로 특정 곡을 찾는 화면에서는 아티스트와 곡 제목이 어떻게 연결되어 있는지가 중요합니다.

이처럼 데이터를 담아 두고 필요한 정보를 꺼내 쓸 수 있도록 정리하는 방식을 **자료구조**(**Data Structure**)라고 합니다. 파이썬에서 자주 쓰는 네 가지 자료구조를 용도에 따라 살펴봅시다.

<table align="center">
  <thead>
    <tr><th>자료구조</th><th>언제 쓸까요?</th><th>예시</th></tr>
  </thead>
  <tbody>
    <tr><td><a href="./4.2.List.md">리스트 (List)</a></td><td>항목을 순서대로 담고 위치를 기준으로 읽을 때</td><td>첫 번째 곡과 다음 곡을 확인합니다.</td></tr>
    <tr><td><a href="./4.3.Dictionary.md">딕셔너리 (Dictionary)</a></td><td>키와 값을 한 쌍으로 저장하고 키로 값을 찾을 때</td><td>아티스트 이름으로 연결된 곡 제목을 찾습니다.</td></tr>
    <tr><td><a href="./4.4.Tuple-and-Set.md">튜플 (Tuple)</a></td><td>각 자리의 역할이 정해진 값을 묶고, 만든 뒤 항목을 그대로 둘 때</td><td>좌석 구역과 번호를 한 묶음으로 다룹니다.</td></tr>
    <tr><td><a href="./4.4.Tuple-and-Set.md">집합 (Set)</a></td><td>중복을 빼거나 공통 항목을 찾을 때</td><td>플레이리스트에서 서로 다른 곡 제목의 수를 셉니다.</td></tr>
  </tbody>
</table>

같은 플레이리스트에서도 재생할 곡의 개수와 서로 다른 제목의 개수는 다를 수 있습니다. 무엇을 기록하거나 확인할지 먼저 생각하면, 그 일에 맞는 자료구조를 고르기 쉽습니다.
