# 8.2. Menu and Order Records

**메뉴판과 주문 기록**

손님의 주문을 받으려면 메뉴 이름을 통해 해당 메뉴의 가격을 조회할 수 있어야 합니다. 또한 전체 주문 금액을 계산하고 영수증을 출력하려면 메뉴 이름, 주문 수량, 단가 등의 정보를 기록해야 합니다.

이번 절에서는 메뉴판을 **딕셔너리**(**Dictionary**)로 구성하고, 각각의 주문 내역을 **리스트**(**List**)에 저장하는 방법을 알아봅시다.

## 8.2.1. 메뉴판 만들기

딕셔너리에 메뉴 이름을 **키**(**Key**)로, 메뉴 한 개의 가격을 **값**(**Value**)으로 저장합니다. 이렇게 구성하면 메뉴 이름을 사용하여 해당 메뉴의 가격을 조회할 수 있습니다.

6.5.3절에서 배운 `items()` 메서드를 사용하여 딕셔너리의 키와 값을 한 쌍씩 꺼내고, 메뉴 이름과 가격을 출력해 봅시다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")
```

**실행 결과**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원
```

반복문이 실행될 때마다 메뉴 이름은 `name`에, 가격은 `price`에 저장됩니다. f-문자열의 형식 지정자 `:,`를 사용하여 가격에 천 단위 쉼표를 표시합니다.

> 메뉴의 가격을 변경하거나 새로운 메뉴를 추가할 때는 `menu` 딕셔너리의 데이터만 수정하면 됩니다. 메뉴판을 출력하는 반복문은 별도로 수정할 필요가 없습니다.

## 8.2.2. 주문 한 건 저장하기

손님이 커피를 두 잔 주문했다고 가정해 봅시다. 주문 한 건에는 메뉴 이름, 수량, 단가의 세 가지 정보가 필요합니다.

이러한 정보를 하나의 **튜플**(**Tuple**)로 묶어 주문 기록을 구성합니다.

주문 기록은 `("커피", 2, 4800)`과 같은 형태로 구성합니다. 여러 건의 주문을 입력된 순서대로 관리할 수 있도록 각각의 튜플을 `orders` 리스트에 추가합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

item = "커피"
quantity = 2

if item not in menu:
    print("판매하지 않는 메뉴입니다.")
elif quantity < 1:
    print("수량은 1 이상이어야 합니다.")
else:
    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

print(orders)
```

**실행 결과**

```text
[('커피', 2, 4800)]
```

프로그램은 다음 순서로 주문을 처리합니다.

1. `item not in menu` 조건으로 주문한 메뉴가 등록되어 있는지 확인합니다.
2. `quantity < 1` 조건으로 주문 수량이 유효한지 확인합니다.
3. 메뉴와 수량이 모두 유효하면 `menu[item]`을 사용하여 해당 메뉴의 단가를 조회합니다.
4. 메뉴 이름, 수량, 단가를 하나의 튜플로 구성합니다.
5. `append()` 메서드를 사용하여 주문 기록을 `orders` 리스트에 추가합니다.

> `orders.append((item, quantity, unit_price))`에서 바깥쪽 소괄호는 `append()` 메서드를 호출하기 위해 사용하고, 안쪽 소괄호는 주문 정보를 하나의 튜플로 구성하기 위해 사용합니다. 따라서 세 개의 값이 각각 추가되는 것이 아니라, 세 개의 값을 포함한 튜플 하나가 리스트에 추가됩니다.

메뉴판에 없는 메뉴를 주문하거나 수량이 `1` 미만이면 주문 기록은 추가되지 않습니다. `item`과 `quantity`의 값을 변경하여 프로그램의 동작을 확인해 봅시다.

각 경우는 `orders`가 빈 리스트인 상태에서 프로그램을 새로 실행한 결과입니다.

> 메뉴가 등록되어 있는지 확인하지 않고 `menu[item]`으로 가격을 조회하면, 존재하지 않는 키에 접근하여 `KeyError`가 발생할 수 있습니다. 따라서 메뉴의 존재 여부를 먼저 검사한 뒤 가격을 조회합니다.

## 8.2.3. 저장한 주문으로 금액 확인하기

`orders` 리스트에 저장된 주문 기록을 사용하여 주문 금액을 계산해 봅시다.

리스트의 인덱스 `0`을 사용하면 첫 번째 주문 기록을 꺼낼 수 있습니다. 튜플에 저장된 여러 값을 각각의 변수에 나누어 대입하는 것을 **언패킹**(**Unpacking**)이라고 합니다.

```python
orders = [("커피", 2, 4800)]

name, quantity, unit_price = orders[0]
amount = quantity * unit_price

print(f"{name} × {quantity}: {amount:,}원")
```

**실행 결과**

```text
커피 × 2: 9,600원
```

`orders[0]`은 첫 번째 주문 기록인 `("커피", 2, 4800)`을 가져옵니다. 언패킹을 통해 튜플의 각 값은 다음과 같이 변수에 대입됩니다.

주문 기록에 단가를 함께 저장했으므로 메뉴판에서 가격을 다시 조회하지 않고도 주문 금액을 계산할 수 있습니다.

> 주문 기록에 단가를 저장하면 이후 메뉴판의 가격이 변경되더라도 주문 당시의 가격을 기준으로 금액을 계산할 수 있습니다.
>
> 이 예제에서는 주문 기록이 한 건 이상 존재한다고 가정합니다. `orders`가 빈 리스트인 상태에서 `orders[0]`에 접근하면 `IndexError`가 발생합니다.

지금까지 메뉴판을 구성하고, 주문 한 건을 저장한 뒤 주문 금액을 계산하는 방법을 알아보았습니다. 8.3절에서는 반복문을 사용하여 여러 건의 주문을 입력받고 저장하는 기능을 구현합니다. 8.4절에서는 저장된 모든 주문 기록을 활용하여 전체 주문 합계를 계산하고 영수증을 출력합니다.
