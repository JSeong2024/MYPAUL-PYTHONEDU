# 8.2. Menu and Order Records

**메뉴판과 주문 기록**

주문을 받으려면 메뉴 이름으로 가격을 찾을 수 있어야 합니다. 주문을 받은 뒤에는 어떤 메뉴를 몇 개 주문했는지 남겨야 합니다. 메뉴판은 딕셔너리로 만들고, 주문 내역은 리스트에 저장해 봅시다.

## 8.2.1. 메뉴판 만들기

메뉴 이름을 키로, 한 개의 가격을 값으로 저장합니다. 아래 코드에서는 키와 값을 한 쌍씩 꺼내 메뉴판을 출력합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")
```

**실행 결과**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원
```

## 8.2.2. 주문 한 건 저장하기

손님이 커피를 두 잔 주문했습니다. 주문 한 건은 **메뉴 이름, 수량, 단가**를 순서대로 담은 튜플로 기록합니다. 여러 주문을 받은 순서대로 보관할 수 있도록, 이 튜플을 리스트 `orders`에 추가합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

item = "커피"
quantity = 2

if item not in menu:
    print("판매하지 않는 메뉴입니다.")
elif quantity < 1:
    print("수량은 1 이상이어야 합니다.")
else:
    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

print(orders)
```

**실행 결과**

```text
[('커피', 2, 4800)]
```

> `orders.append((item, quantity, unit_price))`의 안쪽 괄호는 주문 한 건을 튜플로 묶습니다. 이 튜플 하나가 리스트의 끝에 추가됩니다.

메뉴가 등록되어 있고 수량이 1 이상일 때만 가격을 조회하고 주문을 추가합니다. `item = "주스"`로 바꾸거나, 커피를 주문하면서 `quantity = 0`으로 바꾸면 안내 문구가 나오고 주문 목록은 빈 리스트 `[]`로 남습니다.

## 8.2.3. 저장한 주문으로 금액 확인하기

주문 목록에서 첫 번째 기록을 꺼냅니다. 튜플에 담긴 세 값을 `name`, `quantity`, `unit_price`에 순서대로 나누어 담은 뒤, 수량과 단가를 곱합니다.

```python
orders = [("커피", 2, 4800)]

name, quantity, unit_price = orders[0]
amount = quantity * unit_price

print(f"{name} × {quantity}: {amount:,}원")
```

**실행 결과**

```text
커피 × 2: 9,600원
```

이 예제는 주문이 한 건 들어 있는 상태에서 시작합니다. `orders[0]`은 첫 주문 한 건을 가리키고, `unit_price`에는 그 주문을 기록할 때 저장한 단가가 들어갑니다. 8.4절에서는 같은 방식으로 주문을 한 건씩 읽어 영수증을 출력합니다.
