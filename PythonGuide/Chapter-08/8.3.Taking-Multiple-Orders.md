# 8.3. Taking Multiple Orders

**여러 주문 받기**

8.2절에서는 메뉴 이름, 수량, 단가를 튜플로 묶어 주문 리스트에 저장했습니다. 이번에는 손님이 메뉴 이름에 `0`을 입력할 때까지 같은 작업을 반복합니다.

## 8.3.1. 주문을 계속 받을지 판단하기

메뉴 이름을 먼저 입력받습니다. `0`이면 `break`로 주문을 마칩니다. 가격표에 없는 이름이면 안내를 출력하고 `continue`로 다음 메뉴를 받습니다. 등록된 메뉴에만 수량을 묻고, 수량이 1 이상일 때 주문을 저장합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")

print()
while True:
    item = input("메뉴 이름 (주문 종료: 0): ")

    if item == "0":
        break

    if item not in menu:
        print("판매하지 않는 메뉴입니다.")
        continue

    quantity = int(input("수량: "))

    if quantity < 1:
        print("수량은 1 이상이어야 합니다.")
        continue

    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

if orders:
    print(f"저장한 주문: {len(orders)}건")
    print(orders)
else:
    print("저장한 주문이 없습니다.")
```

**실행 예시**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 커피
수량: 2
메뉴 이름 (주문 종료: 0): 쿠키
수량: 2
메뉴 이름 (주문 종료: 0): 0
저장한 주문: 2건
[('커피', 2, 4800), ('쿠키', 2, 2500)]
```

> `input()`이 돌려주는 메뉴 이름은 문자열입니다. 주문을 끝내는 값도 정수 `0`이 아닌 문자열 `"0"`과 비교합니다. 수량은 정수를 입력한다고 가정하고 `int()`로 바꿉니다.

`if orders:`는 주문 리스트에 항목이 있을 때 참입니다. 이 절에서는 결제로 넘어가기 전에 저장된 주문을 확인할 수 있도록 리스트를 출력합니다. 같은 메뉴를 여러 번 입력하면 들어온 순서대로 별도의 주문 기록에 저장합니다.
