# 8.3. Taking Multiple Orders

**여러 주문 받기**

8.2절에서는 메뉴 이름, 수량, 단가를 하나의 튜플로 구성하여 주문 리스트에 저장하는 방법을 알아보았습니다. 이번에는 6.8.3절에서 배운 `while True`와 `break`, `continue` 문을 활용하여 여러 건의 주문을 연속으로 받는 기능을 구현해 봅시다.

사용자가 메뉴 이름에 `0`을 입력할 때까지 주문을 반복해서 받고, 메뉴와 수량이 모두 유효한 주문만 리스트에 저장합니다.

## 8.3.1. 주문을 계속 받을지 판단하기

`while True`를 사용하면 조건이 항상 참이므로 반복문을 계속 실행할 수 있습니다. 반복문 내부에서는 입력값에 따라 주문을 저장하거나, 다음 반복으로 넘어가거나, 반복문을 종료하도록 구성합니다.

주문을 처리하는 순서는 다음과 같습니다.

1. 메뉴 이름을 입력받습니다.
2. 메뉴 이름이 `"0"`이면 `break` 문으로 반복문을 종료합니다.
3. 등록되지 않은 메뉴라면 안내 문구를 출력하고 `continue` 문으로 다음 반복을 시작합니다.
4. 등록된 메뉴라면 주문 수량을 입력받습니다.
5. 수량이 `1` 미만이면 안내 문구를 출력하고 `continue` 문으로 다음 반복을 시작합니다.
6. 메뉴와 수량이 모두 유효하면 단가를 조회하고 주문 기록을 리스트에 추가합니다.

수량에는 항상 정수가 입력된다고 가정합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")

print()
while True:
    item = input("메뉴 이름 (주문 종료: 0): ")

    if item == "0":
        break

    if item not in menu:
        print("판매하지 않는 메뉴입니다.")
        continue

    quantity = int(input("수량: "))

    if quantity < 1:
        print("수량은 1 이상이어야 합니다.")
        continue

    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

if orders:
    print(f"저장한 주문: {len(orders)}건")
    print(orders)
else:
    print("저장한 주문이 없습니다.")
```

**실행 예시**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 커피
수량: 2
메뉴 이름 (주문 종료: 0): 쿠키
수량: 2
메뉴 이름 (주문 종료: 0): 0
저장한 주문: 2건
[('커피', 2, 4800), ('쿠키', 2, 2500)]
```

> `input()` 함수의 반환값은 문자열(`str`)입니다. 따라서 주문 종료 조건에서는 정수 `0`이 아닌 문자열 `"0"`과 비교해야 합니다. 수량은 크기 비교와 산술 연산에 사용하므로 `int()` 함수로 정수형 값을 변환하여 저장합니다.

주문을 입력할 때마다 `orders` 리스트에 새로운 주문 기록이 추가됩니다. 위 실행 예시에서 리스트의 변화 과정은 다음과 같습니다.

`orders` 리스트는 반복문 외부에서 빈 리스트로 초기화합니다. 따라서 새로운 반복이 시작되더라도 이전에 저장한 주문 기록은 유지됩니다.

주문 입력이 끝나면 `if orders:` 조건문으로 저장된 주문이 있는지 확인합니다. 리스트에 요소가 하나 이상 있으면 참(`True`), 빈 리스트이면 거짓(`False`)으로 평가됩니다.

이번 절에서는 결제 기능을 구현하기 전에 주문이 정상적으로 저장되었는지 확인하기 위해 `len()` 함수를 사용하여 주문 건수를 구하고 리스트의 내용을 출력합니다.

> `len(orders)`는 전체 주문 수량이 아니라 리스트에 저장된 주문 기록의 개수를 반환합니다. 같은 메뉴를 여러 번 주문하더라도 각각 별도의 튜플로 기록됩니다.

## 8.3.2. 입력에 따라 달라지는 흐름 확인하기

사용자가 입력한 메뉴 이름과 수량에 따라 반복문의 실행 흐름이 달라집니다. 각 입력 조건에서 프로그램이 어떻게 동작하는지 살펴봅시다.

잘못된 메뉴 이름과 수량을 입력한 뒤 정상적인 주문을 입력하여 프로그램의 동작을 확인해 봅시다.

**실행 예시 1 — 잘못된 입력과 정상적인 주문**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 주스
판매하지 않는 메뉴입니다.
메뉴 이름 (주문 종료: 0): 커피
수량: 0
수량은 1 이상이어야 합니다.
메뉴 이름 (주문 종료: 0): 차
수량: 1
메뉴 이름 (주문 종료: 0): 0
저장한 주문: 1건
[('차', 1, 3000)]
```

등록되지 않은 메뉴인 `주스`를 입력하면 수량을 입력받지 않고 다음 반복으로 넘어갑니다. 커피를 선택한 뒤 수량에 `0`을 입력한 경우에도 주문 기록을 추가하지 않고 다음 반복으로 넘어갑니다.

따라서 `orders` 리스트에는 정상적으로 입력한 차 한 잔의 주문 기록만 저장됩니다.

**실행 예시 2 — 주문 없이 종료**

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 0
저장한 주문이 없습니다.
```

프로그램을 실행한 직후 메뉴 이름에 `0`을 입력하면 `break` 문이 실행되어 반복문이 종료됩니다. 이때 `orders`는 빈 리스트이므로 `if orders:` 조건이 거짓으로 평가되고, `else` 블록의 안내 문구가 출력됩니다.

잘못된 메뉴 이름이나 수량만 입력한 뒤 주문을 종료하는 경우에도 주문 기록은 추가되지 않으므로 동일한 안내 문구가 출력됩니다.

> `break` 문은 반복문 자체를 종료하지만, `continue` 문은 현재 반복에서 남은 코드를 건너뛰고 다음 반복을 시작합니다. 이 프로그램에서는 주문 종료와 잘못된 주문 처리에 각각 활용합니다.

이제 여러 건의 주문을 입력받아 리스트에 저장할 수 있습니다. 8.4절에서는 저장된 주문 기록을 바탕으로 전체 주문 합계와 할인액을 계산하고, 결제 및 영수증 출력 기능을 구현합니다.
