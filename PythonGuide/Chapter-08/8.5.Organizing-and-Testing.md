# 8.5. Organizing and Testing

**함수로 정리하고 결과 확인하기**

8.4절에서는 주문을 받고 결제 금액을 계산한 뒤 영수증을 출력했습니다. 이번에는 작업마다 이름을 붙여 함수로 나눕니다. `main()`에서는 함수들을 호출해 주문부터 결제까지 진행합니다.

## 8.5.2. 완성 코드

```python
def take_orders(menu):
    orders = []

    print("메뉴판")
    for name, price in menu.items():
        print(f"{name}: {price:,}원")

    print()
    while True:
        item = input("메뉴 이름 (주문 종료: 0): ")

        if item == "0":
            break

        if item not in menu:
            print("판매하지 않는 메뉴입니다.")
            continue

        quantity = int(input("수량: "))

        if quantity < 1:
            print("수량은 1 이상이어야 합니다.")
            continue

        unit_price = menu[item]
        orders.append((item, quantity, unit_price))
    return orders


def calculate_total(orders):
    total = 0
    for item, quantity, unit_price in orders:
        total += quantity * unit_price
    return total


def calculate_discount(total):
    if total >= 30_000:
        rate = 10
    elif total >= 10_000:
        rate = 5
    else:
        rate = 0
    return total * rate // 100


def print_receipt(orders, total, discount, payment, paid):
    change = paid - payment
    print("영수증")
    for item, quantity, unit_price in orders:
        amount = quantity * unit_price
        print(f"{item} × {quantity}: {amount:,}원")

    print(f"주문 합계: {total:,}원")
    print(f"할인액: {discount:,}원")
    print(f"결제 금액: {payment:,}원")
    print(f"받은 돈: {paid:,}원")
    print(f"거스름돈: {change:,}원")


def main():
    menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
    orders = take_orders(menu)

    if not orders:
        print("저장한 주문이 없습니다.")
        return

    total = calculate_total(orders)
    discount = calculate_discount(total)
    payment = total - discount

    print()
    print(f"결제 금액: {payment:,}원")
    paid = int(input("받은 돈: "))

    if paid < payment:
        print(f"{payment - paid:,}원이 부족합니다.")
    else:
        print()
        print_receipt(orders, total, discount, payment, paid)


main()
```

`take_orders(menu)`에서 `0`을 입력하면 `break`로 주문 입력 반복을 끝내고 `return orders`로 리스트를 돌려줍니다. `main()`이 빈 리스트를 받으면 안내를 출력한 뒤 `return`으로 함수 실행을 끝냅니다.

계산 함수는 금액을 반환합니다. `main()`은 그 값으로 결제 금액을 계산하고, 받은 돈이 충분할 때만 `print_receipt()`를 호출합니다.
