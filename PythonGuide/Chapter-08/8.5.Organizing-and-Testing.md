# 8.5. Organizing and Testing

**함수로 정리하고 결과 확인하기**

8.4절에서는 주문 입력부터 결제 금액 계산, 영수증 출력까지 모든 기능을 하나의 실행 흐름으로 구현했습니다. 이번에는 7.6절에서 배운 기능 분해를 활용하여 프로그램을 역할별 함수로 나누어 봅시다.

각 함수는 자신이 담당하는 작업을 수행하고, `main()` 함수는 다른 함수들을 호출하여 프로그램의 전체 실행 흐름을 관리합니다. 프로그램을 완성한 뒤에는 다양한 입력값을 사용하여 각 기능이 올바르게 동작하는지 확인합니다.

## 8.5.1. 작업을 함수로 나누기

프로그램을 기능별로 나누면 각 함수의 역할이 명확해지고, 특정 기능을 독립적으로 수정하거나 검증하기 쉬워집니다.

계산을 담당하는 함수는 계산 결과를 반환하고, 출력 기능을 담당하는 함수는 필요한 정보를 전달받아 화면에 출력합니다. 각 함수에서 필요한 데이터는 매개변수를 통해 전달하며, 작업 결과는 `return`을 통해 반환합니다.

> `main()`은 Python에서 특별한 동작을 수행하는 내장 함수나 키워드가 아닙니다. 프로그램의 주요 실행 흐름을 담당하는 함수에 관례적으로 사용하는 이름이며, 다른 사용자 정의 함수와 마찬가지로 직접 호출해야 실행됩니다.

## 8.5.2. 함수 틀 완성하기

아래 틀의 `pass`를 필요한 코드로 바꾸어 보세요. 8.4.2절에서 작성한 코드의 동작을 유지하면서 역할표에 맞춰 옮깁니다.

1. `take_orders()`에서 메뉴판을 출력하고 메뉴 이름에 `0`이 들어올 때까지 주문을 받습니다. 유효한 주문만 `(메뉴 이름, 수량, 단가)` 튜플로 기록하고, 리스트를 반환합니다.
2. `calculate_total()`과 `calculate_discount()`는 각각 주문 합계와 할인액을 반환합니다. 할인율은 30,000원 이상 10%, 10,000원 이상 30,000원 미만 5%, 그 미만 0%입니다. 할인액의 1원 미만은 버립니다.
3. `main()`에서 주문이 없으면 안내 후 종료합니다. 주문이 있으면 결제 금액을 표시하고 받은 돈을 입력받습니다. 부족하면 부족액을 안내하고, 충분하면 `print_receipt()`를 호출합니다.
4. `print_receipt()`는 아래 실행 예시와 같은 항목을 출력합니다. 계산 함수의 반환값은 `main()`에서 받아 영수증 함수에 넘깁니다.

```python
def take_orders(menu):
    orders = []

    print("메뉴판")
    for name, price in menu.items():
        print(f"{name}: {price:,}원")

    print()
    while True:
        item = input("메뉴 이름 (주문 종료: 0): ")

        if item == "0":
            break

        if item not in menu:
            print("판매하지 않는 메뉴입니다.")
            continue

        quantity = int(input("수량: "))

        if quantity < 1:
            print("수량은 1 이상이어야 합니다.")
            continue

        unit_price = menu[item]
        orders.append((item, quantity, unit_price))
    return orders


def calculate_total(orders):
    total = 0
    for item, quantity, unit_price in orders:
        total += quantity * unit_price
    return total


def calculate_discount(total):
    if total >= 30_000:
        rate = 10
    elif total >= 10_000:
        rate = 5
    else:
        rate = 0
    return total * rate // 100


def print_receipt(orders, total, discount, payment, paid):
    change = paid - payment
    print("영수증")
    for item, quantity, unit_price in orders:
        amount = quantity * unit_price
        print(f"{item} × {quantity}: {amount:,}원")

    print(f"주문 합계: {total:,}원")
    print(f"할인액: {discount:,}원")
    print(f"결제 금액: {payment:,}원")
    print(f"받은 돈: {paid:,}원")
    print(f"거스름돈: {change:,}원")


def main():
    menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
    orders = take_orders(menu)

    if not orders:
        print("저장한 주문이 없습니다.")
        return

    total = calculate_total(orders)
    discount = calculate_discount(total)
    payment = total - discount

    print()
    print(f"결제 금액: {payment:,}원")
    paid = int(input("받은 돈: "))

    if paid < payment:
        print(f"{payment - paid:,}원이 부족합니다.")
    else:
        print()
        print_receipt(orders, total, discount, payment, paid)


main()
```

### 프로그램의 실행 흐름

`main()` 함수가 호출되면 메뉴판을 구성하고, 주문 입력부터 결제 및 영수증 출력까지 각 기능을 순서대로 실행합니다.

1. `take_orders(menu)`를 호출하여 메뉴판을 출력하고 주문을 입력받습니다.
2. 사용자가 메뉴 이름에 `0`을 입력하면 주문 입력을 종료하고 `orders` 리스트를 반환합니다.
3. 반환받은 주문 리스트가 비어 있다면 안내 문구를 출력하고 `main()` 함수의 실행을 종료합니다.
4. `calculate_total(orders)`를 호출하여 전체 주문 합계를 계산합니다.
5. `calculate_discount(total)`을 호출하여 할인액을 계산합니다.
6. 주문 합계에서 할인액을 빼 최종 결제 금액을 구합니다.
7. 손님에게 받은 돈을 입력받고 결제 가능 여부를 확인합니다.
8. 결제가 가능하면 `print_receipt()`를 호출하여 영수증을 출력하고, 받은 돈이 부족하면 부족한 금액을 안내합니다.

각 함수는 필요한 값을 매개변수로 전달받아 작업을 수행합니다. 예를 들어 `take_orders()` 함수 내부에서 생성한 지역 변수 `orders`는 `return orders`를 통해 반환되며, `main()` 함수에서는 반환받은 리스트를 `orders` 변수에 저장합니다.

이처럼 7.3절과 7.4절에서 배운 매개변수와 반환값을 활용하면 전역 변수에 의존하지 않고도 함수 사이에서 필요한 데이터를 전달할 수 있습니다.

### `return`을 활용하여 함수 일찍 종료하기

`main()` 함수에서는 주문 내역이 없는 경우 다음 코드가 실행됩니다.

```python
if not orders:
    print("저장한 주문이 없습니다.")
    return
```

`orders`가 빈 리스트이면 안내 문구를 출력한 뒤 `return` 문을 실행합니다. 이 시점에서 `main()` 함수의 실행이 종료되므로 주문 합계 계산, 할인액 계산, 결제 과정은 실행되지 않습니다.

> 7.4.2절에서 살펴본 것처럼 반환할 값을 작성하지 않고 `return`만 사용하면 `None`을 반환하면서 현재 함수의 실행을 종료합니다. 이러한 방식을 활용하면 불필요한 중첩 조건문을 줄일 수 있습니다.

8.4절의 코드와 비교하면 프로그램의 구조는 달라졌지만 실행 결과는 동일합니다. 기존 기능을 유지하면서 코드의 구조를 개선하는 작업을 **리팩터링**(**Refactoring**)이라고 합니다.

### 개별 함수 검증

프로그램을 함수로 나누면 전체 프로그램을 실행하지 않고도 특정 기능을 독립적으로 검증할 수 있습니다.

예를 들어 할인액 계산 기능만 확인하려면 다음과 같이 `calculate_discount()` 함수를 직접 호출할 수 있습니다.

```python
def calculate_discount(total):
    if total >= 30_000:
        rate = 10
    elif total >= 10_000:
        rate = 5
    else:
        rate = 0
    return total * rate // 100


for total in [9_999, 10_000, 29_999, 30_000]:
    discount = calculate_discount(total)
    print(f"주문 합계: {total:,}원, 할인액: {discount:,}원")
```

**실행 결과**

```text
주문 합계: 9,999원, 할인액: 0원
주문 합계: 10,000원, 할인액: 500원
주문 합계: 29,999원, 할인액: 1,499원
주문 합계: 30,000원, 할인액: 3,000원
```

이 예제에서는 메뉴판의 가격과 관계없이 주문 합계를 인수로 직접 전달하므로 할인 기준에 해당하는 경계값을 정확하게 검증할 수 있습니다.

> 전체 프로그램과 개별 함수를 각각 검증하면 오류가 발생했을 때 어느 기능에서 문제가 발생했는지 파악하기 쉽습니다.

이제 딕셔너리, 리스트, 튜플, 조건문, 반복문, 함수를 종합적으로 활용한 카페 주문 프로그램이 완성되었습니다. 프로그램을 기능별로 나누고 다양한 입력값으로 검증하는 과정은 앞으로 더 복잡한 프로그램을 개발할 때에도 활용할 수 있습니다.
