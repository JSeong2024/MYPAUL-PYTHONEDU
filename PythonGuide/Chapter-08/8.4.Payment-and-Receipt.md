# 8.4. Payment and Receipt

**결제와 영수증**

8.3절에서는 여러 건의 주문을 입력받아 리스트에 저장하는 기능을 구현했습니다. 이번에는 저장된 주문 내역을 하나씩 읽어 전체 주문 합계를 구하고, 할인율을 적용하여 최종 결제 금액을 계산해 봅시다.

이후 손님에게 받은 돈으로 결제할 수 있는지 확인하고, 주문 내역과 결제 정보가 포함된 영수증을 출력합니다.

## 8.4.1. 주문 합계와 할인액 구하기

`orders` 리스트의 각 요소는 메뉴 이름, 수량, 단가로 구성된 튜플입니다. `for` 문과 언패킹을 사용하면 각 주문 기록에 저장된 세 값을 한 번에 꺼낼 수 있습니다.

전체 주문 합계를 저장할 변수 `total`을 `0`으로 초기화하고, 각 주문의 수량(`quantity`)과 단가(`unit_price`)를 곱한 금액을 `total`에 누적합니다.

```python
orders = [("커피", 2, 4800), ("쿠키", 2, 2500)]
total = 0

for item, quantity, unit_price in orders:
    total += quantity * unit_price

if total >= 30_000:
    rate = 10
elif total >= 10_000:
    rate = 5
else:
    rate = 0

discount = total * rate // 100
payment = total - discount

print(f"주문 합계: {total:,}원")
print(f"할인액: {discount:,}원")
print(f"결제 금액: {payment:,}원")
```

```text

결제 금액: 13,870원
```

5.3절에서 배운 `if-elif-else` 문은 위에서부터 조건을 검사하고, 처음으로 참이 되는 조건에 해당하는 코드 블록만 실행합니다.

`total >= 30_000`을 만족하는 금액은 `total >= 10_000`도 만족합니다. 따라서 이처럼 조건의 범위가 겹치는 경우에는 더 높은 금액 기준부터 검사해야 올바른 할인율을 적용할 수 있습니다.

할인율을 결정한 뒤에는 할인액과 최종 결제 금액을 계산합니다.

- `discount = total * rate // 100`: 전체 주문 합계에 할인율을 적용하여 할인액을 계산합니다.
- `payment = total - discount`: 전체 주문 합계에서 할인액을 빼 최종 결제 금액을 계산합니다.

이 예제에서는 전체 주문 합계가 14,600원이므로 5%의 할인율이 적용됩니다. 할인액은 730원이며, 최종 결제 금액은 13,870원입니다.

> 몫을 구하는 연산자(`//`)는 나눗셈 결과를 내림합니다. 이 프로그램에서는 주문 합계와 할인율이 모두 `0` 이상의 정수이므로 `total * rate // 100`으로 계산하면 할인액의 1원 미만 단위를 버릴 수 있습니다.

## 8.4.2. 결제를 확인하고 영수증 출력하기

8.3절에서 구현한 주문 입력 기능에 결제 금액 계산과 영수증 출력 기능을 추가해 봅시다.

주문 입력이 끝나면 `if not orders:` 조건으로 저장된 주문 내역이 있는지 확인합니다. 주문 내역이 없다면 안내 문구만 출력하고 결제를 진행하지 않습니다.

주문이 한 건 이상 저장되어 있다면 전체 주문 합계와 할인액을 계산하고, 손님에게 받은 돈을 입력받습니다. 수량에는 정수가 입력되며, 받은 돈에는 `0` 이상의 정수가 입력된다고 가정합니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")

print()
while True:
    item = input("메뉴 이름 (주문 종료: 0): ")

    if item == "0":
        break

    if item not in menu:
        print("판매하지 않는 메뉴입니다.")
        continue

    quantity = int(input("수량: "))

    if quantity < 1:
        print("수량은 1 이상이어야 합니다.")
        continue

    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

if not orders:
    print("저장한 주문이 없습니다.")
else:
    total = 0
    for item, quantity, unit_price in orders:
        total += quantity * unit_price

    if total >= 30_000:
        rate = 10
    elif total >= 10_000:
        rate = 5
    else:
        rate = 0

    discount = total * rate // 100
    payment = total - discount

    print()
    print(f"결제 금액: {payment:,}원")
    paid = int(input("받은 돈: "))

    if paid < payment:
        print(f"{payment - paid:,}원이 부족합니다.")
    else:
        change = paid - payment

        print()
        print("영수증")
        for item, quantity, unit_price in orders:
            amount = quantity * unit_price
            print(f"{item} × {quantity}: {amount:,}원")

        print(f"주문 합계: {total:,}원")
        print(f"할인액: {discount:,}원")
        print(f"결제 금액: {payment:,}원")
        print(f"받은 돈: {paid:,}원")
        print(f"거스름돈: {change:,}원")
```

받은 돈이 결제 금액보다 적으면 `paid < payment` 조건이 참이므로 부족한 금액인 `payment - paid`를 계산하여 출력합니다. 이 경우에는 거스름돈을 계산하거나 영수증을 출력하지 않습니다.

반대로 받은 돈이 결제 금액 이상이면 `paid - payment`로 거스름돈을 계산한 뒤 영수증을 출력합니다.

정상적으로 결제하는 경우 `orders` 리스트를 총 두 번 순회합니다.

1. 첫 번째 순회에서는 각 주문의 금액을 누적하여 전체 주문 합계를 계산합니다.
2. 두 번째 순회에서는 각 주문의 금액을 계산하여 영수증에 한 줄씩 출력합니다.

두 반복문은 같은 리스트를 사용하지만 서로 다른 작업을 수행합니다. 리스트의 요소를 읽는 과정에서 주문 기록을 삭제하거나 변경하지 않으므로 저장된 주문 내역을 다시 사용할 수 있습니다.

> 받은 돈과 결제 금액이 같으면 정상적으로 결제할 수 있으며, 거스름돈은 `0`원이 됩니다. 따라서 결제 금액이 부족한지를 검사할 때는 `<=`가 아닌 `<` 연산자를 사용해야 합니다.
