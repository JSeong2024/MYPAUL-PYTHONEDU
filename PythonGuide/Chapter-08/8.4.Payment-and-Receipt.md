# 8.4. Payment and Receipt

**결제와 영수증**

8.3절에서 받은 주문을 하나씩 읽어 합계를 구합니다. 합계에 맞는 할인을 적용한 뒤, 받은 돈이 충분하면 영수증을 출력합니다.

## 8.4.1. 주문 합계와 할인액 구하기

주문 한 건에는 메뉴 이름, 수량, 단가가 들어 있습니다. `for item, quantity, unit_price in orders:`로 세 값을 꺼내고, 수량과 단가를 곱한 금액을 `total`에 누적합니다.

```python
orders = [("커피", 2, 4800), ("쿠키", 2, 2500)]
total = 0

for item, quantity, unit_price in orders:
    total += quantity * unit_price

if total >= 30_000:
    rate = 10
elif total >= 10_000:
    rate = 5
else:
    rate = 0

discount = total * rate // 100
payment = total - discount

print(f"주문 합계: {total:,}원")
print(f"할인액: {discount:,}원")
print(f"결제 금액: {payment:,}원")
```

**실행 결과**

```text
주문 합계: 14,600원
할인액: 730원
결제 금액: 13,870원
```

30,000원 이상이면 10%, 10,000원 이상 30,000원 미만이면 5%를 할인합니다. 10,000원 미만이면 할인율은 0%입니다. 5.3절에서처럼 두 조건을 모두 만족할 수 있으므로 높은 금액 기준부터 검사합니다.

> 할인액은 `total * rate // 100`으로 구합니다. 이 프로그램에서 주문 합계와 할인율은 0 이상이므로 `//`를 사용하면 1원 미만을 버릴 수 있습니다.

## 8.4.2. 결제를 확인하고 영수증 출력하기

8.3절의 주문 입력 코드에 결제 과정을 붙여 봅시다. 저장된 주문이 없으면 받은 돈을 묻지 않습니다. 주문이 있다면 먼저 결제 금액을 보여 주고, 받은 돈은 0 이상의 정수로 입력받습니다.

```python
menu = {"커피": 4800, "쿠키": 2500, "차": 3000}
orders = []

print("메뉴판")
for name, price in menu.items():
    print(f"{name}: {price:,}원")

print()
while True:
    item = input("메뉴 이름 (주문 종료: 0): ")

    if item == "0":
        break

    if item not in menu:
        print("판매하지 않는 메뉴입니다.")
        continue

    quantity = int(input("수량: "))

    if quantity < 1:
        print("수량은 1 이상이어야 합니다.")
        continue

    unit_price = menu[item]
    orders.append((item, quantity, unit_price))

if not orders:
    print("저장한 주문이 없습니다.")
else:
    total = 0
    for item, quantity, unit_price in orders:
        total += quantity * unit_price

    if total >= 30_000:
        rate = 10
    elif total >= 10_000:
        rate = 5
    else:
        rate = 0

    discount = total * rate // 100
    payment = total - discount

    print()
    print(f"결제 금액: {payment:,}원")
    paid = int(input("받은 돈: "))

    if paid < payment:
        print(f"{payment - paid:,}원이 부족합니다.")
    else:
        change = paid - payment

        print()
        print("영수증")
        for item, quantity, unit_price in orders:
            amount = quantity * unit_price
            print(f"{item} × {quantity}: {amount:,}원")

        print(f"주문 합계: {total:,}원")
        print(f"할인액: {discount:,}원")
        print(f"결제 금액: {payment:,}원")
        print(f"받은 돈: {paid:,}원")
        print(f"거스름돈: {change:,}원")
```

**실행 예시**

```text

쿠키: 2,500원
차: 3,000원

수량: 2
메뉴 이름 (주문 종료: 0): 쿠키
수량: 2

영수증
```
