# 8.1. Project Overview

**카페 주문 프로그램 소개**

챕터 5에서는 주문 한 건의 결제 금액을 계산했습니다. 이번 프로젝트에서는 메뉴를 여러 번 주문할 수 있도록 주문 내역을 리스트에 모읍니다. 주문이 끝나면 할인액과 결제 금액을 계산하고, 받은 돈으로 결제할 수 있는지 확인합니다.

## 완성 화면

커피 두 잔과 쿠키 두 개를 주문한 뒤 `0`을 입력해 주문을 마칩니다.

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 커피
수량: 2
메뉴 이름 (주문 종료: 0): 쿠키
수량: 2
메뉴 이름 (주문 종료: 0): 0

결제 금액: 13,870원
받은 돈: 15000

영수증
커피 × 2: 9,600원
쿠키 × 2: 5,000원
주문 합계: 14,600원
할인액: 730원
결제 금액: 13,870원
받은 돈: 15,000원
거스름돈: 1,130원
```

## 프로그램 동작

- 메뉴판에 없는 이름을 입력하면 안내를 표시하고 메뉴 이름을 다시 받습니다. 수량은 정수로 입력한다고 가정하며, 1 미만이면 주문에 추가하지 않고 메뉴 선택으로 돌아갑니다.
- 메뉴 이름에 `0`을 입력하면 주문을 마칩니다. 저장된 주문이 없으면 결제 없이 프로그램을 끝냅니다.
- 주문 합계가 30,000원 이상이면 10%, 10,000원 이상 30,000원 미만이면 5%를 할인합니다. 10,000원 미만이면 할인하지 않습니다. 할인액의 1원 미만은 버립니다.
- 받은 돈은 0 이상의 정수로 입력한다고 가정합니다. 받은 돈이 결제 금액에 미치지 못하면 부족한 금액을 안내합니다. 결제가 가능하면 주문 내역과 거스름돈을 영수증에 출력합니다.
