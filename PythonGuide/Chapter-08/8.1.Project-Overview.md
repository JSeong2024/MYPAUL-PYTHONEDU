# 8.1. Project Overview

**카페 주문 프로그램 소개**

Chapter 05에서는 한 건의 주문에 대한 결제 금액을 계산하는 프로그램을 작성했습니다. 이번 프로젝트에서는 여러 메뉴를 연속으로 주문하고, 각각의 주문 내역을 리스트에 저장할 수 있도록 프로그램을 확장해 봅시다.

주문이 끝나면 전체 주문 합계와 할인액을 계산하고, 손님에게 받은 돈으로 결제할 수 있는지 확인합니다. 결제가 완료되면 주문 내역, 할인액, 결제 금액, 거스름돈 등이 포함된 영수증을 출력합니다.

## 완성 화면

다음은 커피 두 잔과 쿠키 두 개를 주문한 뒤, 메뉴 이름에 `0`을 입력하여 주문을 마치고 결제하는 과정입니다.

```text
메뉴판
커피: 4,800원
쿠키: 2,500원
차: 3,000원

메뉴 이름 (주문 종료: 0): 커피
수량: 2
메뉴 이름 (주문 종료: 0): 쿠키
수량: 2
메뉴 이름 (주문 종료: 0): 0

결제 금액: 13,870원
받은 돈: 15000

영수증
커피 × 2: 9,600원
쿠키 × 2: 5,000원
주문 합계: 14,600원
할인액: 730원
결제 금액: 13,870원
받은 돈: 15,000원
거스름돈: 1,130원
```

## 프로그램 동작

프로그램은 메뉴판 출력, 주문 입력, 결제 금액 계산, 결제 및 영수증 출력 순서로 동작합니다.

### 1. 메뉴판 출력

판매하는 메뉴의 이름과 가격을 딕셔너리에 저장하고, 프로그램을 시작할 때 메뉴판을 출력합니다.

### 2. 주문 입력

메뉴 이름과 수량을 반복해서 입력받고, 유효한 주문을 리스트에 추가합니다.

- 메뉴판에 없는 메뉴 이름을 입력하면 안내 문구를 출력하고 메뉴 이름을 다시 입력받습니다.
- 수량이 `1` 미만이면 안내 문구를 출력하고, 해당 주문을 저장하지 않은 채 메뉴 선택 단계로 돌아갑니다.
- 메뉴 이름에 `0`을 입력하면 주문 입력을 종료합니다.
- 저장된 주문 내역이 없다면 결제 과정을 진행하지 않고 프로그램을 종료합니다.

수량에는 항상 정수가 입력된다고 가정합니다.

### 3. 결제 금액 계산

저장된 주문 내역을 바탕으로 전체 주문 합계를 구하고, 주문 합계에 따라 할인율을 적용합니다.

최종 결제 금액은 전체 주문 합계에서 할인액을 빼 계산합니다.

> 할인율은 개별 메뉴의 주문 금액이 아닌 전체 주문 합계를 기준으로 결정합니다. 할인액을 계산할 때 1원 미만의 금액은 버립니다.

### 4. 결제 및 영수증 출력

최종 결제 금액을 출력하고 손님에게 받은 돈을 입력받습니다.

- 받은 돈이 결제 금액보다 적으면 부족한 금액을 안내하고 프로그램을 종료합니다.
- 받은 돈이 결제 금액 이상이면 거스름돈을 계산하고 영수증을 출력합니다.

영수증에는 각 주문의 메뉴 이름, 수량, 주문 금액과 함께 전체 주문 합계, 할인액, 결제 금액, 받은 돈, 거스름돈을 표시합니다.

받은 돈은 항상 `0` 이상의 정수로 입력된다고 가정합니다.
