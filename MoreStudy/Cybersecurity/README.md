폴더 구조 예시

```
Cybersecurity (정보보안)
├── Fundamentals (보안 기초)
│   ├── 정보보안의 기본 개념
│   ├── 네트워크와 웹의 동작 원리
│   ├── 암호화 및 인증
│   └── 보안 취약점과 공격 유형
│
├── Web Security (웹 보안)
│   ├── HTTP / HTTPS
│   ├── Cookie / Session / JWT
│   ├── SQL Injection
│   ├── XSS
│   ├── CSRF
│   └── 웹 취약점 분석 및 실습
│
├── Network Security (네트워크 보안)
│   ├── TCP/IP 및 OSI 모델
│   ├── IP / Port / DNS
│   ├── 패킷 분석
│   ├── 방화벽 및 접근 제어
│   ├── 네트워크 공격 및 방어
│   └── 네트워크 트래픽 분석 실습
│
└── CTF & Practice (보안 실습)
    ├── Web Challenges
    ├── Network Challenges
    └── Integrated Challenges
```
