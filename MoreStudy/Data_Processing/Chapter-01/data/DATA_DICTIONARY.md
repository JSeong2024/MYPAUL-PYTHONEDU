# Weekly Orders — 데이터 명세

Chapter 01 학습용으로 작성한 **가상 주문 데이터**입니다. 실제 고객의 주문 내역이 아닙니다.

| 열 | 의미 | 값의 조건 |
|---|---|---|
| `order_id` | 주문 식별자 | 비어 있지 않은 문자열, 파일 내 고유값 |
| `category` | 상품 분류 | 비어 있지 않은 문자열 |
| `quantity` | 주문 수량 | 1 이상의 정수 |
| `unit_price` | 상품 단가 | 0 이상의 정수 (원, KRW) |

- 한 행이 하나의 주문 기록을 의미합니다.
- 매출액은 `quantity × unit_price`로 계산합니다. 할인, 취소, 세금은 고려하지 않습니다.
- 의도적으로 잘못된 데이터 4건(수량 0, 숫자가 아닌 수량, 단가 누락, 주문 번호 중복)이 포함되어 있습니다.
- 중복 주문 번호는 파일에서 먼저 등장한 유효한 기록을 기준으로 판정합니다. 유효하지 않은 기록의 주문 번호는 고유값 목록에 추가하지 않습니다.
- CSV의 수치는 처음에는 **문자열**이므로, 계산 전에 정수로 변환하고 검증해야 합니다.
