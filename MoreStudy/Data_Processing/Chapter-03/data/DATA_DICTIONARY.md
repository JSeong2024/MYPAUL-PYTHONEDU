# Weekly Sensor Temperature — Data Dictionary

교육용 가상 온도 측정 데이터입니다. 실제 관측 기록이 아닙니다.

| 항목 | 의미 | 단위 및 규칙 |
|---|---|---|
| `date` | 측정 날짜 | ISO 8601, `YYYY-MM-DD` |
| `ST-01` ~ `ST-04` | 장치별 일일 온도 측정값 | 섭씨(°C), 실수 |
| `-999` | 측정값 누락을 나타내는 표식 | 물리적 온도가 아니라 결측 표식 |
| `0~45` | 이 실습에서 허용하는 온도 범위 | 교육용 규칙이며 일반적인 센서 표준이 아님 |
| `>30` | 경보 판정 기준 | 유효한 온도만 판정 |

원본은 `weekly_temperatures.csv`이며 실습 코드는 원본 파일을 수정하지 않습니다.
합계 및 평균을 계산할 때 결측값과 범위 밖 값을 제외합니다.
이 데이터는 실제 기상 관측소 데이터가 아니라 4개 가상 센서의 단순 수치 행렬입니다.
