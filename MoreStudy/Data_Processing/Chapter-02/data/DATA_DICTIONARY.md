# Library Loans — Data Dictionary

Chapter 02 Mini Project용 가상 도서관 대출 데이터입니다. 실제 이용자나 공공도서관의 기록이 아닙니다.

- **파일:** `library_loans.json`
- **레코드 수:** 15건 (정상 12건, 오류 3건)
- **구조:** JSON 배열 안의 객체를 Python `list[dict]`로 표현
- **고유성 기준:** `loan_id`는 **유효 레코드 기준** 중복 불가; `book_id`는 서로 다른 대출에서 재등장 가능

| 필드 | 자료형 | 의미 | 검증 규칙 |
|---|---|---|---|
| `loan_id` | `str` | 대출 건 식별자 | 공백 제외 비어 있지 않고 유효 기록 내 고유 |
| `branch` | `str` | 도서관 분관 | 공백 제외 비어 있지 않음 |
| `book_id` | `str` | 도서 식별자 | 공백 제외 비어 있지 않음 |
| `category` | `str` | 도서 분류 | 공백 제외 비어 있지 않음 |
| `status` | `str` | 대출 상태 | `borrowed` 또는 `returned` |
| `days_overdue` | `int` | 연체 일수 | 0 이상, `bool`은 허용하지 않음 |

이 자료에서는 `borrowed`이면서 `days_overdue > 0`인 기록을 현재 연체 건으로 간주합니다. 이 규칙은 **교육용 가정**이며 실제 대출 시스템의 연체 정책과는 다를 수 있습니다. 검증 실패 레코드는 집계에서 제외하되 사유별 건수로 기록합니다.

| 오류 예시 | 레코드 |
|---|---|
| 중복 대출 번호 | `L-009` 두 번째 등장 |
| 분류 누락 | `L-014` |
| 음수 연체 일수 | `L-015` |
