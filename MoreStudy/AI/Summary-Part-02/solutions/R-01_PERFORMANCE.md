# R-01 — 성능 비교 기준

[← Problems](../problem.md) · [Summary 목차](../README.md)

Batch 추론과 Sample별 추론을 동일한 CPU·모델·입력 순서에서 비교합니다. 먼저 두 방법의 분류 확률과 회귀 예측값 차이를 확인한 뒤 처리 시간을 측정합니다.

| 확인 항목 | 검증 기준 |
|---|---|
| 출력 일치 | 각 모델의 최대 절댓값 차이 `1e-6` 이하 |
| 처리 순서 | `site_id`, `date`와 정렬 정책 유지 |
| 측정 | 사전 실행 뒤 반복 측정 시간 중앙값 |
| 오류 처리 | 처리 실패 시 기존 정상 배포 정보 유지 |

동일 환경에서 측정하더라도 운영체제의 자원 사용량에 따라 실행 시간이 달라질 수 있습니다. **특정 배속을 정답 조건으로 사용하지 않습니다.** 실제 측정치는 `benchmark.json`에 기록합니다.
