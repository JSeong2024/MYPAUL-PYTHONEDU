# 자동 테스트

`Chapter-05/` 폴더에서 다음 명령으로 실행합니다.

```bash
python -m unittest discover -s tests -v
```

테스트는 파일의 상대경로와 함수 반환값을 검사하고, 프로젝트 모범 구현을 임시 폴더에서 실행해 CSV 출력 규격을 확인합니다. 학생용 `starter.py`는 미완성 상태이며 자동 통과가 요구되지 않습니다.

Notebook의 코드 셀은 별도로 `nbclient`를 이용해 실행 검증할 수 있습니다. 배포 ZIP에는 Notebook 실행으로 생긴 `outputs`와 `__pycache__`를 포함하지 않습니다.
