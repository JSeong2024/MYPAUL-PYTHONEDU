# Chapter 04 — Tests

입력 데이터 검증, 평가 지표 계산, 데이터 분할 규칙, 프로젝트 모범 구현과 Notebook에 사용되는 예제 함수를 검사합니다.

`Chapter-04/`에서 실행합니다.

```bash
python -m unittest discover -s tests -v
```

`starter.py`는 학생이 완성할 파일이므로 테스트 대상에서 제외합니다. 테스트는 `solutions/`의 모범 구현을 검사합니다. 일부 테스트는 잘못된 입력을 임시 CSV로 저장한 뒤 오류 발생 여부를 확인합니다.
