# Chapter 02 — Tests

모범답안의 계산, 입력 검증, 합성 데이터, 프로젝트 결과를 검사합니다. Starter Code에는 구현되지 않은 TODO가 있으므로 테스트 대상에 포함하지 않습니다.

`Chapter-02/`에서 실행:

```bash
python -m unittest discover -s tests -v
```

테스트는 제공된 합성 데이터와 고정된 난수 시드를 기준으로 작성했습니다. 다른 데이터에서 같은 Accuracy 또는 MAE가 나온다는 의미는 아닙니다.
