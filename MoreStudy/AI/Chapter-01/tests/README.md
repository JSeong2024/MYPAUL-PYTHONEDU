# Testing & Verification

`Chapter-01/`에서 테스트를 실행합니다.

```bash
python -m unittest discover -s tests -v
```

데이터 생성 재현성, 입력 검증, 예제·모범 구현의 계산값, 검토 기준의 경계 조건을 확인합니다. 직접 완성하는 `starter.py`는 자동 테스트 대상이 아닙니다.
