# Testing & Verification

`Chapter-01/` 폴더에서 실행합니다.

```bash
python -m unittest discover -s tests -v
```

테스트에서는 데이터 생성의 재현성, 예제 실행, 모범 구현의 집계값, 입력 오류와 경계값 처리, 사람 검토 기준의 일관성을 확인합니다. `projects/*/starter.py`는 학습자가 완성할 코드이므로 자동 테스트 대상에서 제외합니다.
