# Advanced Project — Multi-Station Air Quality Report

## 문제 상황

다수의 대기질 관측소 데이터를 검증하고, 선택한 관측소 수에 맞는 상세 보고서를 자동 생성합니다.

입력 데이터: `data/air_quality_hourly.csv, data/air_stations.json` (모두 교육용 가상 기록)

## 요구사항

1. 날짜 범위·중복·음수·미등록 관측소·비수치 값을 검사하고 감사 기록을 저장합니다.
2. 선택한 관측소마다 예상 1시간 슬롯을 생성하고 관측 수집률을 계산합니다.
3. 관측값과 24개 관측 시각 이동평균을 비교하고, 최소 18개 관측을 요구합니다.
4. 관측소 수가 1개·3개·전체일 때도 레이아웃이 유지되어야 합니다.
5. 그래프의 임계선은 교육용 예시값이며 법적·공적 기준을 뜻하지 않습니다.

## 완료 조건

- 원본 데이터를 변경하지 않고 `output/`에 결과를 저장합니다.
- 결과 그래프의 시간대와 단위를 명확히 표기합니다.
- 결측·미관측값을 실제 0으로 단정하지 않습니다.
- 테스트가 검증하는 항목 외에도 그래프의 축·범례·레이아웃을 직접 점검합니다.
