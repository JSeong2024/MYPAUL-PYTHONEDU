# Mini Project — Hourly Weather Review

## 문제 상황

기온은 관측값의 평균, 구간별 강수량은 합계라는 차이를 유지하면서 시간대별 변화를 분석합니다.

입력 데이터: `data/weather_hourly.csv` (모두 교육용 가상 기록)

## 요구사항

1. 관측소와 시각을 기준으로 중복을 검사합니다.
2. 관측소별 누락 시각을 복원합니다.
3. 기온 추이와 24시간 이동평균을 비교합니다.
4. 일별 평균기온·강수량 합계·관측 건수를 CSV에 저장합니다.

## 완료 조건

- 원본 데이터를 변경하지 않고 `output/`에 결과를 저장합니다.
- 결과 그래프의 시간대와 단위를 명확히 표기합니다.
- 결측·미관측값을 실제 0으로 단정하지 않습니다.
- 테스트가 검증하는 항목 외에도 그래프의 축·범례·레이아웃을 직접 점검합니다.
