# Mini Project — Daily Store Revenue Trends

## 문제 상황

매장별 매출 기록에서 실제 0원과 관측 누락을 구분하고, 일별 추이와 7일 이동평균을 비교합니다.

입력 데이터: `data/sales_daily.csv` (모두 교육용 가상 기록)

## 요구사항

1. 매장·날짜 키 중복을 검사합니다.
2. 모든 날짜를 가진 인덱스로 재구성하되 결측은 NaN으로 유지합니다.
3. 매장별 일별 매출과 7개 관측이 모두 존재하는 이동평균을 그림으로 저장합니다.
4. 매장별 관측 일수와 매출 합계 표를 CSV로 저장합니다.

## 완료 조건

- 원본 데이터를 변경하지 않고 `output/`에 결과를 저장합니다.
- 결과 그래프의 시간대와 단위를 명확히 표기합니다.
- 결측·미관측값을 실제 0으로 단정하지 않습니다.
- 테스트가 검증하는 항목 외에도 그래프의 축·범례·레이아웃을 직접 점검합니다.
