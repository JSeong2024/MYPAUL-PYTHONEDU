# Urban Traffic Time Series Audit & Reporting — Reference Implementation Notes

이 파일은 문제의 유일한 정답이 아닌 **모범 구현의 설계 근거**를 설명합니다. 먼저 `projects/advanced_02_traffic/TASK.md`에 따라 직접 구현해 보세요.

## 검증 순서

1. 원본 행의 키(관측소·시각, 또는 구간·시각)와 시간대 기준을 확인합니다.
2. 비정상 시각, 등록되지 않은 ID, 음수·문자열 측정, 중복 키를 기록하고 집계에서 제외합니다.
3. 예상 관측 슬롯을 생성해 `NaN`으로 누락을 보존합니다.
4. 합계는 구간별 개수에만 적용하며, 측정 농도나 평균 지연을 단순 합산하지 않습니다.
5. 처리 결과를 CSV로 기록해 재검증하고, 보고서에 단위·기간·한계를 표기합니다.

## 중요한 선택

- 중복 키는 한 행만 임의로 택하지 않고 해당 키를 가진 원본 행들을 격리합니다.
- 이동평균의 최소 유효 관측 수(`min_periods`)와 기대 관측 간격을 명시합니다.
- 데이터가 없는 시각의 값을 0이라고 가정하지 않습니다.
- 자동 테스트는 데이터 계산의 정확성을 보완하지만 시각적 오해 가능성을 완전히 검증하지는 못합니다.
