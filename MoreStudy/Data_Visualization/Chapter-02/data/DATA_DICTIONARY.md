# DATA_DICTIONARY — Library Visits

교육용 가상 데이터이며 실제 도서관 또는 행정기관의 통계가 아닙니다.

- **관측 기간:** 2026-10-01 ~ 2026-10-14 (14일)
- **관측 단위(Grain):** 도서관 분관 1곳의 1일 기록
- **분관:** Central, Riverside, Hilltop, Eastgate (총 4곳)
- **예정 레코드:** 14일 × 4곳 = 56행
- **제공 레코드:** 55행. `Eastgate`의 `2026-10-07` 기록은 의도적으로 누락된 상태이며 **방문 0건이 아닙니다**.
- **자료 성격:** 재현 가능한 교육용 가상 데이터. 인과관계·모집단 추론을 목적으로 생성하지 않았습니다.

| 필드 | 형식 | 의미 | 단위 및 범위 |
|---|---|---|---|
| `date` | `YYYY-MM-DD` | 관측 날짜(현지 날짜) | 일 |
| `branch` | 문자열 | 분관 이름 | 지정된 4곳 |
| `visitors` | 정수 | 일별 방문자 수 | 명/일, 0 이상 |
| `new_members` | 정수 | 일별 신규 등록자 수 | 명/일, 0 ≤ `new_members` ≤ `visitors` |
| `event_day` | 0 또는 1 | 해당 분관의 자체 행사 개최 여부 | 플래그, 인과관계 해석 금지 |

`new_members / visitors * 100`은 **일별 방문자 대비 신규 등록 비율**입니다. 신규 등록과 방문을 중복 없는 1인 단위로 집계한다는 교육용 가정이 필요합니다. 여기에서는 코드 구조를 배우기 위한 예시이며 실제 지표를 대표하지 않습니다.

비어 있는 행은 데이터 부재를 나타냅니다. 누락 날짜를 정해진 이유 없이 0명으로 대체하지 마세요. 월간·일간 비교에서는 분관별 관측일 수를 함께 표시하세요.
