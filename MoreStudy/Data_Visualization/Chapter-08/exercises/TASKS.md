- **P07 두 그래프를 탭으로 구성** — 매출 추이와 분류 그래프를 별도 탭으로 표시하세요. [`07_tabs.py`](./07_tabs.py)

- **P10 세션별 카운터** — 세션 상태를 초기화하고, Add one 버튼 클릭 시 값이 1 증가하도록 나머지 코드를 완성하세요. [`10_state_counter.py`](./10_state_counter.py)

- **P12 데이터 로딩 캐시** — 파일 변경 시 캐시 키가 바뀌도록 함수에 인수를 전달하세요. [`12_cache.py`](./12_cache.py)

- **P14 업로드 검증** — CSV 업로드 파일을 읽고 크기·내용 검증을 통과한 행만 표시하세요. [`14_upload.py`](./14_upload.py)

- **P18 임계값 편집** — 사용자가 편집한 임계값에 음수·결측이 없는지 검증하세요. [`18_editor.py`](./18_editor.py)

- **P20 필터와 KPI 동기화** — 선택한 매장의 데이터를 먼저 필터링한 뒤 KPI와 Figure를 계산하세요. [`20_recompute.py`](./20_recompute.py)
