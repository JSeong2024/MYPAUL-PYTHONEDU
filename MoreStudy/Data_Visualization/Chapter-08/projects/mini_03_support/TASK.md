# Mini Project — Customer Support Workload Dashboard

## 문제 상황

여러 고객지원팀의 문의 처리 현황을 파악하려고 합니다. 팀과 우선순위에 따라 열린 문의 수가 얼마나 다른지, 첫 응답시간의 분포는 어떠한지 비교하는 대시보드가 필요합니다.

## 요구사항

1. 팀과 우선순위를 다중 선택할 수 있도록 구성합니다.
2. 선택 조건에서 전체 문의, 미해결 문의, 미해결 비율, 첫 응답시간 중앙값을 표시합니다.
3. 날짜별 문의 수와 팀별 첫 응답시간 분포를 시각화합니다.
4. 0건 필터 상태를 별도로 안내합니다.
5. 다운로드 CSV에는 필터된 데이터만 저장합니다.
6. 중앙값과 평균의 의미가 다름을 도움말에 안내합니다.

## 완료 기준

- 전체 문의 건수 = 현재 필터의 행 수입니다.
- 미해결 비율의 분모는 **현재 필터의 전체 문의 수**입니다.
- 분포 비교는 축 단위를 시간으로 명시합니다.
