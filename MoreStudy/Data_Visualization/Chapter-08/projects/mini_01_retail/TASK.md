# Mini Project — Retail Sales Dashboard

## 문제 상황

네 개 매장의 매출 데이터를 관리하고 있습니다. 분석 담당자가 매장·상품 분류·기간을 변경하면 화면의 매출 합계, 판매 수량, 추이 그래프, 분류 그래프가 **같은 조건**으로 갱신되는 웹 대시보드가 필요합니다.

## 요구사항

1. 매장(복수), 상품 분류(복수), 날짜 범위 필터를 제공합니다.
2. 현재 필터를 적용한 뒤 매출액·판매 수량·관측 일수를 계산합니다.
3. 날짜별 매출 선 그래프와 분류별 매출 막대그래프를 나란히 표시합니다.
4. 매장을 모두 해제한 경우 0원이라는 임의의 결과로 차트를 그리지 않고 빈 상태 안내를 표시합니다.
5. 현재 필터가 적용된 행만 CSV로 내려받습니다.
6. 원본 CSV는 수정하지 않으며 경로는 `Path(__file__)` 기준으로 찾습니다.

## 완료 기준

- 필터를 변경하면 두 그래프와 세 KPI가 함께 변합니다.
- 매출은 `revenue_krw`의 합계이며 평균이나 단가가 아닙니다.
- CSV 내보내기 값과 화면의 필터 조건이 일치합니다.
