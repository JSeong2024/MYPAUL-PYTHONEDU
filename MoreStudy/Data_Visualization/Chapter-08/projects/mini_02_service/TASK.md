# Mini Project — Service Latency Monitoring Dashboard

## 문제 상황

서비스 세 종류의 시간별 응답 지연 및 오류 기록을 확인하려고 합니다. 운영자가 서비스와 기간을 선택하고 허용 지연시간을 바꾸면, 기준 초과 기록과 오류율, 지연 추이를 함께 확인할 수 있어야 합니다.

## 요구사항

1. 서비스 선택과 P95 지연 임계값 슬라이더를 제공합니다.
2. 전체 요청 수, 오류 건수, **요청 수로 가중된 오류율**을 KPI로 표시합니다.
3. 시간별 P95 그래프와 서비스별 오류율 그래프를 표시합니다.
4. 기준 초과 시간대의 **기록 개수**를 함께 표시합니다.
5. 서비스 선택을 모두 해제하면 안전한 빈 화면을 보여줍니다.
6. 시간별 P95의 평균을 전체 요청의 P95로 잘못 표기하지 않습니다.

## 완료 기준

- 오류율은 오류 건수 합계 ÷ 요청 수 합계로 계산됩니다.
- 임계값을 바꾸면 기준 초과 시간대 수가 바뀝니다.
- UTC라는 시간대 정보가 그래프에 표시됩니다.
