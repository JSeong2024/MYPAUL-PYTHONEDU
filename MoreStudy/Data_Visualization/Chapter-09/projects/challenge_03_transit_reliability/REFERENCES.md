# City Transit Reliability — 참고 문서

<a id="coverage"></a>
## 예정 슬롯과 관측 누락

`(stop_id, local_date, expected_hour)`의 고유 조합을 `schedule.csv`에서 가져옵니다. 실제 관측 CSV에는 결측 시간 자체가 없으므로, 입력 행 수만으로 누락을 알 수 없습니다. 유효한 관측과 예정 슬롯을 `left join`하면 누락을 확인할 수 있습니다.

| 예정 슬롯 | 실제 관측 | 표시 |
|---|---|---|
| 있음 | 0명 | `valid`, 0명 |
| 있음 | 기록 없음 | `missing`, 승객 수 공란 |
| 있음 | 유효한 15명 | `valid`, 15명 |

<a id="timezone"></a>
## 시간대 변환

`2026-09-30T22:00:00Z`는 KST에서 2026년 10월 1일 오전 7시입니다. UTC를 KST로 변환한 **뒤** 예정 슬롯을 찾습니다. 원본 ISO UTC 표기에는 `Z` 또는 `+00:00` 오프셋이 필요합니다.

<a id="intervals"></a>
## 장애 시간 구간

시작 시각 포함, 끝 시각 제외인 `[start, end)`를 사용합니다. 예를 들어 10:00부터 12:00까지 장애는 10시·11시 슬롯을 포함하지만 12시 슬롯은 포함하지 않습니다.

<a id="completeness"></a>
## 완전한 일별 집계

매일 예정 슬롯 8개 중 7개만 있으면 관측된 7개 슬롯의 합계는 계산할 수 있습니다. 그러나 **확정된 일별 총승객 수**는 결측이 해소될 때까지 공란입니다.

<a id="determinism"></a>
## 동일 결과 검증

입력 파일·필터 설정·코드가 같으면 분석 CSV와 JSON, 정적 PNG, Plotly HTML의 SHA-256이 같아야 합니다. Plotly의 임의 DOM ID나 시간 의존적 메타데이터는 고정합니다. `manifest.json`은 자신을 제외한 입출력 파일 해시를 기록합니다.

<a id="quality-gate"></a>
## Quality Gate

`quality_gate.py`는 후보 프로그램을 별도 데이터·출력 경로로 반복 실행합니다. G1 입력 계약·필수 출력, G2 파일 무결성, G3 집계·경계 조건, G4 정적/대화형 시각화, G5 재현성을 검사합니다. 그래프의 색 대비나 글자 겹침은 별도로 육안 확인이 필요합니다.
