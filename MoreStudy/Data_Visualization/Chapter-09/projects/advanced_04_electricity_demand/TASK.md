# Advanced 04 — Regional Electricity Demand

## 문제 상황
UTC 시간대·실측 전력과 에너지를 구별한 지역별 수요 보고서가 필요합니다. 관측이 없는 시간과 값이 0인 시간을 혼동하지 않고, 선택 대상이 달라져도 보고서를 생성해야 합니다.

## 요구사항
1. `data/`의 원본 파일을 수정하지 않습니다.
2. 잘못된 값, 중복 관측, 등록되지 않은 참조 ID를 검증합니다.
3. 그래프에는 제목·축 단위·집계 기간·데이터 출처를 표시합니다.
4. 기록이 없는 슬롯은 관측 0건으로 표시하되, 측정값 0으로 대체하지 않습니다.
5. 그래프 PNG와 집계 CSV, 실행 요약 JSON을 `output/`에 생성합니다.
6. 빈 필터 결과와 잘못된 입력에서 이해할 수 있는 오류를 제공합니다.
7. 결과 파일은 반복 실행해도 예측 가능한 형태여야 합니다.

## 시작 방법
`starter.py`를 완성한 뒤 `python projects/advanced_04_electricity_demand/starter.py`로 실행합니다.

## 완료 기준
생성된 CSV의 집계값이 원본의 유효 데이터 기준과 일치하고, PNG의 축·범례·단위가 명확해야 합니다. 파일이 만들어졌다는 사실만으로 합격 처리하지 않습니다.
