# Advanced Project 03 — 모범 구현 해설

P95는 상위 지연 구간을, 서버 오류율은 응답의 안정성을 보여줍니다. 빠른 응답이라도 오류가 빈번할 수 있으므로 두 지표를 함께 확인합니다.

## 실행

```bash
python solutions/advanced_03_service_monitor/reference_solution.py
```

## 코드 검토 순서

1. 서비스 기준정보와 요청 CSV의 필수 열·고유키를 확인합니다.
2. 중복 ID, 지연시간, HTTP 코드, 서비스 ID, UTC 시각을 검증하고 행별 제외 사유를 모두 기록합니다.
3. 유효 요청의 시각을 KST로 변환하고 선택한 기간·서비스로 한 번 필터링합니다.
4. 서비스별 요청 수, P95, 오류율을 계산하고 빈 그룹은 별도로 처리합니다.
5. 예정 시간 축을 생성해 요청이 없는 시간대를 CSV에 보존합니다.
6. 동일 필터 결과에서 정적 그래프·인터랙티브 그래프·CSV를 생성합니다.

이 파일의 계산 규칙은 프로젝트 README의 데이터 검증 및 계산 기준을 따릅니다. 출력 그림은 `figures/projects/`에 생성된 예시와 비교할 수 있습니다.
