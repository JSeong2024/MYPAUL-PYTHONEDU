# Mini Project 01 — 모범 구현 해설

서로 다른 단위의 수치를 같은 y축에서 직접 비교하지 않습니다.

## 실행

```bash
python solutions/mini_01_weather_report/reference_solution.py
```

## 코드 검토 순서

1. 날짜 열과 두 측정 열의 자료형을 확인합니다.
2. 날짜를 정렬한 뒤 그래프의 x축을 준비합니다.
3. 기온·강수량의 서로 다른 y축과 범례를 구성합니다.
4. CSV와 PNG의 수치와 레이블을 검토합니다.

이 파일의 계산 규칙은 프로젝트 README의 데이터 검증 및 계산 기준을 따릅니다. 출력 그림은 `figures/projects/`에 생성된 예시와 비교할 수 있습니다.
