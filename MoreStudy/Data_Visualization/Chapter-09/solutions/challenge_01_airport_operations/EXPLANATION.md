# Challenge 01 — 모범 구현 해설

비율 계산 전에 분모의 모집단을 정의해야 합니다.

## 실행

```bash
python solutions/challenge_01_airport_operations/reference_solution.py
```

## 코드 검토 순서

1. 입력 검증과 참조 데이터 계약을 문서화합니다.
2. 결항과 운항을 분리한 지표 함수를 작성합니다.
3. 공항·기간 필터가 집계와 그림에 동일하게 적용되도록 연결합니다.
4. 정상·취소·중복·잘못된 항공편 시나리오를 작성합니다.
5. 일별 결과와 전체 KPI의 합계가 일치하는지 검증합니다.

이 파일의 계산 규칙은 프로젝트 README의 데이터 검증 및 계산 기준을 따릅니다. 출력 그림은 `figures/projects/`에 생성된 예시와 비교할 수 있습니다.
