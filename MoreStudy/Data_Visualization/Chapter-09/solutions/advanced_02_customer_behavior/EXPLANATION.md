# Advanced Project 02 — 모범 구현 해설

지표의 분모를 먼저 정의해야 서로 다른 고객군을 공정하게 비교할 수 있습니다.

## 실행

```bash
python solutions/advanced_02_customer_behavior/reference_solution.py
```

## 코드 검토 순서

1. 고객 기준정보와 주문 데이터를 키로 연결할 수 있는지 확인합니다.
2. 주문 ID·금액·상태·날짜·참조 고객을 검증합니다.
3. 선택 기간과 `paid` 조건을 적용한 후 구매 고객을 고유 ID로 셉니다.
4. 전체 등록 고객 수를 별도로 집계해 참여율의 분모로 사용합니다.
5. 고객군별 매출과 참여율을 CSV·그래프로 검증합니다.

이 파일의 계산 규칙은 프로젝트 README의 데이터 검증 및 계산 기준을 따릅니다. 출력 그림은 `figures/projects/`에 생성된 예시와 비교할 수 있습니다.
