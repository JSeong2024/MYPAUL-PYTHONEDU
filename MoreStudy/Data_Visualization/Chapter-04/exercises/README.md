# Coding Practice

- 각 파일에 있는 `TODO`와 `NotImplementedError`를 요구사항에 맞춰 대체하세요.
- 각 파일의 원본 예제는 `examples/`에 있습니다. 먼저 직접 구현한 후 비교하세요.
- 완성 예시는 `solutions/practice/`에 분리했습니다. README에서는 정답 코드를 공개하지 않습니다.
- **출력 그래프는 `figures/`에 기록되므로**, 실행 전에 기존 파일을 복사해 두면 비교하기 좋습니다.
- 연습문제의 목적은 처음부터 프로그램을 모두 작성하는 것이 아니라, 변경해야 할 핵심 부분을 올바르게 작성하는 것입니다.
