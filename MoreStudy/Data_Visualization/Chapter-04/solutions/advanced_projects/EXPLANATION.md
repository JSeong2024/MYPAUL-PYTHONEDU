# Advanced Project 01 — Reference Solution Design

1. `load_inputs`: 대여소 정보·집계 가능 상태·개별 이용 기록을 구분하여 로드합니다.
2. `clean_rides`: 미등록 대여소, 음수·과도한 이용시간, 잘못된 날짜, 미등록 시간대, 중복 `ride_id`, 집계 불가 슬롯의 기록을 제외합니다.
3. `build_slot_counts`: 먼저 유효 이용을 슬롯별로 세고 `bike_reporting.csv`와 결합합니다. `reporting=1`이며 이용이 없는 슬롯은 0으로, `reporting=0`이면 결측으로 유지합니다.
4. `filter_stations`: 보고서에 포함할 대여소 ID 목록을 검증합니다. 미등록 ID는 조용히 버리지 않고 오류를 발생시킵니다.
5. `summarize`: 커버리지와 집계값을 분리합니다. 누락된 슬롯을 평균 분모에 포함하지 않습니다.
6. `run`: 요약 PNG·히트맵·Facets·CSV·JSON을 저장하며 모든 Figure를 닫습니다.

**검증 기준:** 원본 6,824행 중 5행 제외, 선택 대여소 수가 달라도 보고서가 생성됨, 누락 슬롯은 `NaN` 유지, 미등록 대여소 요청은 `ValueError`.

**추가 확장:** 기간 필터·HTML 보고서·관측 장비/데이터 수집 상태 점검은 별도 기능으로 확장할 수 있습니다.

이 모범 구현은 하나의 가능한 답안입니다. 시각화의 가독성과 검증 조건을 만족하는 다른 구현도 정답이 될 수 있습니다.
