# Mini 02 Support

## 문제 상황

문의 응답시간의 분포와 우선순위별 응답 수준을 비교합니다.

## 요구사항

1. 결측·음수 응답시간 구분
2. 우선순위별 중앙값/P90 산출
3. Histogram·ECDF·Boxplot·60분 이내 비율
4. 누락 기록 수 명시

## 실행과 확인

`starter.py`의 `run()`을 구현하세요. 참조용 데이터는 `../../data/`에 있습니다. 원본 데이터는 수정하지 않고 `output/`에 결과를 저장해야 합니다.

**기대 출력:** report.png, priority_summary.csv, summary.json

## 평가 기준

- 그룹별 표본 크기(n), 결측과 제외 기준, 수치 단위 표시
- 시각적 비교에서 축·색·범례의 일관성
- 예상 밖 입력 및 누락 관측값 대응
- 결론에서 관측 결과와 인과적 주장 구분
