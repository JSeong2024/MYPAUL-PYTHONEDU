# Advanced 01 Quality

## 문제 상황

공장 수·라인 수가 달라져도 자동으로 시각화 보고서를 생성하는 시스템을 작성합니다.

## 요구사항

1. 입력 Schema·고유 ID 검증
2. 측정 검토 로그와 분모 계산
3. Plant 선택 및 존재 여부 확인
4. Wilson 구간과 두께 평균 부트스트랩 구간 제시
5. Plant별 2×2 Figure를 자동 저장
6. JSON/CSV 생성 및 재현성 테스트

## 실행과 확인

`starter.py`의 `run()`을 구현하세요. 참조용 데이터는 `../../data/`에 있습니다. 원본 데이터는 수정하지 않고 `output/`에 결과를 저장해야 합니다.

**기대 출력:** Plant-A.png 등, line_summary.csv, summary.json

## 평가 기준

- 그룹별 표본 크기(n), 결측과 제외 기준, 수치 단위 표시
- 시각적 비교에서 축·색·범례의 일관성
- 예상 밖 입력 및 누락 관측값 대응
- 결론에서 관측 결과와 인과적 주장 구분
