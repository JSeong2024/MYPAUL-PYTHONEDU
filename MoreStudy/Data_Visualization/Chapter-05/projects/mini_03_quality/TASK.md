# Mini 03 Quality

## 문제 상황

생산 라인별 검사 결과와 두께 측정 분포를 확인합니다.

## 요구사항

1. 검사 ID 중복 처리 및 기록
2. 두께 결측·범위 밖 값은 검토로 분리
3. 라인별 분모/불량률 보고
4. Boxplot과 비교 Bar 제작

## 실행과 확인

`starter.py`의 `run()`을 구현하세요. 참조용 데이터는 `../../data/`에 있습니다. 원본 데이터는 수정하지 않고 `output/`에 결과를 저장해야 합니다.

**기대 출력:** report.png, line_summary.csv, summary.json

## 평가 기준

- 그룹별 표본 크기(n), 결측과 제외 기준, 수치 단위 표시
- 시각적 비교에서 축·색·범례의 일관성
- 예상 밖 입력 및 누락 관측값 대응
- 결론에서 관측 결과와 인과적 주장 구분
