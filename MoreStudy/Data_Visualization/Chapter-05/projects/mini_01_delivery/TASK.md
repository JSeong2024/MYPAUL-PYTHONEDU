# Mini 01 Delivery

## 문제 상황

배송 소요일의 분포와 지역·운송사별 정시 배송 비율을 비교합니다.

## 요구사항

1. 배송 완료·측정 가능한 소요일만 비교 분석
2. 지역별/운송사별 분모와 비율 계산
3. 분포/Box/범주별 비율 2×2 출력
4. 제외된 배송 건수 보고

## 실행과 확인

`starter.py`의 `run()`을 구현하세요. 참조용 데이터는 `../../data/`에 있습니다. 원본 데이터는 수정하지 않고 `output/`에 결과를 저장해야 합니다.

**기대 출력:** report.png, zone_summary.csv, carrier_summary.csv, summary.json

## 평가 기준

- 그룹별 표본 크기(n), 결측과 제외 기준, 수치 단위 표시
- 시각적 비교에서 축·색·범례의 일관성
- 예상 밖 입력 및 누락 관측값 대응
- 결론에서 관측 결과와 인과적 주장 구분
